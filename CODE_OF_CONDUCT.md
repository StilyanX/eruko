# Code of conduct

Eruko follows the Contributor Covenant, version 2.1 (contributor-covenant.org/version/2/1/code_of_conduct). It applies in the repository, its issues and pull requests, and wherever someone speaks for the project.

Report a breach to the maintainers privately, through the repository's Security tab, "Report a vulnerability", and start the title with "Conduct". The maintainers answer within 14 days and keep the reporter's name private.
