# 6.08 Relaxed order
Part: relaxed order
Clause: [atomics.order], [intro.races]
After: 6.07
Levels: c++11

## Example
```cpp
#include <atomic>
#include <functional>
#include <print>
#include <thread>

//: Count with relaxed adds; no other memory hangs on them.
void count_up(std::atomic<int>& hits, int k)
{
    for (int i {0}; i < k; ++i) {
        hits.fetch_add(1, std::memory_order_relaxed);
    }
}

int main()
{
    std::atomic<int> hits {0};
    std::thread a {count_up, std::ref(hits), 500};
    std::thread b {count_up, std::ref(hits), 500};
    //: Let the joins order the adds before the read.
    a.join();
    b.join();
    //: Read with relaxed too; no add is lost, so it prints 1000.
    std::println("{}", hits.load(std::memory_order_relaxed));
}
```

Write a program that reads n and then n numbers and prints their sum and how many are negative. Two threads each take a half: the first n / 2 numbers, and the rest. Each adds its half into its own sum and counts negatives in one shared atomic counter, then raises its own done flag. Main waits for both flags, then prints.
Input: one line, n, then n numbers.
Output: one line, the sum and the count of negatives.
Limits: 1 ≤ n ≤ 1000; −1000 ≤ each number ≤ 1000.
### Examples
```in
4 3 -1 4 -2
```
```out
4 2
```
### Reference
```cpp
#include <atomic>
#include <functional>
#include <iostream>
#include <thread>
#include <vector>

void work(const std::vector<int>& v, int from, int to,
          long long& sum, std::atomic<int>& negatives,
          std::atomic<bool>& done)
{
    for (int i {from}; i < to; ++i) {
        sum += v[i];
        if (v[i] < 0) {
            negatives.fetch_add(1, ORDER_1);
        }
    }
    done.store(true, ORDER_2);
}

int main()
{
    int n {0};
    std::cin >> n;
    std::vector<int> v(n, 0);
    for (int& x : v) {
        std::cin >> x;
    }
    long long lo {0};
    long long hi {0};
    std::atomic<int> negatives {0};
    std::atomic<bool> lo_done {false};
    std::atomic<bool> hi_done {false};
    std::thread a {work, std::cref(v), 0, n / 2, std::ref(lo),
                   std::ref(negatives), std::ref(lo_done)};
    std::thread b {work, std::cref(v), n / 2, n, std::ref(hi),
                   std::ref(negatives), std::ref(hi_done)};
    while (!lo_done.load(ORDER_3)) {
    }
    while (!hi_done.load(ORDER_4)) {
    }
    int neg {negatives.load(ORDER_5)};
    std::cout << lo + hi << ' ' << neg << '\n';
    a.join();
    b.join();
}
```

## Alone 2
Form: orders
Sanitizer: thread
Flags: -pthread
Orders:
- 1: rmw relaxed
- 2: store release
- 3: load acquire
Write a program that reads n and then n numbers and prints their squares in input order. Two worker threads take places one at a time from one shared counter that starts at 0. A worker squares the number at the place it took and marks that place done. Main prints each square as soon as its place is done.
Input: one line, n, then n numbers.
Output: one line, n squares separated by spaces.
Limits: 1 ≤ n ≤ 1000; −1000 ≤ each number ≤ 1000.
### Examples
```in
3 1 2 3
```
```out
1 4 9
```
### Reference
```cpp
#include <atomic>
#include <functional>
#include <iostream>
#include <thread>
#include <vector>

void work(const std::vector<int>& v,
          std::vector<long long>& out,
          std::atomic<int>& next,
          std::vector<std::atomic<bool>>& done)
{
    int n {static_cast<int>(v.size())};
    while (true) {
        int i {next.fetch_add(1, ORDER_1)};
        if (i >= n) {
            return;
        }
        out[i] = 1LL * v[i] * v[i];
        done[i].store(true, ORDER_2);
    }
}

int main()
{
    int n {0};
    std::cin >> n;
    std::vector<int> v(n, 0);
    for (int& x : v) {
        std::cin >> x;
    }
    std::vector<long long> out(n, 0);
    std::atomic<int> next {0};
    std::vector<std::atomic<bool>> done(n);
    std::thread a {work, std::cref(v), std::ref(out),
                   std::ref(next), std::ref(done)};
    std::thread b {work, std::cref(v), std::ref(out),
                   std::ref(next), std::ref(done)};
    for (int i {0}; i < n; ++i) {
        while (!done[i].load(ORDER_3)) {
        }
        std::cout << out[i] << ' ';
    }
    std::cout << '\n';
    a.join();
    b.join();
}
```
