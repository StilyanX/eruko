# 32.01
Source: exercism atbash-cipher
Write a function `atbash_cipher::encode(const std::string& text)` that returns the text with each letter swapped and grouped.
Each letter becomes its lower case mirror in the alphabet: `a` and `z` swap, `b` and `y` swap, and so on, whatever the letter's case.
Digits stay as they are, and every other character is dropped.
The characters kept are split into groups of 5, with one space between groups.
Write a function `atbash_cipher::decode(const std::string& text)` that returns the text with each letter swapped back, digits kept and spaces dropped.
Empty text gives empty text.
Limits: 0 ≤ length of text ≤ 1000; text holds letters, digits, spaces and punctuation.
## Solution
```cpp
#pragma once

#include <cctype>
#include <string>

namespace atbash_cipher {

//: Write a function that tests each case in order and gives back the result of the first that holds.
char swap([[char character]])
{
    //:: Give back a digit as it is.
    if ([[std::isdigit(character)]]) {
        return character;
    }
    //:: Give back the letter as far from `z` as the letter is from `a`.
    return [['z' - (std::tolower(character) - 'a')]];
}

//: Write a function that builds a new string from each character of the text.
std::string encode([[const std::string& text]])
{
    //:: Start the result as an empty string.
    std::string result {[[""]]};
    //:: Start the count at zero.
    int count {[[0]]};
    //:: Add each letter or digit swapped, with a space before every 5.
    for (const char character : text) {
        if ([[std::isalnum(character)]]) {
            if (count > 0 && count % 5 == 0) {
                result += ' ';
            }
            result += swap(character);
            ++count;
        }
    }
    //:: Give back the result.
    return [[result]];
}

//: Write a function that builds a new string from each character of the text.
std::string decode([[const std::string& text]])
{
    //:: Start the result as an empty string.
    std::string result {[[""]]};
    //:: Add each character swapped when it is not a space.
    for (const char character : text) {
        if ([[character != ' ']]) {
            result += swap(character);
        }
    }
    //:: Give back the result.
    return [[result]];
}

}  // namespace atbash_cipher
```
