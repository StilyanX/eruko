# 22.04
Source: exercism series
Write a function `series::slice(const std::string& text, int length)` that returns a `std::vector<std::string>` of every run of `length` side-by-side characters of the text, in the order they start.
It throws `std::domain_error` when the length is below 1 or above the length of the text, so empty text always throws.
Limits: 0 ≤ length of text ≤ 1000, -1000 ≤ length ≤ 1000; text holds digits.
## Solution
```cpp
#pragma once

#include <stdexcept>
#include <string>
#include <vector>

namespace series {

//: Write a function that builds a new list one item at a time and gives it back.
std::vector<std::string> slice(const std::string& text,
                               [[int length]])
{
    //:: Throw `std::domain_error` for a length below 1 or above the text's.
    const int size {static_cast<int>(text.size())};
    if ([[length < 1 || length > size]]) {
        throw std::domain_error {"length out of range"};
    }
    //:: Start the result as an empty list.
    std::vector<std::string> result [[{}]];
    //:: Add the part of that length that starts at each index.
    for (int start {0}; start + length <= size; ++start) {
        result.push_back([[text.substr(start, length)]]);
    }
    //:: Give back the result.
    return [[result]];
}

}  // namespace series
```
