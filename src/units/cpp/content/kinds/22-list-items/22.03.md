# 22.03
Source: exercism diamond
Write a function `diamond::rows(char letter)` that returns, as a `std::vector<std::string>`, the rows of a diamond of letters that runs from `A` down to letter and back to `A`.
Say letter is d places after `A`: there are 2d + 1 rows, each 2d + 1 characters wide.
Row k from the top, and row k from the bottom, with k from 0 to d, hold the letter k places after `A` at positions d - k and d + k, counting from 0, and spaces everywhere else.
Limits: letter is an uppercase letter from `A` to `Z`.
## Solution
```cpp
#pragma once

#include <cstdlib>
#include <string>
#include <vector>

namespace diamond {

//: Write a function that builds a new list one item at a time and gives it back.
std::vector<std::string> rows([[char letter]])
{
    //:: Work out the size, 2 times the distance of the letter from `A`, plus 1.
    const int size {[[2 * (letter - 'A') + 1]]};
    //:: Start the result as an empty list.
    std::vector<std::string> result [[{}]];
    //:: For each row, add a row of spaces with the row's letter at its 2 places.
    for (int row {0}; row < size; ++row) {
        const int distance {std::abs(size / 2 - row)};
        std::string line(size, ' ');
        line[distance] = static_cast<char>([[letter - distance]]);
        line[size - 1 - distance] = line[distance];
        result.push_back(line);
    }
    //:: Give back the result.
    return [[result]];
}

}  // namespace diamond
```
