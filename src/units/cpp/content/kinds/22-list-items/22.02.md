# 22.02
Source: exercism protein-translation
Write a function `protein_translation::proteins(std::string rna)` that returns the list of amino acids the text codes for.
Read the text 3 letters at a time, from the start; each group of 3 letters is a codon.
The codons and their amino acids:
AUG Methionine; UUU, UUC Phenylalanine; UUA, UUG Leucine; UCU, UCC, UCA, UCG Serine; UAU, UAC Tyrosine; UGU, UGC Cysteine; UGG Tryptophan.
UAA, UAG and UGA are stop codons: return the list at the first one, and ignore everything after it.
Throw an exception (of any type) at a codon not in this list, or at a last group shorter than 3 letters, when no stop codon comes before it.
The empty text gives the empty list.
Limits: 0 ≤ length of the text ≤ 1000.
## Solution
```cpp
#pragma once

#include <map>
#include <string>
#include <vector>

namespace protein_translation {

//: Write a function that builds a new list one item at a time and gives it back.
std::vector<std::string> proteins([[std::string rna]])
{
    //:: Make the map from each codon to its amino acid, or to STOP.
    const std::map<std::string, std::string> amino_acids {
        {"AUG", [["Methionine"]]},
        {"UUU", "Phenylalanine"}, {"UUC", "Phenylalanine"},
        {"UUA", "Leucine"}, {"UUG", "Leucine"},
        {"UCU", "Serine"}, {"UCC", "Serine"},
        {"UCA", "Serine"}, {"UCG", "Serine"},
        {"UAU", "Tyrosine"}, {"UAC", "Tyrosine"},
        {"UGU", "Cysteine"}, {"UGC", "Cysteine"},
        {"UGG", "Tryptophan"},
        {"UAA", "STOP"}, {"UAG", "STOP"}, {"UGA", "STOP"}};
    //:: Start the result as an empty list.
    [[std::vector<std::string>]] result {};
    //:: For each codon in order, stop at STOP, else add its amino acid, where `at` throws for a codon the map lacks.
    for (std::size_t pos {0}; pos < rna.size(); pos += 3) {
        const std::string codon {rna.substr(pos, 3)};
        const std::string amino_acid {amino_acids.at(codon)};
        if ([[amino_acid == "STOP"]]) {
            break;
        }
        result.push_back(amino_acid);
    }
    //:: Give back the result.
    return [[result]];
}

}  // namespace protein_translation
```
