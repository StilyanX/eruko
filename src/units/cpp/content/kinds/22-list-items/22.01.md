# 22.01
Source: exercism secret-handshake
Write a function `secret_handshake::commands(int value)` that returns a `std::vector<std::string>` of actions read from the bits of value.
The bit for 1 adds `wink`, the bit for 2 `double blink`, the bit for 4 `close your eyes` and the bit for 8 `jump`, in that order.
When the bit for 16 is set, the actions come in the reverse order.
A value with none of the bits for 1 to 8 set gives an empty list.
Limits: 0 ≤ value ≤ 31.
## Solution
```cpp
#pragma once

#include <algorithm>
#include <string>
#include <vector>

namespace secret_handshake {

//: Write a function that builds a new list one item at a time and gives it back.
std::vector<std::string> commands([[int value]])
{
    //:: Make the list of the 4 actions, the one for the lowest bit first.
    const std::vector<std::string> actions {
        [["wink"]], "double blink", "close your eyes", "jump"};
    //:: Start the result as an empty list.
    std::vector<std::string> result [[{}]];
    //:: For each of the 4 bits, lowest first, add its action when the bit is 1.
    for (int bit {0}; bit < 4; ++bit) {
        if ([[(value >> bit) % 2 == 1]]) {
            result.push_back(actions[bit]);
        }
    }
    //:: Reverse the result when the bit for 16 is 1.
    if ([[(value >> 4) % 2 == 1]]) {
        std::ranges::reverse(result);
    }
    //:: Give back the result.
    return [[result]];
}

}  // namespace secret_handshake
```
