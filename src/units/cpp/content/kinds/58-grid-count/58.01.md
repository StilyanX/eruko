# 58.01
Source: exercism flower-field
Write a function `flower_field::annotate(const std::vector<std::string>& garden)` that returns the garden with a number in each empty square.
The garden is a rectangle of rows of the same length; each square is a space (empty) or `*` (a flower).
In the result each flower stays, and each empty square holds the number of flowers in the up to 8 squares around it, side by side or corner to corner, as a digit; an empty square with no flower around it stays a space.
No rows give no rows, and empty rows stay empty.
Limits: 0 ≤ rows ≤ 100; 0 ≤ length of each row ≤ 100.
## Solution
```cpp
#pragma once

#include <string>
#include <vector>

namespace flower_field {

//: Write a function that gives back a value worked out in one step.
bool is_flower(const std::vector<std::string>& garden,
               [[int r, int c]])
{
    //:: Give back whether the square is in the garden and holds a flower.
    return r >= 0 && r < std::ssize(garden) && c >= 0
           && c < std::ssize(garden[r]) && [[garden[r][c] == '*']];
}

//: Write a function that counts the items that pass a test and gives back the count.
int flowers_around(const std::vector<std::string>& garden,
                   [[int row, int column]])
{
    //:: Start the count at zero.
    int count {[[0]]};
    //:: Add one for each flower in the 3 rows and 3 columns around it.
    for (int r {row - 1}; r <= row + 1; ++r) {
        for (int c {column - 1}; c <= column + 1; ++c) {
            if ([[is_flower(garden, r, c)]]) {
                ++count;
            }
        }
    }
    //:: Give back the count.
    return [[count]];
}

//: Write a function that builds a new grid from the answer for each square of the old one.
std::vector<std::string> annotate(
    [[const std::vector<std::string>& garden]])
{
    //:: Start the result as a copy of the garden.
    std::vector<std::string> result {[[garden]]};
    //:: Put the count of flowers around each empty square, when above 0.
    for (int r {0}; r < std::ssize(garden); ++r) {
        for (int c {0}; c < std::ssize(garden[r]); ++c) {
            const int count {flowers_around(garden, r, c)};
            if (garden[r][c] == ' ' && [[count > 0]]) {
                result[r][c] = '0' + count;
            }
        }
    }
    //:: Give back the result.
    return [[result]];
}

}  // namespace flower_field
```
