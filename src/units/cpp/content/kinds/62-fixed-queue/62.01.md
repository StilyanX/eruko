# 62.01
Source: exercism circular-buffer
Write a class `circular_buffer::circular_buffer<T>` whose objects hold at most a fixed number of items of type T, given to its constructor as a `std::size_t`.
`read()` removes the oldest item and returns it; when there is none it throws `std::domain_error`.
`write(item)` adds the item as the newest; when the buffer is full it throws `std::domain_error`.
`overwrite(item)` adds the item as the newest; when the buffer is full it first removes the oldest item.
`clear()` removes every item.
T may be `int` or `std::string`.
Limits: 1 ≤ capacity ≤ 3.
## Solution
```cpp
#pragma once

#include <cstddef>
#include <deque>
#include <stdexcept>

namespace circular_buffer {

//: Write a class that keeps its data in private members.
template <typename T>
class circular_buffer {
    std::deque<T> items_ [[{}]];
    std::size_t capacity_ {0};
public:
    //: Write a constructor that sets the data.
    explicit circular_buffer(std::size_t capacity)
        : capacity_ {[[capacity]]}
    {
    }
    //: Write a member function that gives back the oldest item and removes it, or throws when there is none.
    T read()
    {
        if ([[items_.empty()]]) {
            throw std::domain_error {"the buffer is empty"};
        }
        T item {items_.front()};
        items_.pop_front();
        return item;
    }
    //: Write a member function that adds an item at the end, or throws when the buffer is full.
    void write(const T& item)
    {
        if ([[items_.size() == capacity_]]) {
            throw std::domain_error {"the buffer is full"};
        }
        items_.push_back(item);
    }
    //: Write a member function that adds an item at the end, removing the oldest first when the buffer is full.
    void overwrite(const T& item)
    {
        if ([[items_.size() == capacity_]]) {
            items_.pop_front();
        }
        items_.push_back(item);
    }
    //: Write a member function that removes every item.
    void clear()
    {
        items_.[[clear()]];
    }
};

}  // namespace circular_buffer
```
