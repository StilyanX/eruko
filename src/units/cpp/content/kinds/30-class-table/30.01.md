# 30.01
Source: exercism allergies
Write a class `allergies::allergy_test` whose constructor takes an `unsigned int` score.
Each of these names has a value: eggs 1, peanuts 2, shellfish 4, strawberries 8, tomatoes 16, chocolate 32, pollen 64, cats 128.
The score is a sum of different powers of 2, and a name is in the score when its value is one of them.
Powers of 2 from 256 up belong to no name.
`is_allergic_to(const std::string& name) const` returns whether the name is in the score.
`get_allergies() const` returns a `std::unordered_set<std::string>` of every name in the score.
Limits: 0 ≤ score ≤ 1023; each name given is one of the 8 above.
## Solution
```cpp
#pragma once

#include <map>
#include <string>
#include <unordered_set>

namespace allergies {

//: Make a table of fixed values.
const [[std::map<std::string, unsigned int>]] values {
    {"eggs", 1}, {"peanuts", 2}, {"shellfish", 4},
    {"strawberries", 8}, {"tomatoes", 16}, {"chocolate", 32},
    {"pollen", 64}, {"cats", 128}};

//: Write a class that keeps its data in private members.
class allergy_test {
    unsigned int score {[[0]]};
public:
    //: Write a constructor that sets the data.
    explicit allergy_test([[unsigned int value]]) : score {value}
    {
    }
    //: Write a member function that gives back a value worked out in one step.
    bool is_allergic_to([[const std::string& name]]) const
    {
        //:: Give back whether the score holds the value of the name.
        return [[score / values.at(name) % 2 == 1]];
    }
    //: Write a member function that gives back the items that pass a test.
    [[std::unordered_set<std::string>]] get_allergies() const
    {
        //:: Start the result as an empty set.
        std::unordered_set<std::string> result [[{}]];
        //:: Add each name whose value the score holds.
        for (const auto& [name, value] : values) {
            if ([[score / value % 2 == 1]]) {
                result.insert(name);
            }
        }
        //:: Give back the result.
        return [[result]];
    }
};

}  // namespace allergies
```
