# 43.01
Source: exercism binary-search
Write a function `binary_search::find(const std::vector<int>& data, int value)` that returns the index, as a `std::size_t`, at which the value stands in the list.
The list is sorted from smallest to largest and holds no number twice.
When the value is not in the list, or the list is empty, it throws `std::domain_error`.
Limits: 0 ≤ n ≤ 13, where n is the length of the list.
## Solution
```cpp
#pragma once

#include <cstddef>
#include <stdexcept>
#include <vector>

namespace binary_search {

//: Write a function that halves the range that can hold the value until it finds it.
std::size_t find([[const std::vector<int>& data]], int value)
{
    //:: Start the range as the whole list.
    std::size_t low {0};
    std::size_t high {[[data.size()]]};
    //:: Give back the middle index when it holds the value, else keep the half that can hold it.
    while (low < high) {
        const std::size_t middle {low + (high - low) / 2};
        if (data[middle] == value) {
            return middle;
        } else if ([[data[middle] < value]]) {
            low = middle + 1;
        } else {
            high = middle;
        }
    }
    //:: Throw `std::domain_error` when the range is empty.
    throw [[std::domain_error]] {"value not in the list"};
}

}  // namespace binary_search
```
