# 18.03
Source: exercism dnd-character
Write a function `dnd_character::modifier(int score)` that returns `score - 10` halved and rounded down (3 gives -4, 11 gives 0).
Write a function `dnd_character::ability()` that rolls 4 six-sided dice at random and returns the sum of the 3 largest.
Write a struct `dnd_character::Character` with the `int` members `strength`, `dexterity`, `constitution`, `intelligence`, `wisdom` and `charisma`, each set by `ability()`, and `hitpoints`, set to 10 plus the modifier of `constitution`.
Limits: 3 ≤ score ≤ 18.
## Solution
```cpp
#pragma once

#include <algorithm>
#include <random>

namespace dnd_character {

//: Write a function that gives back a value worked out in one step.
inline int modifier([[int score]])
{
    //:: Halve the score less 10, rounding down.
    const int above {score - 10};
    return [[above / 2 - (above % 2 < 0 ? 1 : 0)]];
}

//: Write a function that adds up a sequence and gives back the total.
inline [[int]] ability()
{
    static std::mt19937 engine {std::random_device {}()};
    std::uniform_int_distribution<int> die {1, 6};
    //:: Start the total at zero.
    int sum {[[0]]};
    int lowest {6};
    //:: Add each of the 4 rolls to the total, keeping the lowest.
    for (int roll {0}; roll < 4; ++roll) {
        const int value {die(engine)};
        sum += [[value]];
        lowest = std::min(lowest, value);
    }
    //:: Give back the total less the lowest roll.
    return [[sum - lowest]];
}
//:: Set each ability by `ability()`, and the hit points from the constitution.
struct Character {
    int strength {ability()};
    int dexterity {ability()};
    int constitution {ability()};
    int intelligence {ability()};
    int wisdom {ability()};
    int charisma {ability()};
    int hitpoints {[[10 + modifier(constitution)]]};
};

}  // namespace dnd_character
```
