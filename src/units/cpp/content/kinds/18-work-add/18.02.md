# 18.02
Source: written
Write a function `odd::nth(int n)` that returns the n-th odd number, counting 1 as the first.
Write a function `odd::total(int count)` that returns the sum of `nth(n)` for each n from 1 to count.
Limits: 1 ≤ n ≤ 1000; 0 ≤ count ≤ 1000.
## Solution
```cpp
#pragma once

namespace odd {

//: Write a function that gives back a value worked out in one step.
int nth([[int n]])
{
    //:: Give back 2 times n, less 1.
    return [[2 * n - 1]];
}

//: Write a function that adds up a sequence and gives back the total.
[[int]] total(int count)
{
    //:: Start the total at zero.
    int sum {[[0]]};
    //:: Add the n-th odd number for each n from 1 to the count to the total.
    for (int n {1}; n <= count; ++n) {
        sum += [[nth(n)]];
    }
    //:: Give back the total.
    return [[sum]];
}

}  // namespace odd
```
## Slow
```cpp
#pragma once

namespace odd {

int nth(int n)
{
    int found {0};
    int number {0};
    while (found < n) {
        ++number;
        if (number % 2 == 1) {
            ++found;
        }
    }
    return number;
}

int total(int count)
{
    int sum {0};
    for (int number {1}; number <= 2 * count; ++number) {
        if (number % 2 == 1) {
            sum += number;
        }
    }
    return sum;
}

}  // namespace odd
```
