# 18.01
Source: exercism grains
Write a function `grains::square(int which)` that returns 2 to the power of `which - 1`, as an `unsigned long long`.
Write a function `grains::total()` that returns the sum of `square(which)` for each `which` from 1 to 64.
Limits: 1 ≤ which ≤ 64.
## Solution
```cpp
#pragma once

namespace grains {

//: Write a function that gives back a value worked out in one step.
unsigned long long square([[int which]])
{
    //:: Give back 1 doubled once for each square before this one.
    return [[1ULL << (which - 1)]];
}

//: Write a function that adds up a sequence and gives back the total.
[[unsigned long long]] total()
{
    //:: Start the total at zero.
    unsigned long long sum {[[0]]};
    //:: Add the value of each square from 1 to 64 to the total.
    for (int which {1}; which <= 64; ++which) {
        sum += [[square(which)]];
    }
    //:: Give back the total.
    return [[sum]];
}

}  // namespace grains
```
