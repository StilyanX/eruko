# 24.01
Source: exercism triangle
Write a function `triangle::kind(double a, double b, double c)` that returns the kind of the triangle with sides a, b and c.
The header also defines the result type, `enum class triangle::flavor { equilateral, isosceles, scalene }`.
It returns `equilateral` when all 3 sides are equal, `isosceles` when exactly 2 are equal, and `scalene` when no 2 are equal.
It throws `std::domain_error` when a side is 0 or less, or when one side is longer than the other 2 together.
Limits: none
## Solution
```cpp
#pragma once

#include <stdexcept>

namespace triangle {

//: Name each possible value in an `enum class`.
enum class flavor { [[equilateral]], isosceles, scalene };

//: Write a function that tests each case in order and gives back the result of the first that holds.
flavor kind([[double a, double b, double c]])
{
    //:: Stop with an error when a side is 0 or less, or longer than the other 2 together.
    if (a <= 0 || b <= 0 || c <= 0 || a + b < c || a + c < b
        || [[b + c < a]]) {
        throw std::domain_error {"not a triangle"};
    }
    //:: Give back equilateral when all 3 sides are equal, isosceles when 2 are, else scalene.
    if (a == b && b == c) {
        return flavor::equilateral;
    } else if ([[a == b || b == c || a == c]]) {
        return flavor::isosceles;
    } else {
        return flavor::scalene;
    }
}

}  // namespace triangle
```
