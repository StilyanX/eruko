# 49.01
Source: exercism pig-latin
Write a function `pig_latin::translate(const std::string& phrase)` that returns, as a `std::string`, phrase with each word changed as follows, the words kept in order with one space between 2 words.
The vowels are `a`, `e`, `i`, `o` and `u`.
A word that starts with a vowel, `xr` or `yt` gets `ay` added at its end.
Any other word has its letters before the first vowel moved to its end, then `ay` added.
In such a word, a `u` right after a `q` moves with the `q`, and a `y` after the first letter counts as a vowel.
Limits: phrase holds one or more words of lowercase letters, split by single spaces.
## Solution
```cpp
#pragma once

#include <cstddef>
#include <sstream>
#include <string>
#include <string_view>

namespace pig_latin {

//: Write a function that finds the first item that passes a test and gives back its position.
std::size_t split_point([[const std::string& word]])
{
    //:: Give back 0 when the word starts with a vowel, `xr` or `yt`.
    const std::string_view vowels {"aeiou"};
    if (vowels.contains(word[0]) || word.starts_with("xr")
        || [[word.starts_with("yt")]]) {
        return 0;
    }
    //:: Give back the index of the first vowel or `y` after the first letter, counting the `u` of `qu` with the letters before it.
    for (std::size_t index {1}; index < word.size(); ++index) {
        if (word[index] == 'u' && word[index - 1] == 'q') {
            return index + 1;
        }
        if (vowels.contains(word[index])
            || [[word[index] == 'y']]) {
            return index;
        }
    }
    return word.size();
}

//: Write a function that builds a new string one piece at a time and gives it back.
std::string translate([[const std::string& phrase]])
{
    //:: Start the result as an empty string.
    std::string result {[[""]]};
    //:: For each word, add a space before all but the first, then the word from its split point, the letters before it, and `ay`.
    std::istringstream words {phrase};
    std::string word {};
    while (words >> word) {
        if (!result.empty()) {
            result += ' ';
        }
        const std::size_t split {split_point(word)};
        result += word.substr(split);
        result += [[word.substr(0, split)]] + "ay";
    }
    //:: Give back the result.
    return [[result]];
}

}  // namespace pig_latin
```
