# 6.12
Write a program that reads n integers and prints the sum of the last 3.

Input: line 1, n; line 2, n integers separated by spaces.
Output: one line, one integer.
Limits: 3 ≤ n ≤ 100, -1000 ≤ each integer ≤ 1000.

## Examples
```in
5
1 2 3 4 5
```
```out
12
```
## Solution
```cpp
#include <iostream>
#include <print>

int main()
{
    //: Read how many numbers follow.
    int n {0};
    std::cin >> [[n]];
    //: Start the total at zero.
    int total {[[0]]};
    //: For each index from 0 to n - 1, read a number and add to the total.
    for (int index {0}; index < [[n]]; ++index) {
        int number {0};
        std::cin >> number;
        //:: Add the number when it is one of the last 3.
        if ([[index >= n - 3]]) {
            total += number;
        }
    }
    //: Print the total.
    std::println("{}", [[total]]);
}
```
## Slow

```cpp
#include <iostream>
#include <print>
#include <vector>

int main()
{
    int n {0};
    std::cin >> n;
    std::vector<int> numbers(n);
    for (int& x : numbers) {
        std::cin >> x;
    }
    int total {0};
    for (int place {0}; place < n; ++place) {
        int after {0};
        for (int other {place + 1}; other < n; ++other) {
            ++after;
        }
        if (after < 3) {
            total += numbers[place];
        }
    }
    std::println("{}", total);
}
```
