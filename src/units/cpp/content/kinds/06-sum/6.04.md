# 6.04
Write a program that reads n integers and prints the sum of their last digits.

Input: line 1, n; line 2, n integers separated by spaces.
Output: one line, one integer.
Limits: 1 ≤ n ≤ 100, 0 ≤ each integer ≤ 1000.

## Examples
```in
3
25 7 130
```
```out
12
```
## Solution
```cpp
#include <iostream>
#include <print>

int main()
{
    //: Read how many numbers follow.
    int n {0};
    std::cin >> [[n]];
    //: Start the total at zero.
    int total {[[0]]};
    //: For each index from 0 to n - 1, read a number and add to the total.
    for (int index {0}; index < [[n]]; ++index) {
        int number {0};
        std::cin >> number;
        //:: Add the last digit of the number to the total.
        total += [[number % 10]];
    }
    //: Print the total.
    std::println("{}", [[total]]);
}
```
## Slow
```cpp
#include <algorithm>
#include <iostream>
#include <print>
#include <string>
#include <vector>

int main()
{
    int n {0};
    std::cin >> n;
    std::vector<int> numbers(n);
    for (int& x : numbers) {
        std::cin >> x;
    }
    auto part = [](int v) { return v % 10; };
    int total {0};
    for (int v {0}; v <= 1000; ++v) {
        int times = static_cast<int>(std::ranges::count(numbers, v));
        for (int t {0}; t < times; ++t) {
            total += static_cast<int>(part(v));
        }
    }
    std::println("{}", total);
}
```
