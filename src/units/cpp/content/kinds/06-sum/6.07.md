# 6.07
Write a program that reads n integers and prints their sum, with each integer greater than 100 counted as 100.

Input: line 1, n; line 2, n integers separated by spaces.
Output: one line, one integer.
Limits: 1 ≤ n ≤ 100, -1000 ≤ each integer ≤ 1000.

## Examples
```in
4
50 250 100 -20
```
```out
230
```
## Solution
```cpp
#include <iostream>
#include <print>

int main()
{
    //: Read how many numbers follow.
    int n {0};
    std::cin >> [[n]];
    //: Start the total at zero.
    int total {[[0]]};
    //: For each index from 0 to n - 1, read a number and add to the total.
    for (int index {0}; index < [[n]]; ++index) {
        int number {0};
        std::cin >> number;
        //:: Add the number, or 100 when the number is greater than 100.
        if ([[number > 100]]) {
            total += 100;
        } else {
            total += number;
        }
    }
    //: Print the total.
    std::println("{}", [[total]]);
}
```
## Slow
```cpp
#include <algorithm>
#include <iostream>
#include <print>
#include <string>
#include <vector>

int main()
{
    int n {0};
    std::cin >> n;
    std::vector<int> numbers(n);
    for (int& x : numbers) {
        std::cin >> x;
    }
    auto part = [](int v) { return v > 100 ? 100 : v; };
    int total {0};
    for (int v {-1000}; v <= 1000; ++v) {
        int times = static_cast<int>(std::ranges::count(numbers, v));
        for (int t {0}; t < times; ++t) {
            total += static_cast<int>(part(v));
        }
    }
    std::println("{}", total);
}
```
