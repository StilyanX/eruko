# 6.10
Write a program that reads n integers and prints how many digits they hold in all.

Input: line 1, n; line 2, n integers separated by spaces.
Output: one line, one integer.
Limits: 1 ≤ n ≤ 100, 1 ≤ each integer ≤ 1000.

## Examples
```in
4
7 42 100 1000
```
```out
10
```
## Solution
```cpp
#include <iostream>
#include <print>

int main()
{
    //: Read how many numbers follow.
    int n {0};
    std::cin >> [[n]];
    //: Start the total at zero.
    int total {[[0]]};
    //: For each index from 0 to n - 1, read a number and add to the total.
    for (int index {0}; index < [[n]]; ++index) {
        int number {0};
        std::cin >> number;
        //:: Add the number of digits of the number.
        if ([[number == 1000]]) {
            total += 4;
        } else if (number >= 100) {
            total += 3;
        } else if (number >= 10) {
            total += 2;
        } else {
            total += 1;
        }
    }
    //: Print the total.
    std::println("{}", [[total]]);
}
```
## Slow
```cpp
#include <algorithm>
#include <iostream>
#include <print>
#include <string>
#include <vector>

int main()
{
    int n {0};
    std::cin >> n;
    std::vector<int> numbers(n);
    for (int& x : numbers) {
        std::cin >> x;
    }
    auto part = [](int v) { return std::to_string(v).size(); };
    int total {0};
    for (int v {1}; v <= 1000; ++v) {
        int times = static_cast<int>(std::ranges::count(numbers, v));
        for (int t {0}; t < times; ++t) {
            total += static_cast<int>(part(v));
        }
    }
    std::println("{}", total);
}
```
