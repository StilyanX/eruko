# 6.11
Write a program that reads n integers and prints the first, minus the second, plus the third, and so on.

Input: line 1, n; line 2, n integers separated by spaces.
Output: one line, one integer.
Limits: 1 ≤ n ≤ 100, -1000 ≤ each integer ≤ 1000.

## Examples
```in
4
5 2 7 -1
```
```out
11
```
## Solution
```cpp
#include <iostream>
#include <print>

int main()
{
    //: Read how many numbers follow.
    int n {0};
    std::cin >> [[n]];
    //: Start the total at zero.
    int total {[[0]]};
    //: For each index from 0 to n - 1, read a number and add to the total.
    for (int index {0}; index < [[n]]; ++index) {
        int number {0};
        std::cin >> number;
        //:: Add the number at an even index, else take it away.
        if ([[index % 2 == 0]]) {
            total += number;
        } else {
            total += -number;
        }
    }
    //: Print the total.
    std::println("{}", [[total]]);
}
```
## Slow
```cpp
#include <iostream>
#include <print>
#include <vector>

int main()
{
    int n {0};
    std::cin >> n;
    std::vector<int> numbers(n);
    for (int& x : numbers) {
        std::cin >> x;
    }
    int plus {0};
    int minus {0};
    for (int place {0}; place < n; ++place) {
        for (int other {0}; other < n; ++other) {
            if (other == place && place % 2 == 0) {
                plus += numbers[other];
            }
            if (other == place && place % 2 == 1) {
                minus += numbers[other];
            }
        }
    }
    std::println("{}", plus - minus);
}
```
