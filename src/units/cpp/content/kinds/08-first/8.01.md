# 8.01
Write a program that reads n integers and prints the position of the first even one.
Positions count from 1.

Input: line 1, n; line 2, n integers separated by spaces.
Output: one line, one integer, or -1 when no integer is even.
Limits: 1 ≤ n ≤ 100, -1000 ≤ each integer ≤ 1000.

## Examples
```in
5
3 7 4 8 1
```
```out
3
```
```in
2
1 3
```
```out
-1
```
## Solution
```cpp
#include <iostream>
#include <print>

int main()
{
    //: Read how many numbers follow.
    int n {0};
    std::cin >> [[n]];
    //: Start the position at -1, the mark for none found.
    int position {[[-1]]};
    //: For each index from 0 to n - 1, read a number and test it.
    for (int index {0}; index < [[n]]; ++index) {
        int number {0};
        std::cin >> number;
        //:: Keep the position of the first even number.
        if (position == -1 && [[number % 2 == 0]]) {
            position = index + 1;
        }
    }
    //: Print the position.
    std::println("{}", [[position]]);
}
```
## Slow
```cpp
#include <algorithm>
#include <iostream>
#include <print>
#include <string>
#include <vector>

int main()
{
    int n {0};
    std::cin >> n;
    std::vector<int> numbers(n);
    for (int& x : numbers) {
        std::cin >> x;
    }
    auto passes = [](int v) { return v % 2 == 0; };
    int answer {-1};
    for (int place {n}; place >= 1; --place) {
        bool earlier {false};
        for (int before {1}; before < place; ++before) {
            if (passes(numbers[before - 1])) {
                earlier = true;
            }
        }
        if (passes(numbers[place - 1]) && !earlier) {
            answer = place;
        }
    }
    std::println("{}", answer);
}
```
