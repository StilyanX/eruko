# 8.04
Write a program that reads n integers and prints the position of the first one that 7 divides.
Positions count from 1.

Input: line 1, n; line 2, n integers separated by spaces.
Output: one line, one integer, or -1 when 7 divides none of them.
Limits: 1 ≤ n ≤ 100, 1 ≤ each integer ≤ 1000.

## Examples
```in
4
5 13 21 14
```
```out
3
```
## Solution
```cpp
#include <iostream>
#include <print>

int main()
{
    //: Read how many numbers follow.
    int n {0};
    std::cin >> [[n]];
    //: Start the position at -1, the mark for none found.
    int position {[[-1]]};
    //: For each index from 0 to n - 1, read a number and test it.
    for (int index {0}; index < [[n]]; ++index) {
        int number {0};
        std::cin >> number;
        //:: Keep the position of the first number that 7 divides.
        if (position == -1 && [[number % 7 == 0]]) {
            position = index + 1;
        }
    }
    //: Print the position.
    std::println("{}", [[position]]);
}
```
## Slow
```cpp
#include <algorithm>
#include <iostream>
#include <print>
#include <string>
#include <vector>

int main()
{
    int n {0};
    std::cin >> n;
    std::vector<int> numbers(n);
    for (int& x : numbers) {
        std::cin >> x;
    }
    auto passes = [](int v) { return v % 7 == 0; };
    int answer {-1};
    for (int place {n}; place >= 1; --place) {
        bool earlier {false};
        for (int before {1}; before < place; ++before) {
            if (passes(numbers[before - 1])) {
                earlier = true;
            }
        }
        if (passes(numbers[place - 1]) && !earlier) {
            answer = place;
        }
    }
    std::println("{}", answer);
}
```
