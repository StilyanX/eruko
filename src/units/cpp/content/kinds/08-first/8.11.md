# 8.11
Write a program that reads n integers and prints the position of the first one smaller than its position.
Positions count from 1.

Input: line 1, n; line 2, n integers separated by spaces.
Output: one line, one integer, or -1 when no integer is smaller than its position.
Limits: 1 ≤ n ≤ 100, -1000 ≤ each integer ≤ 1000.

## Examples
```in
4
5 7 2 9
```
```out
3
```
```in
3
1 2 3
```
```out
-1
```
## Solution
```cpp
#include <iostream>
#include <print>

int main()
{
    //: Read how many numbers follow.
    int n {0};
    std::cin >> [[n]];
    //: Start the position at -1, the mark for none found.
    int position {[[-1]]};
    //: For each index from 0 to n - 1, read a number and test it.
    for (int index {0}; index < [[n]]; ++index) {
        int number {0};
        std::cin >> number;
        //:: Keep the position of the first number smaller than its position.
        if (position == -1 && [[number < index + 1]]) {
            position = index + 1;
        }
    }
    //: Print the position.
    std::println("{}", [[position]]);
}
```
## Slow
```cpp
#include <iostream>
#include <print>
#include <vector>

int main()
{
    int n {0};
    std::cin >> n;
    std::vector<int> numbers(n + 1);
    for (int place {1}; place <= n; ++place) {
        std::cin >> numbers[place];
    }
    auto passes = [&](int place) { return numbers[place] < place; };
    int answer {-1};
    for (int place {n}; place >= 1; --place) {
        bool earlier {false};
        for (int before {1}; before < place; ++before) {
            if (passes(before)) {
                earlier = true;
            }
        }
        if (passes(place) && !earlier) {
            answer = place;
        }
    }
    std::println("{}", answer);
}
```
