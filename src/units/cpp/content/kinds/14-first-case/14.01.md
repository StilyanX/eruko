# 14.01
Source: exercism leap
Write a function `leap::is_leap_year(int year)` that returns `true` when the year is a leap year, else `false`.
A year is a leap year when 4 divides it.
A year that 100 divides is a leap year only when 400 divides it too.
Limits: 1 ≤ year ≤ 9999.
## Solution
```cpp
#pragma once

namespace leap {

//: Write a function that tests each case in order and gives back the result of the first that holds.
bool is_leap_year([[int year]])
{
    //:: Give back whether 400 divides a year that 100 divides.
    if ([[year % 100 == 0]]) {
        return year % 400 == 0;
    }
    //:: Give back whether 4 divides any other year.
    return [[year % 4 == 0]];
}

}  // namespace leap
```
