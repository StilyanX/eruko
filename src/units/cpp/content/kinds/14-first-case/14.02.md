# 14.02
Source: exercism darts
Write a function `darts::score(float x, float y)` that returns the score of the point (x, y).
The score is 10 when the point's distance from (0, 0) is at most 1, 5 when it is at most 5, 1 when it is at most 10, else 0.
Limits: -20 ≤ x ≤ 20, -20 ≤ y ≤ 20.
## Solution
```cpp
#pragma once

namespace darts {

//: Write a function that tests each case in order and gives back the result of the first that holds.
int score([[float x, float y]])
{
    //:: Work out the square of the distance from (0, 0).
    const float square {[[x * x + y * y]]};
    //:: Give back the score for the band of the distance.
    if ([[square <= 1]]) {
        return 10;
    } else if (square <= 25) {
        return 5;
    } else if (square <= 100) {
        return 1;
    } else {
        return 0;
    }
}

}  // namespace darts
```
