# 2.08
Write a program that reads a line of text and prints how many rows of 10 characters it needs.

Input: one line of text, which may hold spaces.
Output: one line, one integer, 0 when the text is empty.
Limits: the text holds 0 to 100 characters.

## Examples
```in
the quick brown fox
```
```out
2
```
## Solution
```cpp
#include <iostream>
#include <print>
#include <string>

int main()
{
    //: Read the line.
    std::string line {};
    std::getline(std::cin, [[line]]);
    //: Print the value.
    std::println("{}", [[(line.size() + 9) / 10]]);
}
```
## Slow
```cpp
#include <iostream>
#include <print>
#include <string>

int main()
{
    std::string line {};
    std::getline(std::cin, line);
    int rows {0};
    while (!line.empty()) {
        line.erase(0, 10);
        ++rows;
    }
    std::println("{}", rows);
}
```
