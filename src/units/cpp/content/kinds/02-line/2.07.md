# 2.07
Write a program that reads a line of text and prints the number of characters in 3 copies of it.
The copies stand in a row, with one space between each 2.

Input: one line of text, which may hold spaces.
Output: one line, one integer.
Limits: the text holds 0 to 100 characters.

## Examples
```in
ab
```
```out
8
```
## Solution
```cpp
#include <iostream>
#include <print>
#include <string>

int main()
{
    //: Read the line.
    std::string line {};
    std::getline(std::cin, [[line]]);
    //: Print the value.
    std::println("{}", [[3 * line.size() + 2]]);
}
```
