# 2.01
Write a program that reads a line of text and prints it between square brackets.

Input: one line of text, which may hold spaces.
Output: one line.
Limits: the text holds 0 to 100 characters.

## Examples
```in
to be or not
```
```out
[to be or not]
```
## Solution
```cpp
#include <iostream>
#include <print>
#include <string>

int main()
{
    //: Read the line.
    std::string line {};
    std::getline(std::cin, [[line]]);
    //: Print the value.
    std::println("[{}]", [[line]]);
}
```
## Slow
```cpp
#include <iostream>
#include <print>
#include <string>

int main()
{
    std::string line {};
    std::getline(std::cin, line);
    std::string result {"["};
    for (const char character : line) {
        result += character;
    }
    result += ']';
    std::println("{}", result);
}
```
