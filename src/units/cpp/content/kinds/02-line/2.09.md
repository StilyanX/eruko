# 2.09
Write a program that reads a line and prints the remainder of its number of characters divided by 3.

Input: one line of text, which may hold spaces.
Output: one line, one integer.
Limits: the text holds 0 to 100 characters.

## Examples
```in
hello
```
```out
2
```
```in
abc def
```
```out
1
```
## Solution
```cpp
#include <iostream>
#include <print>
#include <string>

int main()
{
    //: Read the line.
    std::string line {};
    std::getline(std::cin, [[line]]);
    //: Print the value.
    std::println("{}", [[line.size() % 3]]);
}
```
## Slow
```cpp
#include <iostream>
#include <print>
#include <string>

int main()
{
    std::string line {};
    std::getline(std::cin, line);
    int rest {0};
    while (!line.empty()) {
        line.pop_back();
        rest = rest == 2 ? 0 : rest + 1;
    }
    std::println("{}", rest);
}
```
