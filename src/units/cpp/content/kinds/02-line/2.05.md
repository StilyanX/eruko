# 2.05
Write a program that reads a line of text and prints Hello, a comma, a space, the text, then !.

Input: one line of text, which may hold spaces.
Output: one line.
Limits: the text holds 1 to 50 characters.

## Examples
```in
world
```
```out
Hello, world!
```
```in
big sky
```
```out
Hello, big sky!
```
## Solution
```cpp
#include <iostream>
#include <print>
#include <string>

int main()
{
    //: Read the line.
    std::string line {};
    std::getline(std::cin, [[line]]);
    //: Print the value.
    std::println("Hello, {}!", [[line]]);
}
```
## Slow
```cpp
#include <iostream>
#include <print>
#include <string>

int main()
{
    std::string line {};
    std::getline(std::cin, line);
    std::string result {"Hello, "};
    for (const char character : line) {
        result += character;
    }
    result += '!';
    std::println("{}", result);
}
```
