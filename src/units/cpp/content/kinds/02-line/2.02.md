# 2.02
Write a program that reads a line of text and prints 100 minus its number of characters.

Input: one line of text, which may hold spaces.
Output: one line, one integer.
Limits: the text holds 0 to 100 characters.

## Examples
```in
hello world
```
```out
89
```
## Solution
```cpp
#include <iostream>
#include <print>
#include <string>

int main()
{
    //: Read the line.
    std::string line {};
    std::getline(std::cin, [[line]]);
    //: Print the value.
    std::println("{}", [[100 - line.size()]]);
}
```
## Slow
```cpp
#include <iostream>
#include <print>
#include <string>

int main()
{
    std::string line {};
    std::getline(std::cin, line);
    int missing {0};
    while (line.size() < 100) {
        line += ' ';
        ++missing;
    }
    std::println("{}", missing);
}
```
