# 2.06
Write a program that reads a line of text and prints it followed by its number of characters.

Input: one line of text, which may hold spaces.
Output: one line, the text, a space, then the number.
Limits: the text holds 1 to 100 characters.

## Examples
```in
hello
```
```out
hello 5
```
```in
a b c
```
```out
a b c 5
```
## Solution
```cpp
#include <iostream>
#include <print>
#include <string>

int main()
{
    //: Read the line.
    std::string line {};
    std::getline(std::cin, [[line]]);
    //: Print the value.
    std::println("{} {}", line, [[line.size()]]);
}
```
## Slow
```cpp
#include <iostream>
#include <print>
#include <string>

int main()
{
    std::string line {};
    std::getline(std::cin, line);
    std::string rest {line};
    int length {0};
    while (!rest.empty()) {
        rest.pop_back();
        ++length;
    }
    std::println("{} {}", line, length);
}
```
