# 2.11
Write a program that reads a line of text and prints how many characters lie between its first character and its last.

Input: one line of text, which may hold spaces.
Output: one line, one integer.
Limits: the text holds 2 to 100 characters.

## Examples
```in
hello
```
```out
3
```
```in
a b
```
```out
1
```
## Solution
```cpp
#include <iostream>
#include <print>
#include <string>

int main()
{
    //: Read the line.
    std::string line {};
    std::getline(std::cin, [[line]]);
    //: Print the value.
    std::println("{}", [[line.size() - 2]]);
}
```
## Slow
```cpp
#include <iostream>
#include <print>
#include <string>

int main()
{
    std::string line {};
    std::getline(std::cin, line);
    int count {0};
    for (int index {1}; index + 1 < static_cast<int>(line.size()); ++index) {
        ++count;
    }
    std::println("{}", count);
}
```
