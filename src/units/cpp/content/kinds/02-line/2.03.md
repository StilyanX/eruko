# 2.03
Write a program that reads a line of text and prints it twice, with one space between the 2 copies.

Input: one line of text, which may hold spaces.
Output: one line.
Limits: the text holds 1 to 100 characters.

## Examples
```in
knock
```
```out
knock knock
```
```in
a b
```
```out
a b a b
```
## Solution
```cpp
#include <iostream>
#include <print>
#include <string>

int main()
{
    //: Read the line.
    std::string line {};
    std::getline(std::cin, [[line]]);
    //: Print the value.
    std::println("{} {}", line, [[line]]);
}
```
## Slow
```cpp
#include <iostream>
#include <print>
#include <string>

int main()
{
    std::string line {};
    std::getline(std::cin, line);
    std::string result {};
    for (int copy {0}; copy < 2; ++copy) {
        if (copy == 1) {
            result += ' ';
        }
        for (const char character : line) {
            result += character;
        }
    }
    std::println("{}", result);
}
```
