# 2.04
Write a program that reads a line of text and prints how many full groups of 8 characters it holds.

Input: one line of text, which may hold spaces.
Output: one line, one integer.
Limits: the text holds 0 to 100 characters.

## Examples
```in
one two three four
```
```out
2
```
## Solution
```cpp
#include <iostream>
#include <print>
#include <string>

int main()
{
    //: Read the line.
    std::string line {};
    std::getline(std::cin, [[line]]);
    //: Print the value.
    std::println("{}", [[line.size() / 8]]);
}
```
## Slow
```cpp
#include <iostream>
#include <print>
#include <string>

int main()
{
    std::string line {};
    std::getline(std::cin, line);
    int groups {0};
    while (line.size() >= 8) {
        line.erase(0, 8);
        ++groups;
    }
    std::println("{}", groups);
}
```
