# 23.01
Source: exercism resistor-color
Write a function `resistor_color::color_code(const std::string& color)` that returns the value of a band color as an `int`.
The 10 colors, in order of their values 0 to 9, are black, brown, red, orange, yellow, green, blue, violet, grey and white.
Also write `resistor_color::colors()`, which returns the 10 colors in that order as a `std::vector<std::string>`.
Limits: the color is one of the 10, in lower case.
## Solution
```cpp
#pragma once

#include <string>
#include <vector>

namespace resistor_color {

//: Make a table of fixed values.
const std::vector<std::string> bands {
    [["black"]], "brown", "red", "orange", "yellow",
    "green", "blue", "violet", "grey", "white"};

//: Write a function that gives back a value worked out in one step.
[[std::vector<std::string>]] colors()
{
    //:: Give back the table of colors.
    return [[bands]];
}

//: Write a function that finds the first item that passes a test and gives back its position.
int color_code([[const std::string& color]])
{
    //:: Give back the index of the first entry equal to the color.
    for (int index {0}; index < std::ssize(bands); ++index) {
        if ([[bands[index] == color]]) {
            return index;
        }
    }
    //:: Give back -1 when no entry is equal to it.
    return [[-1]];
}

}  // namespace resistor_color
```
