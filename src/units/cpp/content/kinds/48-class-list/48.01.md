# 48.01
Source: exercism high-scores
Write a class `arcade::HighScores` made from a `std::vector<int>` of scores, in the order they were added.
`list_scores()` returns all the scores, in the same order.
`latest_score()` returns the score added last.
`personal_best()` returns the largest score.
`top_three()` returns the 3 largest scores, largest first, or all of them, largest first, when there are fewer than 3; equal scores each count.
No member function changes the scores.
Limits: 1 ≤ number of scores ≤ 1000; 0 ≤ each score ≤ 1 000 000.
## Solution
```cpp
#pragma once

#include <algorithm>
#include <functional>
#include <vector>

namespace arcade {

//: Write a class with a constructor that sets the data.
class HighScores {
public:
    explicit HighScores([[std::vector<int> scores]])
        : scores_ {scores}
    {
    }
    //: Write a member function that gives back the data.
    std::vector<int> list_scores() const
    {
        return [[scores_]];
    }
    //: Write a member function that gives back a value worked out in one step.
    int latest_score() const
    {
        return [[scores_.back()]];
    }
    //: Write a member function that gives back a value worked out in one step.
    int personal_best() const
    {
        return [[std::ranges::max(scores_)]];
    }
    //: Write a member function that gives back the largest values of a list, largest first.
    [[std::vector<int>]] top_three() const
    {
        //:: Copy the list, and sort it from largest to smallest.
        std::vector<int> sorted {[[scores_]]};
        std::ranges::sort(sorted, std::ranges::greater {});
        //:: Keep at most the first 3.
        sorted.resize([[std::min(sorted.size(), std::size_t {3})]]);
        //:: Give back the sorted list.
        return [[sorted]];
    }
//: Keep the data in private members.
private:
    [[std::vector<int>]] scores_ {};
};

}  // namespace arcade
```
