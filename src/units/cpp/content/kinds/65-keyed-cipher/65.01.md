# 65.01
Source: exercism affine-cipher
Write a function `affine_cipher::encode(const std::string& input, int a, int b)` that returns the text encoded with the key a, b.
Write a function `affine_cipher::decode(const std::string& input, int a, int b)` that returns the text decoded with the same key.
Number the letters a = 0 to z = 25, in either case. Encoding turns letter number i into the lower-case letter number (a × i + b) mod 26.
Decoding turns letter number y into the letter number x × (y - b) mod 26, where x is the number from 1 to 25 for which a × x mod 26 is 1.
Both keep digits as they are and leave out every other character. Encoding then puts a space after every 5 characters, but not at the end.
Throw `std::invalid_argument` when a and 26 have a common divisor above 1.
Limits: 1 ≤ a ≤ 100; 0 ≤ b ≤ 100; 0 ≤ length of the text ≤ 1000.
## Solution
```cpp
#pragma once

#include <cctype>
#include <numeric>
#include <stdexcept>
#include <string>

namespace affine_cipher {

//: Write a function that throws an error when its input is not allowed.
void check_key([[int a]])
{
    if (std::gcd(a, 26) != 1) {
        throw std::invalid_argument {"a has no inverse"};
    }
}

//: Write a function that repeats a step until a condition holds and gives back the result.
int inverse([[int a]])
{
    //:: Start the inverse at 1.
    int inverse {[[1]]};
    //:: Add one to the inverse until a times it leaves 1 after dividing by 26.
    while ([[a * inverse % 26 != 1]]) {
        ++inverse;
    }
    //:: Give back the inverse.
    return [[inverse]];
}

//: Write a function that builds a new string from each character of the text.
std::string apply_key([[const std::string& text]], int times,
    int plus)
{
    //:: Start the result as an empty string.
    std::string result {[[""]]};
    //:: For each character, add a digit as it is, and a letter moved by the key.
    for (const char character : text) {
        if (std::isdigit(character)) {
            result += character;
        } else if ([[std::isalpha(character)]]) {
            const int index {std::tolower(character) - 'a'};
            const int moved {(times * index + plus) % 26};
            result += static_cast<char>('a' + moved);
        }
    }
    //:: Give back the result.
    return [[result]];
}

//: Write a function that builds a new string from each character of the text.
std::string in_groups([[const std::string& text]])
{
    //:: Start the result as an empty string.
    std::string result {[[""]]};
    //:: For each character, add a space before it when 5, 10, 15 or more characters come before it, then the character.
    for (std::size_t index {0}; index < text.size(); ++index) {
        if ([[index > 0 && index % 5 == 0]]) {
            result += ' ';
        }
        result += text[index];
    }
    //:: Give back the result.
    return [[result]];
}

//: Write a function that calls the functions above and gives back the answer.
std::string encode([[const std::string& input, int a, int b]])
{
    check_key(a);
    return in_groups(apply_key(input, a, b));
}

//: Write a function that calls the functions above and gives back the answer.
std::string decode([[const std::string& input, int a, int b]])
{
    check_key(a);
    const int x {inverse(a)};
    return apply_key(input, x, x * (26 - b % 26));
}

}  // namespace affine_cipher
```
