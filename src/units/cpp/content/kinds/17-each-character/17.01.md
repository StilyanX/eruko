# 17.01
Source: exercism reverse-string
Write a function `reverse_string::reverse_string(const std::string& text)` that returns the text with its characters in reverse order.
The text is UTF-8, so one character may take 2 to 4 bytes: a byte from 0x80 to 0xBF goes on the character before it.
The bytes of each character keep their order.
The empty text gives the empty text.
Limits: 0 ≤ length of the text ≤ 1000 bytes.
## Solution
```cpp
#pragma once

#include <string>

namespace reverse_string {

//: Write a function that builds a new string from each character of the text.
std::string reverse_string([[const std::string& text]])
{
    //:: Start the result as an empty string.
    std::string result {[[""]]};
    //:: Start the place to add at 0.
    std::size_t place {[[0]]};
    //:: For each byte, add it at the front, or just after the bytes before it in its own character.
    for (const char character : text) {
        if ([[(character & 0xC0) != 0x80]]) {
            place = 0;
        }
        result.insert(place, 1, character);
        ++place;
    }
    //:: Give back the result.
    return [[result]];
}

}  // namespace reverse_string
```
