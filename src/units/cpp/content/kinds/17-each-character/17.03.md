# 17.03
Source: exercism rotational-cipher
Write a function `rotational_cipher::rotate(const std::string& text, int key)` that returns the text with each letter moved on by `key` places in the alphabet.
After z comes a again, and after Z comes A; a letter keeps its case. Every other character stays as it is.
Limits: 0 ≤ key ≤ 26; 0 ≤ length of the text ≤ 1000.
## Solution
```cpp
#pragma once

#include <cctype>
#include <string>

namespace rotational_cipher {

//: Write a function that builds a new string from each character of the text.
std::string rotate([[const std::string& text, int key]])
{
    //:: Start the result as an empty string.
    std::string result {[[""]]};
    //:: For each character, add a letter moved on by the key, back to the start after z, else the character itself.
    for (const char character : text) {
        if ([[std::islower(character)]]) {
            const int moved {(character - 'a' + key) % 26};
            result += static_cast<char>('a' + moved);
        } else if (std::isupper(character)) {
            const int moved {(character - 'A' + key) % 26};
            result += static_cast<char>('A' + moved);
        } else {
            result += character;
        }
    }
    //:: Give back the result.
    return [[result]];
}

}  // namespace rotational_cipher
```
