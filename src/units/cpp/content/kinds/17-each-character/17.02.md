# 17.02
Source: exercism acronym
Write a function `acronym::acronym(const std::string& phrase)` that returns the first letter of each word of the phrase, in capitals.
Spaces and dashes separate words. Every other character that is not a letter is left out, so `Halley's` is one word and `_Not_` begins with N.
Limits: 1 ≤ length of the phrase ≤ 1000.
## Solution
```cpp
#pragma once

#include <cctype>
#include <string>

namespace acronym {

//: Write a function that builds a new string from each character of the text.
std::string acronym([[const std::string& phrase]])
{
    //:: Start the result as an empty string.
    std::string result {[[""]]};
    //:: Start `word_start` at true, since the next letter begins a word.
    bool word_start {[[true]]};
    //:: For each character, add a letter that begins a word in capitals, and mark a space or a dash as the start of a new word.
    for (const char character : phrase) {
        if ([[std::isalpha(character) && word_start]]) {
            result += static_cast<char>(
                std::toupper(character));
            word_start = false;
        } else if (character == ' ' || character == '-') {
            word_start = true;
        }
    }
    //:: Give back the result.
    return [[result]];
}

}  // namespace acronym
```
