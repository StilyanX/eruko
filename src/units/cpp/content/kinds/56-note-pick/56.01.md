# 56.01
Source: exercism bob
Write a function `bob::hey(const std::string& text)` that returns one of five answers for the text.
When the text is empty or holds only spaces, tabs, line ends and returns: `Fine. Be that way!`.
When the text has a capital letter and no small letter, and its last character that is not white space is `?`: `Calm down, I know what I'm doing!`.
When the text has a capital letter and no small letter otherwise: `Whoa, chill out!`.
When the last character that is not white space is `?` otherwise: `Sure.`.
Else: `Whatever.`.
Limits: 0 ≤ length of text ≤ 1000; text holds printable ASCII characters and white space.
## Solution
```cpp
#pragma once

#include <cctype>
#include <string>

namespace bob {

//: Write a function that keeps what it finds in each character of the text, then gives back the answer for it.
std::string hey([[const std::string& text]])
{
    //:: Start with no letter found and a space as the last character.
    bool capital {false};
    bool small {false};
    char last {[[' ']]};
    //:: Keep whether a capital or small letter comes, and the last character that is not white space.
    for (const char character : text) {
        if (std::isupper(character)) {
            capital = true;
        } else if (std::islower(character)) {
            small = true;
        }
        if ([[!std::isspace(character)]]) {
            last = character;
        }
    }
    //:: Test each case in order, and give back the answer of the first that holds.
    if ([[last == ' ']]) {
        return "Fine. Be that way!";
    } else if (capital && !small && last == '?') {
        return "Calm down, I know what I'm doing!";
    } else if (capital && !small) {
        return "Whoa, chill out!";
    } else if (last == '?') {
        return "Sure.";
    } else {
        return "Whatever.";
    }
}

}  // namespace bob
```
