# 74.01
Source: exercism binary-search-tree
Write a class `binary_search_tree::binary_tree<T>` whose objects are trees in which each node keeps a value of type T and owns a left and a right branch.
Its explicit constructor takes a `const T&` and makes a tree of one node that holds it.
`insert(const T& value)` adds a node for value: from the top node down, it goes to the left branch when value is not above the node's value, else to the right, until it reaches an empty branch, where the new node goes.
`data()` returns the node's value; `left()` and `right()` return the branches as `const std::unique_ptr<binary_tree<T>>&`, empty when there is no branch.
`begin()` and `end()` let a range `for` take every value of the tree in ascending order.
Limits: none
## Solution
```cpp
#pragma once

#include <cstdint>
#include <memory>
#include <vector>

namespace binary_search_tree {

//: Write a class that keeps its data in private members.
template <typename T>
class binary_tree {
    T data_ {};
    std::unique_ptr<binary_tree> left_ [[{}]];
    std::unique_ptr<binary_tree> right_ {};
    std::vector<T> sorted_ {};
public:
    //: Write a constructor that sets the data.
    explicit binary_tree([[const T& data]])
        : data_ {data}
    {
    }
    //: Write member functions that give back the data.
    const T& data() const
    {
        return [[data_]];
    }
    const std::unique_ptr<binary_tree>& left() const
    {
        return left_;
    }
    const std::unique_ptr<binary_tree>& right() const
    {
        return right_;
    }
    //: Write a member function that solves its task by calling itself on a smaller part.
    void insert([[const T& value]])
    {
        //:: Pick the left branch for a value not above the data, else the right.
        auto& branch {[[value <= data_]] ? left_ : right_};
        //:: Put a new tree there when the branch is empty, else insert into the branch.
        if ([[branch == nullptr]]) {
            branch = std::make_unique<binary_tree>(value);
        } else {
            branch->insert(value);
        }
    }
    //: Write a member function that solves its task by calling itself on a smaller part.
    void collect([[std::vector<T>& values]]) const
    {
        //:: Add the left branch's values, then the data, then the right branch's values.
        if (left_ != nullptr) {
            left_->collect(values);
        }
        values.push_back([[data_]]);
        if (right_ != nullptr) {
            right_->collect(values);
        }
    }
    //: Write member functions that give back the start and the end of the values in order.
    auto begin()
    {
        //:: Fill the list with the values in order, then give back its start.
        sorted_.clear();
        collect(sorted_);
        return [[sorted_.cbegin()]];
    }
    auto end() const
    {
        return [[sorted_.cend()]];
    }
};

}  // namespace binary_search_tree
```
