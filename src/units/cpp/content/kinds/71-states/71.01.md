# 71.01
Source: exercism two-bucket
Write a function `two_bucket::measure(int max_one, int max_two, int goal, bucket_id start)` that returns the fewest moves that leave exactly `goal` litres in one of two buckets, bucket one holding at most `max_one` litres and bucket two at most `max_two`.
Write in namespace `two_bucket` the type `enum class bucket_id { one, two }` and the type `struct measure_result { int num_moves; bucket_id goal_bucket; int other_bucket_volume; }`, which the function returns: the number of moves, the bucket that holds the target, and the litres in the other bucket.
Both buckets start empty. The first move fills the bucket `start` names. Each move after it does one of these: fill a bucket to the top, empty a bucket, or pour one bucket into the other until the first is empty or the other is full.
No move may leave the start bucket empty while the other bucket is full.
Throw an exception (of any type) when no moves reach the target.
Limits: 1 ≤ each capacity ≤ 100; 1 ≤ target ≤ 1000.
## Solution
```cpp
#pragma once

#include <algorithm>
#include <deque>
#include <set>
#include <stdexcept>
#include <utility>
#include <vector>

namespace two_bucket {

//: Name each possible value in an `enum class`.
enum class bucket_id { [[one]], two };

//: Write a struct that holds several values together.
struct measure_result {
    int num_moves {[[0]]};
    bucket_id goal_bucket {bucket_id::one};
    int other_bucket_volume {0};
};

//: Write a struct that holds several values together.
struct state {
    int one {[[0]]};
    int two {0};
    int moves {0};
};

//: Write a function that gives back the next states from a state.
std::vector<state> next_states([[const state& now]],
    int max_one, int max_two)
{
    //:: Work out how much each bucket can pour into the other.
    const int to_two {[[std::min(now.one, max_two - now.two)]]};
    const int to_one {std::min(now.two, max_one - now.one)};
    //:: Give back the states after filling, emptying or pouring each bucket, one move later.
    const int moves {[[now.moves + 1]]};
    return {{max_one, now.two, moves},
            {now.one, max_two, moves},
            {0, now.two, moves},
            {now.one, 0, moves},
            {now.one - to_two, now.two + to_two, moves},
            {now.one + to_one, now.two - to_one, moves}};
}

//: Write a function that tries each state in order of moves, and gives back the first that reaches the goal.
measure_result measure([[int max_one, int max_two]],
    int goal, bucket_id start)
{
    //:: Start the states to try with the start bucket full, after 1 move.
    const bool from_one {[[start == bucket_id::one]]};
    const state first {from_one ? state {max_one, 0, 1}
                                : state {0, max_two, 1}};
    std::deque<state> to_try {first};
    //:: Start the states seen with the first one and the one no move may reach.
    const std::pair<int, int> banned {
        from_one ? std::pair {0, max_two}
                 : std::pair {max_one, 0}};
    std::set<std::pair<int, int>> seen {
        {first.one, first.two}, [[banned]]};
    //:: While states are left, take the first, give back the answer when it holds the goal, else add each next state not yet seen.
    while ([[!to_try.empty()]]) {
        const state now {to_try.front()};
        to_try.pop_front();
        if (now.one == goal) {
            return {now.moves, bucket_id::one, now.two};
        }
        if (now.two == goal) {
            return {now.moves, bucket_id::two, now.one};
        }
        for (const state next :
             next_states(now, max_one, max_two)) {
            const std::pair<int, int> key {next.one, next.two};
            if (!seen.contains(key)) {
                seen.insert(key);
                to_try.push_back(next);
            }
        }
    }
    //:: Throw `std::domain_error` when no state reaches the goal.
    throw [[std::domain_error]] {"the goal cannot be reached"};
}

}  // namespace two_bucket
```
