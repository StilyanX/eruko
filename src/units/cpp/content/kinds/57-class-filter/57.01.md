# 57.01
Source: exercism anagram
Write a class `anagram::anagram` whose constructor takes a word as a `const std::string&`.
Its member `matches(const std::vector<std::string>& candidates)` returns a `std::vector<std::string>` of the candidates that use the same letters as the word, each as many times, in any order.
Upper and lower case count as the same letter, and each candidate is returned as given.
A candidate that is the word itself, in any case, is not returned.
The order of the result does not matter.
Limits: 1 ≤ length of each word ≤ 12; 1 ≤ number of candidates ≤ 6; each character is a letter `A` to `Z` or `a` to `z`.
## Solution
```cpp
#pragma once

#include <algorithm>
#include <cctype>
#include <string>
#include <vector>

namespace anagram {

//: Write a function that gives back a copy of the text with each letter in lower case.
std::string lower([[std::string text]])
{
    for (char& character : text) {
        character = std::tolower(character);
    }
    return text;
}

//: Write a function that gives back a copy of the text with its characters in order.
std::string sorted([[std::string text]])
{
    std::ranges::sort(text);
    return text;
}

//: Write a class that keeps its data in private members.
class anagram {
    std::string word_ [[{}]];
public:
    //: Write a constructor that sets the data.
    explicit anagram(const std::string& word)
        : word_ {[[lower(word)]]}
    {
    }
    //: Write a member function that gives back the items that pass a test.
    std::vector<std::string> matches(
        [[const std::vector<std::string>& candidates]]) const
    {
        //:: Start the result as an empty list.
        std::vector<std::string> result [[{}]];
        //:: Add each candidate with the word's letters that is not the word.
        for (const std::string& candidate : candidates) {
            const std::string text {lower(candidate)};
            if (text != word_
                && [[sorted(text) == sorted(word_)]]) {
                result.push_back(candidate);
            }
        }
        //:: Give back the result.
        return [[result]];
    }
};

}  // namespace anagram
```
