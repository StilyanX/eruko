# 36.01
Source: exercism perfect-numbers
Write a function `perfect_numbers::classify(int number)` that compares number with the sum of its divisors other than itself.
The header also defines the result type, `enum class perfect_numbers::classification { deficient, perfect, abundant }`.
It returns `perfect` when the sum equals number, `abundant` when the sum is larger and `deficient` when it is smaller.
It throws `std::domain_error` when number is below 1.
Limits: number ≤ 40 000 000.
## Solution
```cpp
#pragma once

#include <stdexcept>

namespace perfect_numbers {

//: Name each possible value in an `enum class`.
enum class classification { [[deficient]], perfect, abundant };

//: Write a function that adds to a total, then gives back an answer from the total.
classification classify([[int number]])
{
    //:: Stop with an error when the number is below 1.
    if ([[number < 1]]) {
        throw std::domain_error {"not a positive number"};
    }
    //:: Start the total at zero.
    int total {[[0]]};
    //:: Add each integer from 1 to the number - 1 that divides it.
    for (int divisor {1}; divisor < number; ++divisor) {
        if ([[number % divisor == 0]]) {
            total += divisor;
        }
    }
    //:: Give back perfect when the total equals the number, abundant when it is larger, else deficient.
    if ([[total == number]]) {
        return classification::perfect;
    } else if (total > number) {
        return classification::abundant;
    } else {
        return classification::deficient;
    }
}

}  // namespace perfect_numbers
```
