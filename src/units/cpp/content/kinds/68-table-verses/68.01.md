# 68.01
Source: exercism food-chain
Write a function `food_chain::verse(unsigned number)` that returns verse number 1 to 8 of a song as a `std::string`, each line ending in `\n`.
The 8 animals, in order, are fly, spider, bird, cat, dog, goat, cow and horse. Verse n is about animal n and has these lines:
- `I know an old lady who swallowed a <animal>.` for the verse's animal.
- For animals 2 to 8, its own line: spider `It wriggled and jiggled and tickled inside her.`, bird `How absurd to swallow a bird!`, cat `Imagine that, to swallow a cat!`, dog `What a hog, to swallow a dog!`, goat `Just opened her throat and swallowed a goat!`, cow `I don't know how she swallowed a cow!`, horse `She's dead, of course!`. The horse's verse ends there.
- Then, for each animal from the verse's back to the spider, `She swallowed the <animal> to catch the <animal before it>.`, where the spider as the animal caught is written `spider that wriggled and jiggled and tickled inside her`.
- Last, `I don't know why she swallowed the fly. Perhaps she'll die.`
Also write `food_chain::verses(unsigned first, unsigned last)`, which returns the verses from first to last, each followed by an empty line.
Also write `food_chain::sing()`, which returns `verses(1, 8)`.
Limits: 1 ≤ number ≤ 8; 1 ≤ first ≤ last ≤ 8.
## Solution
```cpp
#pragma once

#include <array>
#include <string>

namespace food_chain {

//: Make a table of fixed values.
const std::array<std::string, 8> animals {
    [["fly"]], "spider", "bird", "cat",
    "dog", "goat", "cow", "horse"};

//: Make a table of fixed values.
const std::array<std::string, 8> remarks {
    [[""]],
    "It wriggled and jiggled and tickled inside her.",
    "How absurd to swallow a bird!",
    "Imagine that, to swallow a cat!",
    "What a hog, to swallow a dog!",
    "Just opened her throat and swallowed a goat!",
    "I don't know how she swallowed a cow!",
    "She's dead, of course!"};

//: Write a function that builds a new string one piece at a time and gives it back.
std::string verse([[unsigned number]])
{
    //:: Start the verse with the line that names the animal.
    const unsigned index {number - 1};
    std::string result {"I know an old lady who swallowed a "};
    result += [[animals[index]]] + ".\n";
    //:: Add the animal's own line, unless it is the fly.
    if ([[index > 0]]) {
        result += remarks[index] + "\n";
    }
    //:: Give back the verse when it is the horse.
    if ([[index == 7]]) {
        return result;
    }
    //:: Add a line for each animal back to the spider, with the spider's own words after it.
    for (unsigned step {index}; [[step > 0]]; --step) {
        result += "She swallowed the " + animals[step]
                  + " to catch the " + animals[step - 1];
        if (step == 2) {
            result += " that wriggled and jiggled and tickled"
                      " inside her";
        }
        result += ".\n";
    }
    //:: Add the last line and give back the verse.
    result += "I don't know why she swallowed the fly."
              " Perhaps she'll die.\n";
    return [[result]];
}

//: Write a function that builds a new string one piece at a time and gives it back.
std::string verses([[unsigned first]], unsigned last)
{
    //:: Start the result as an empty string.
    std::string result [[{}]];
    //:: Add each verse, then an empty line.
    for (unsigned number {first}; number <= last; ++number) {
        result += [[verse(number)]] + "\n";
    }
    //:: Give back the result.
    return [[result]];
}

//: Write a function that calls the functions above and gives back the answer.
[[std::string]] sing()
{
    //:: Give back the verses from the first to the last.
    return [[verses(1, 8)]];
}

}  // namespace food_chain
```
