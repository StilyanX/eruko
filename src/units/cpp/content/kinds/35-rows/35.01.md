# 35.01
Source: exercism pascals-triangle
Write a function `pascals_triangle::generate_rows(std::size_t n)` that returns the first n rows of Pascal's triangle as a `std::vector<std::vector<int>>`.
Row 1 is `{1}`. Each row after it is one longer than the row before: its first and last values are 1, and each other value is the sum of the 2 values above it in the row before, at the same index and at the index before.
For n = 0 it returns an empty list.
Limits: 0 ≤ n ≤ 10.
## Solution
```cpp
#pragma once

#include <cstddef>
#include <vector>

namespace pascals_triangle {

//: Write a function that builds each row from the row before it.
std::vector<std::vector<int>> generate_rows([[std::size_t n]])
{
    //:: Start the result as an empty list.
    std::vector<std::vector<int>> rows [[{}]];
    //:: Add each row, with 1 at its ends and the sum of the 2 values above each other value.
    for (std::size_t length {1}; length <= n; ++length) {
        std::vector<int> row(length, 1);
        for (std::size_t i {1}; i + 1 < length; ++i) {
            row[i] = [[rows.back()[i - 1] + rows.back()[i]]];
        }
        rows.push_back(row);
    }
    //:: Give back the result.
    return [[rows]];
}

}  // namespace pascals_triangle
```
