# 16.02
Source: exercism isbn-verifier
Write a function `isbn_verifier::is_valid(const std::string& isbn)` that returns `true` when the text is a valid ISBN-10, else `false`.
Leave out every `-`. What is left must be exactly 10 characters: 9 digits, then a last character that is a digit or `X`, where `X` stands for 10.
Any other character, or an `X` in any other place, makes it not valid.
With d1 to d10 the 10 values in order, it is valid when (d1 × 10 + d2 × 9 + d3 × 8 + … + d9 × 2 + d10 × 1) mod 11 is 0.
Limits: 0 ≤ length of the text ≤ 14.
## Solution
```cpp
#pragma once

#include <cctype>
#include <string>

namespace isbn_verifier {

//: Write a function that adds to a total, then gives back an answer from the total.
bool is_valid([[const std::string& isbn]])
{
    //:: Start the total and the count of digits at zero.
    int total {[[0]]};
    int count {0};
    //:: Add each digit times 10 less the count, or 10 for an `X` at the end, and give back false for any other character but `-`.
    for (const char character : isbn) {
        if (std::isdigit(character) && count < 10) {
            total += [[(character - '0') * (10 - count)]];
            ++count;
        } else if (character == 'X' && count == 9) {
            total += 10;
            ++count;
        } else if (character != '-') {
            return false;
        }
    }
    //:: Give back whether there are 10 digits and 11 divides the total.
    return [[count == 10 && total % 11 == 0]];
}

}  // namespace isbn_verifier
```
