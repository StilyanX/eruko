# 16.03
Source: exercism armstrong-numbers
Write a function `armstrong_numbers::is_armstrong_number(int number)` that returns `true` when the number equals the sum of its digits, each raised to the power of how many digits the number has, else `false`.
For example, 153 returns `true`, since 1³ + 5³ + 3³ = 153, and 10 returns `false`, since 1² + 0² = 1.
Each number from 0 to 9 returns `true`.
Limits: 0 ≤ number ≤ 9 999 999.
## Solution
```cpp
#pragma once

#include <string>

namespace armstrong_numbers {

//: Write a function that adds to a total, then gives back an answer from the total.
bool is_armstrong_number([[int number]])
{
    //:: Make a string of the number's digits, and count them.
    const std::string digits {[[std::to_string(number)]]};
    const int count {static_cast<int>(digits.size())};
    //:: Start the total at zero.
    int total {[[0]]};
    //:: Add each digit to the power of the count to the total.
    for (const char digit : digits) {
        int power {1};
        for (int index {0}; index < count; ++index) {
            power *= digit - '0';
        }
        total += [[power]];
    }
    //:: Give back whether the total equals the number.
    return [[total == number]];
}

}  // namespace armstrong_numbers
```
