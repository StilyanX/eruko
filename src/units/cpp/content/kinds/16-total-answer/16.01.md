# 16.01
Source: exercism luhn
Write a function `luhn::valid(const std::string& text)` that returns whether the text is a valid number by this rule.
Spaces in the text are dropped first.
The text is not valid when it holds any other character that is not a digit, or fewer than 2 digits.
Starting from the last digit, double every second digit, and take 9 from a doubled digit above 9.
The text is valid when 10 divides the sum of the digits so changed.
Limits: 0 ≤ length of text ≤ 100; text holds printable ASCII characters.
## Solution
```cpp
#pragma once

#include <cctype>
#include <ranges>
#include <string>

namespace luhn {

//: Write a function that adds to a total, then gives back an answer from the total.
bool valid([[const std::string& text]])
{
    //:: Start the total and the count of digits at zero.
    int total {[[0]]};
    int count {0};
    //:: Add each digit from the last, doubled at every second, less 9 above 9.
    for (const char character : std::views::reverse(text)) {
        if (character == ' ') {
            continue;
        }
        if (!std::isdigit(character)) {
            return false;
        }
        int digit {character - '0'};
        if (count % 2 == 1) {
            digit *= 2;
        }
        if (digit > 9) {
            digit -= 9;
        }
        total += [[digit]];
        ++count;
    }
    //:: Give back whether there are 2 digits or more and 10 divides the total.
    return [[count > 1 && total % 10 == 0]];
}

}  // namespace luhn
```
