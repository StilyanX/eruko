# 39.01
Source: exercism resistor-color-duo
Write a function `resistor_color_duo::value(const std::vector<std::string>& colors)` that returns 10 times the code of the first color plus the code of the second.
The codes are `black` 0, `brown` 1, `red` 2, `orange` 3, `yellow` 4, `green` 5, `blue` 6, `violet` 7, `grey` 8 and `white` 9.
Colors after the second do not count.
Limits: colors holds 2 or 3 names, each one of the 10 above.
## Solution
```cpp
#pragma once

#include <string>
#include <vector>

namespace resistor_color_duo {

//: Write a function that finds the first item that passes a test and gives back its position.
int code([[const std::string& color]])
{
    //:: Make the list of colors, in the order of their codes.
    const std::vector<std::string> colors {
        [["black"]], "brown", "red", "orange", "yellow",
        "green", "blue", "violet", "grey", "white"};
    //:: Give back the index of the first color in the list equal to the color, else -1.
    for (int index {0}; index < std::ssize(colors); ++index) {
        if ([[colors[index] == color]]) {
            return index;
        }
    }
    return -1;
}

//: Write a function that gives back a value worked out in one step.
int value([[const std::vector<std::string>& colors]])
{
    //:: Give back 10 times the code of the first color plus the code of the second.
    return 10 * code(colors[0]) + [[code(colors[1])]];
}

}  // namespace resistor_color_duo
```
