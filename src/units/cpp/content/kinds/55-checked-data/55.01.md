# 55.01
Source: exercism phone-number
Write a class `phone_number::phone_number` whose constructor takes a `const std::string& text` and keeps the digits of text, in order, dropping every other character.
When it keeps 11 digits and the first is 1, it drops that 1.
It throws `std::domain_error` unless 10 digits are left and the first and the fourth of them are each 2 or more.
`number()` returns the 10 digits as a `std::string`.
Limits: none
## Solution
```cpp
#pragma once

#include <stdexcept>
#include <string>

namespace phone_number {

//: Write a class that keeps its data in private members.
class phone_number {
    std::string digits_ [[{}]];
public:
    //: Write a constructor that sets the data, and stops with an error when it is bad.
    explicit phone_number([[const std::string& text]])
    {
        //:: Keep each digit of the text, in order.
        for (const char character : text) {
            if (character >= '0' && [[character <= '9']]) {
                digits_ += character;
            }
        }
        //:: Drop the first digit when there are 11 and it is 1.
        if (digits_.size() == 11 && [[digits_[0] == '1']]) {
            digits_.erase(0, 1);
        }
        //:: Stop with an error unless 10 digits are left and the first and the fourth are 2 or more.
        if (digits_.size() != 10 || digits_[0] < '2'
            || [[digits_[3] < '2']]) {
            throw std::domain_error {"not a valid number"};
        }
    }
    //: Write a member function that gives back the data.
    std::string number() const
    {
        return [[digits_]];
    }
};

}  // namespace phone_number
```
