# 73.01
Source: exercism say
Write a function `say::in_english(unsigned long long number)` that returns the number in English words.
Write the words in lower case, separated by single spaces, with a dash inside the numbers from 21 to 99 that are not a multiple of 10 (`twenty-two`).
Write no `and`, and leave out every part that is zero: 1002345 is `one million two thousand three hundred forty-five`.
0 gives `zero`.
Throw `std::domain_error` for a number above 999 999 999 999 (a negative number passed in becomes such a number).
Limits: 0 ≤ number ≤ 999 999 999 999 for a number in words.
## Solution
```cpp
#pragma once

#include <stdexcept>
#include <string>
#include <vector>

namespace say {

//: Write a function that tests each case in order and gives back the result of the first that holds.
std::string below_hundred([[unsigned long long number]])
{
    //:: Make the words for 0 to 19 and for each ten.
    const std::vector<std::string> ones {
        "zero", "one", "two", "three", "four", "five", "six",
        "seven", "eight", "nine", "ten", "eleven", "twelve",
        "thirteen", "fourteen", "fifteen", "sixteen",
        "seventeen", "eighteen", "nineteen"};
    const std::vector<std::string> tens {
        "", "", "twenty", "thirty", "forty", [["fifty"]], "sixty",
        "seventy", "eighty", "ninety"};
    //:: Give back the word for a number below 20, the ten for a multiple of 10, else the ten, a dash and the last digit.
    if ([[number < 20]]) {
        return ones[number];
    } else if (number % 10 == 0) {
        return tens[number / 10];
    } else {
        return tens[number / 10] + "-" + ones[number % 10];
    }
}

//: Write a function that tests each case in order and gives back the result of the first that holds.
std::string below_thousand([[unsigned long long number]])
{
    //:: Give back the words for a number below 100, the hundreds for a multiple of 100, else the hundreds and the rest.
    const std::string hundreds {below_hundred(number / 100)};
    if ([[number < 100]]) {
        return below_hundred(number);
    } else if (number % 100 == 0) {
        return hundreds + " hundred";
    } else {
        return hundreds + " hundred "
            + below_hundred(number % 100);
    }
}

//: Write a function that repeats a step until a condition holds and gives back the result.
std::string in_english([[unsigned long long number]])
{
    //:: Throw `std::domain_error` for a number above 999 999 999 999.
    if ([[number > 999'999'999'999]]) {
        throw std::domain_error {"the number is too large"};
    }
    //:: Give back `zero` for 0.
    if ([[number == 0]]) {
        return "zero";
    }
    //:: Make the word for each power of 1000.
    const std::vector<std::string> powers {
        "", " thousand", [[" million"]], " billion"};
    //:: Start the result as an empty string.
    std::string result {[[""]]};
    //:: Start the power at 0.
    std::size_t power {[[0]]};
    //:: While the number is above 0, put the words for its last 3 digits, when not 0, at the front of the result, then drop them.
    while ([[number > 0]]) {
        const unsigned long long last {number % 1000};
        if (last != 0) {
            std::string words {below_thousand(last)};
            words += powers[power];
            if (!result.empty()) {
                words += " " + result;
            }
            result = words;
        }
        number /= 1000;
        ++power;
    }
    //:: Give back the result.
    return [[result]];
}

}  // namespace say
```
