# 54.01
Source: exercism clock
Write a class `date_independent::clock` whose objects each hold a time of day, in hours and minutes, with no date.
`clock::at(int hour, int minute)` returns the clock at that time; `minute` is 0 when left out.
Hours and minutes roll over in both directions: 25:00 is 01:00, 1:60 is 02:00, -1:15 is 23:15 and 1:-40 is 00:20.
`plus(int minutes)` returns the clock that many minutes later; a negative number goes earlier.
Turning a clock into `std::string` gives the time as `HH:MM`, each part 2 digits (`08:00`).
`==` and `!=` compare two clocks by the time they show.
Limits: -1000 ≤ hour ≤ 1000, -100 000 ≤ minute ≤ 100 000, -100 000 ≤ minutes added ≤ 100 000.
## Solution
```cpp
#pragma once

#include <format>
#include <string>

namespace date_independent {

//: Write a class with a constructor that sets the data.
class clock {
public:
    explicit clock([[int minutes]])
        : minutes_ {(minutes % 1440 + 1440) % 1440}
    {
    }
    //: Write a member function that gives back a value worked out in one step.
    static clock at([[int hour, int minute = 0]])
    {
        return clock {hour * 60 + minute};
    }
    //: Write a member function that gives back a value worked out in one step.
    clock plus([[int minutes]]) const
    {
        return clock {minutes_ + minutes};
    }
    //: Write a member function that gives back a value worked out in one step.
    operator std::string() const
    {
        return std::format("{:02}:{:02}", [[minutes_ / 60]],
                           minutes_ % 60);
    }
    //: Compare 2 objects by their values with `==` and `!=`.
    bool operator==(const clock& other) const = [[default]];
//: Keep the data in private members.
private:
    int minutes_ {[[0]]};
};

}  // namespace date_independent
```
