# 54.03
Source: exercism complex-numbers
Write a class `complex_numbers::Complex` whose objects each hold a complex number, a real part and an imaginary part, each a `double`.
Its constructor takes the real part and the imaginary part, in that order; the imaginary part is 0 when left out.
`real()` and `imag()` return the parts.
`+`, `-`, `*` and `/` work out the sum, difference, product and quotient of 2 complex numbers, or of a complex number and a `double` on either side.
`abs()` returns the absolute value, `conj()` the conjugate and `exp()` e raised to the number.
`==` and `!=` compare two numbers by their parts.
Each part must be right to within 0.005.
Limits: none
## Solution
```cpp
#pragma once

#include <cmath>

namespace complex_numbers {

//: Write a class with a constructor that sets the data.
class Complex {
public:
    Complex([[double real, double imag = 0.0]])
        : real_ {real}, imag_ {imag}
    {
    }
    //: Write a member function that gives back a value worked out in one step.
    double real() const
    {
        return [[real_]];
    }
    double imag() const
    {
        return imag_;
    }
    double abs() const
    {
        return std::hypot(real_, imag_);
    }
    //: Write a member function that gives back a value worked out in one step.
    Complex conj() const
    {
        return Complex {real_, [[-imag_]]};
    }
    Complex exp() const
    {
        const double size {std::exp(real_)};
        return Complex {size * std::cos(imag_),
                        size * std::sin(imag_)};
    }
    //: Write a member function that gives back a value worked out in one step.
    friend Complex operator+(const Complex& a, const Complex& b)
    {
        return Complex {[[a.real_ + b.real_]], a.imag_ + b.imag_};
    }
    friend Complex operator-(const Complex& a, const Complex& b)
    {
        return Complex {a.real_ - b.real_, a.imag_ - b.imag_};
    }
    friend Complex operator*(const Complex& a, const Complex& b)
    {
        return Complex {a.real_ * b.real_ - a.imag_ * b.imag_,
                        a.real_ * b.imag_ + a.imag_ * b.real_};
    }
    friend Complex operator/(const Complex& a, const Complex& b)
    {
        const double d {b.real_ * b.real_ + b.imag_ * b.imag_};
        return Complex {
            (a.real_ * b.real_ + a.imag_ * b.imag_) / d,
            (a.imag_ * b.real_ - a.real_ * b.imag_) / d};
    }
    //: Compare 2 objects by their values with `==` and `!=`.
    bool operator==(const Complex& other) const = [[default]];
//: Keep the data in private members.
private:
    double real_ {[[0.0]]};
    double imag_ {0.0};
};

}  // namespace complex_numbers
```
