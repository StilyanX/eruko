# 38.01
Source: exercism run-length-encoding
Write a function `run_length_encoding::encode(const std::string& text)` that returns the text with each run of the same character written as its length, then the character.
A run of length 1 is written as the character alone.
Write a function `run_length_encoding::decode(const std::string& text)` that turns such a string back: each character comes as many times as the number before it, or once when no number comes before it.
Empty text gives empty text.
Limits: 0 ≤ length of text ≤ 1000; the text to encode holds letters and spaces only.
## Solution
```cpp
#pragma once

#include <algorithm>
#include <cctype>
#include <cstddef>
#include <string>

namespace run_length_encoding {

//: Write a function that builds a new string one piece at a time and gives it back.
std::string encode([[const std::string& text]])
{
    //:: Start the result as an empty string.
    std::string result {[[""]]};
    //:: For each run, add its length when above 1, then its character.
    std::size_t start {0};
    while (start < text.size()) {
        std::size_t end {start + 1};
        while (end < text.size() && text[end] == text[start]) {
            ++end;
        }
        if ([[end - start > 1]]) {
            result += std::to_string(end - start);
        }
        result += text[start];
        start = end;
    }
    //:: Give back the result.
    return [[result]];
}

//: Write a function that builds a new string from each character of the text.
std::string decode([[const std::string& text]])
{
    //:: Start the result as an empty string.
    std::string result {[[""]]};
    //:: Start the count at zero.
    int count {[[0]]};
    //:: Add a digit to the count, or else add the character count times, at least once.
    for (const char character : text) {
        if (std::isdigit(character)) {
            count = count * 10 + character - '0';
        } else {
            result.append([[std::max(count, 1)]], character);
            count = 0;
        }
    }
    //:: Give back the result.
    return [[result]];
}

}  // namespace run_length_encoding
```
