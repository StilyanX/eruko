# 4.03
Write a program that reads an integer and prints FizzBuzz, Fizz, Buzz or the integer.
Print FizzBuzz when both 3 and 5 divide it, Fizz when only 3 does, and Buzz when only 5 does.
When neither 3 nor 5 divides it, print the integer itself.

Input: one line, one integer.
Output: one line.
Limits: 1 ≤ the integer ≤ 10 000.

## Examples
```in
9
```
```out
Fizz
```
```in
30
```
```out
FizzBuzz
```
## Solution
```cpp
#include <iostream>
#include <print>

int main()
{
    //: Read the input.
    int number {0};
    std::cin >> [[number]];
    //: Test each case in order, and print the result of the first that holds.
    if (number % 15 == 0) {
        std::println("FizzBuzz");
    } else if (number % 3 == 0) {
        std::println("Fizz");
    } else if ([[number % 5 == 0]]) {
        std::println("Buzz");
    } else {
        std::println("{}", number);
    }
}
```
## Slow
```cpp
#include <iostream>
#include <print>
#include <string>

int main()
{
    int number {0};
    std::cin >> number;
    std::string result {};
    if (number % 3 == 0) {
        result += "Fizz";
    }
    if (number % 5 == 0) {
        result += "Buzz";
    }
    if (result.empty()) {
        result = std::to_string(number);
    }
    std::println("{}", result);
}
```
