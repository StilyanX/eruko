# 4.10
Write a program that reads an integer and prints it with its ending: st, nd, rd or th.
The ending is th when the tens digit is 1.
Else it is st for a last digit of 1, nd for 2, rd for 3, and th for others.

Input: one line, one integer.
Output: one line, with no space between the integer and its ending.
Limits: 1 ≤ the integer ≤ 1000.

## Examples
```in
22
```
```out
22nd
```
```in
13
```
```out
13th
```
## Solution
```cpp
#include <iostream>
#include <print>

int main()
{
    //: Read the input.
    int number {0};
    std::cin >> [[number]];
    //: Test each case in order, and print the result of the first that holds.
    if (number % 100 / 10 == 1) {
        std::println("{}th", number);
    } else if (number % 10 == 1) {
        std::println("{}st", number);
    } else if (number % 10 == 2) {
        std::println("{}nd", number);
    } else if ([[number % 10 == 3]]) {
        std::println("{}rd", number);
    } else {
        std::println("{}th", number);
    }
}
```
## Slow
```cpp
#include <iostream>
#include <print>
#include <string>

int main()
{
    int number {0};
    std::cin >> number;
    const std::string text {std::to_string(number)};
    const char last {text.back()};
    const bool teen {text.size() >= 2 && text[text.size() - 2] == '1'};
    std::string ending {"th"};
    if (!teen && last == '1') {
        ending = "st";
    }
    if (!teen && last == '2') {
        ending = "nd";
    }
    if (!teen && last == '3') {
        ending = "rd";
    }
    std::println("{}{}", text, ending);
}
```
