# 4.05
Write a program that reads a month number and prints its season.
Spring is months 3, 4 and 5, and summer is 6, 7 and 8.
Autumn is 9, 10 and 11, and winter is 12, 1 and 2.

Input: one line, one integer, the month.
Output: one line.
Limits: 1 ≤ month ≤ 12.

## Examples
```in
4
```
```out
spring
```
```in
12
```
```out
winter
```
## Solution
```cpp
#include <iostream>
#include <print>

int main()
{
    //: Read the input.
    int month {0};
    std::cin >> [[month]];
    //: Test each case in order, and print the result of the first that holds.
    if (month <= 2) {
        std::println("winter");
    } else if (month <= 5) {
        std::println("spring");
    } else if (month <= 8) {
        std::println("summer");
    } else if ([[month <= 11]]) {
        std::println("autumn");
    } else {
        std::println("winter");
    }
}
```
