# 4.07
Write a program that reads an hour and prints it on a 12-hour clock.
Print the clock hour, a space, then AM for an hour below 12, else PM.
The clock hour is 12 for hours 0 and 12, the hour minus 12 above 12, else the hour.

Input: one line, one integer, the hour.
Output: one line.
Limits: 0 ≤ hour ≤ 23.

## Examples
```in
0
```
```out
12 AM
```
```in
15
```
```out
3 PM
```
## Solution
```cpp
#include <iostream>
#include <print>

int main()
{
    //: Read the input.
    int hour {0};
    std::cin >> [[hour]];
    //: Test each case in order, and print the result of the first that holds.
    if (hour == 0) {
        std::println("12 AM");
    } else if (hour < 12) {
        std::println("{} AM", hour);
    } else if ([[hour == 12]]) {
        std::println("12 PM");
    } else {
        std::println("{} PM", hour - 12);
    }
}
```
## Slow
```cpp
#include <iostream>
#include <print>

int main()
{
    int hour {0};
    std::cin >> hour;
    int shown {12};
    for (int step {0}; step < hour % 12; ++step) {
        shown = shown % 12 + 1;
    }
    std::println("{} {}", shown, hour < 12 ? "AM" : "PM");
}
```
