# 4.09
Write a program that reads a year and prints Yes when it is a leap year, else No.
A year is a leap year when 400 divides it, or when 4 divides it and 100 does not.

Input: one line, one integer, the year.
Output: one line.
Limits: 1 ≤ year ≤ 9999.

## Examples
```in
2024
```
```out
Yes
```
```in
1900
```
```out
No
```
## Solution
```cpp
#include <iostream>
#include <print>

int main()
{
    //: Read the input.
    int year {0};
    std::cin >> [[year]];
    //: Test each case in order, and print the result of the first that holds.
    if (year % 400 == 0) {
        std::println("Yes");
    } else if ([[year % 100 == 0]]) {
        std::println("No");
    } else if (year % 4 == 0) {
        std::println("Yes");
    } else {
        std::println("No");
    }
}
```
## Slow
```cpp
#include <chrono>
#include <iostream>
#include <print>

int main()
{
    int year {0};
    std::cin >> year;
    std::println("{}", std::chrono::year {year}.is_leap() ? "Yes" : "No");
}
```
