# 4.02
Write a program that reads 2 integers and prints how the first compares with the second.
Print < when the first is less, > when it is greater, and = when they are equal.

Input: one line, 2 integers separated by a space.
Output: one line.
Limits: -1000 ≤ each integer ≤ 1000.

## Examples
```in
3 8
```
```out
<
```
```in
4 4
```
```out
=
```
## Solution
```cpp
#include <iostream>
#include <print>

int main()
{
    //: Read the input.
    int first {0};
    int second {0};
    std::cin >> [[first >> second]];
    //: Test each case in order, and print the result of the first that holds.
    if (first < second) {
        std::println("<");
    } else if ([[first > second]]) {
        std::println(">");
    } else {
        std::println("=");
    }
}
```
