# 4.01
Write a program that reads a score and prints its grade.
The grade is A for 90 or more, else B for 80 or more, else C for 70 or more.
Below 70 it is D for 60 or more, else F.

Input: one line, one integer, the score.
Output: one line.
Limits: 0 ≤ score ≤ 100.

## Examples
```in
85
```
```out
B
```
```in
59
```
```out
F
```
## Solution
```cpp
#include <iostream>
#include <print>

int main()
{
    //: Read the input.
    int score {0};
    std::cin >> [[score]];
    //: Test each case in order, and print the result of the first that holds.
    if (score >= 90) {
        std::println("A");
    } else if ([[score >= 80]]) {
        std::println("B");
    } else if (score >= 70) {
        std::println("C");
    } else if (score >= 60) {
        std::println("D");
    } else {
        std::println("F");
    }
}
```
