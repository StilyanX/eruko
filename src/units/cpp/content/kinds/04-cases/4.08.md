# 4.08
Write a program that reads an integer and prints how many digits it has.

Input: one line, one integer.
Output: one line, one integer, 1 for 0.
Limits: 0 ≤ the integer ≤ 99 999.

## Examples
```in
7
```
```out
1
```
```in
2026
```
```out
4
```
## Solution
```cpp
#include <iostream>
#include <print>

int main()
{
    //: Read the input.
    int number {0};
    std::cin >> [[number]];
    //: Test each case in order, and print the result of the first that holds.
    if (number < 10) {
        std::println("1");
    } else if (number < 100) {
        std::println("2");
    } else if ([[number < 1000]]) {
        std::println("3");
    } else if (number < 10000) {
        std::println("4");
    } else {
        std::println("5");
    }
}
```
