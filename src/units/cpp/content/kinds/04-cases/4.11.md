# 4.11
Write a program that reads 3 integers a, b and c and prints right, acute or obtuse.
Print right when a times a plus b times b equals c times c.
Print acute when a times a plus b times b is greater than c times c, else obtuse.

Input: one line, 3 integers a, b and c, separated by spaces.
Output: one line.
Limits: 1 ≤ a ≤ b ≤ c ≤ 1000.

## Examples
```in
3 4 5
```
```out
right
```
```in
4 5 6
```
```out
acute
```
## Solution
```cpp
#include <iostream>
#include <print>

int main()
{
    //: Read the input.
    int a {0};
    int b {0};
    int c {0};
    std::cin >> [[a >> b >> c]];
    //: Test each case in order, and print the result of the first that holds.
    if (a * a + b * b == c * c) {
        std::println("right");
    } else if ([[a * a + b * b > c * c]]) {
        std::println("acute");
    } else {
        std::println("obtuse");
    }
}
```
## Slow
```cpp
#include <iostream>
#include <print>

int main()
{
    int a {0};
    int b {0};
    int c {0};
    std::cin >> a >> b >> c;
    int left {0};
    for (int step {0}; step < a; ++step) {
        left += a;
    }
    for (int step {0}; step < b; ++step) {
        left += b;
    }
    int right {0};
    for (int step {0}; step < c; ++step) {
        right += c;
    }
    if (left < right) {
        std::println("obtuse");
    } else if (left > right) {
        std::println("acute");
    } else {
        std::println("right");
    }
}
```
