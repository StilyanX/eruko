# 4.06
Write a program that reads a temperature in degrees Celsius and prints ice, water or steam.
Print ice at 0 or below, steam at 100 or above, and water between them.

Input: one line, one integer, the temperature.
Output: one line.
Limits: -273 ≤ temperature ≤ 1000.

## Examples
```in
25
```
```out
water
```
```in
-5
```
```out
ice
```
## Solution
```cpp
#include <iostream>
#include <print>

int main()
{
    //: Read the input.
    int temperature {0};
    std::cin >> [[temperature]];
    //: Test each case in order, and print the result of the first that holds.
    if (temperature <= 0) {
        std::println("ice");
    } else if ([[temperature < 100]]) {
        std::println("water");
    } else {
        std::println("steam");
    }
}
```

    }

    }

        std::println("ice");
    }
}
