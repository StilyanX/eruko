# 26.01
Source: exercism hamming
Write a function `hamming::compute(const std::string& first, const std::string& second)` that returns how many positions hold different letters in the two strings.
The two strings must have the same length; when they differ in length, throw `std::domain_error`.
Two empty strings give 0.
Limits: 0 ≤ length of each string ≤ 1000; each letter is one of A, C, G and T.
## Solution
```cpp
#pragma once

#include <stdexcept>
#include <string>

namespace hamming {

//: Write a function that counts the items that pass a test and gives back the count.
int compute([[const std::string& first, const std::string& second]])
{
    //:: Throw `std::domain_error` when the lengths differ.
    if ([[first.size() != second.size()]]) {
        throw std::domain_error {"the lengths differ"};
    }
    //:: Start the count at zero.
    int count {[[0]]};
    //:: Add one for each index where the 2 letters differ.
    for (std::size_t index {0}; index < first.size(); ++index) {
        if (first[index] != second[index]) {
            ++[[count]];
        }
    }
    //:: Give back the count.
    return [[count]];
}

}  // namespace hamming
```
