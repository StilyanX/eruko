# 72.01
Source: exercism bank-account
Write a class `Bankaccount::Bankaccount` with the members `open()`, `close()`, `deposit(int amount)`, `withdraw(int amount)` and `balance()`, safe to call from many threads at once.
A new object is closed.
`open()` opens it with a balance of 0, and `close()` closes it.
`deposit` adds amount to the balance, `withdraw` takes amount from it, and `balance()` returns it.
Each throws `std::runtime_error`: `open()` when the account is open; `close()`, `deposit`, `withdraw` and `balance()` when it is closed; `deposit` and `withdraw` when amount is below 0; and `withdraw` when amount is more than the balance.
Limits: none
## Solution
```cpp
#pragma once

#include <mutex>
#include <stdexcept>

namespace Bankaccount {

//: Write a class that keeps its data in private members.
class Bankaccount {
    int balance_ [[{0}]];
    bool open_ {false};
    std::mutex mutex_ {};
public:
    //: Write member functions that lock the data, stop with an error when a test fails, else change it.
    void open()
    {
        //:: Stop with an error when the account is open, else open it with a balance of 0.
        const std::lock_guard lock {mutex_};
        if ([[open_]]) {
            throw std::runtime_error {"the account is open"};
        }
        open_ = true;
        balance_ = 0;
    }
    void close()
    {
        //:: Stop with an error when the account is closed, else close it.
        const std::lock_guard lock {mutex_};
        if ([[!open_]]) {
            throw std::runtime_error {"the account is closed"};
        }
        open_ = false;
    }
    void deposit([[int amount]])
    {
        //:: Stop with an error when the account is closed or the amount is below 0, else add it.
        const std::lock_guard lock {mutex_};
        if (!open_ || [[amount < 0]]) {
            throw std::runtime_error {"cannot deposit"};
        }
        balance_ += amount;
    }
    void withdraw(int amount)
    {
        //:: Stop with an error when the account is closed or the amount is below 0 or above the balance, else take it away.
        const std::lock_guard lock {mutex_};
        if (!open_ || amount < 0 || [[amount > balance_]]) {
            throw std::runtime_error {"cannot withdraw"};
        }
        balance_ -= amount;
    }
    //: Write a member function that locks the data, stops with an error when a test fails, else gives back the data.
    int balance()
    {
        const std::lock_guard lock {mutex_};
        if ([[!open_]]) {
            throw std::runtime_error {"the account is closed"};
        }
        return balance_;
    }
};

}  // namespace Bankaccount
```
