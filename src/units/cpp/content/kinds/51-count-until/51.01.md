# 51.01
Source: exercism nth-prime
Write a function `nth_prime::nth(int n)` that returns the nth prime number, counting 2 as the first.
A prime is a whole number greater than 1 that no whole number divides but 1 and itself.
For an n less than 1 it throws `std::domain_error`.
Limits: 0 ≤ n ≤ 10 001.
## Solution
```cpp
#pragma once

#include <stdexcept>

namespace nth_prime {

//: Write a function that gives back false at the first item that fails a test, else true.
bool is_prime([[int number]])
{
    //:: Give back false at the first factor from 2 up to the square root of the number.
    for (int factor {2}; factor * factor <= number; ++factor) {
        if ([[number % factor == 0]]) {
            return false;
        }
    }
    //:: Give back true.
    return [[true]];
}

//: Write a function that repeats a step until a condition holds and gives back the result.
int nth([[int n]])
{
    //:: Throw `std::domain_error` when n is less than 1.
    if ([[n < 1]]) {
        throw std::domain_error {"n must be at least 1"};
    }
    //:: Start the number at 1 and the count at zero.
    int number {[[1]]};
    int count {0};
    //:: Add one to the number, and one to the count when the number is prime, until the count is n.
    while ([[count < n]]) {
        ++number;
        if (is_prime(number)) {
            ++count;
        }
    }
    //:: Give back the number.
    return [[number]];
}

}  // namespace nth_prime
```
