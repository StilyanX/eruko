# 69.01
Source: exercism crypto-square
Write a class `crypto_square::cipher` whose constructor takes a `const std::string& text`, and whose member `normalized_cipher_text()` returns text coded as follows, as a `std::string`.
Keep only the letters and digits of text, in order, the letters made lowercase; say n characters are left.
The number of columns c is the smallest number with c × c ≥ n, and the number of rows r is the smallest with r × c ≥ n.
Write the characters row by row into r rows of c, and fill the end of the last row with spaces.
Return the columns, left to right, each read from top to bottom, with one space between 2 columns.
When no characters are left, return an empty string.
Limits: none
## Solution
```cpp
#pragma once

#include <cctype>
#include <string>

namespace crypto_square {

//: Write a class that keeps its data in private members.
class cipher {
    std::string text_ [[{}]];
public:
    //: Write a constructor that sets the data.
    explicit cipher([[const std::string& text]])
    {
        //:: Keep each letter, made lowercase, and each digit of the text, in order.
        for (const unsigned char sign : text) {
            if ([[std::isalnum(sign)]]) {
                text_ += static_cast<char>(std::tolower(sign));
            }
        }
    }
    //: Write a member function that builds a new string one piece at a time and gives it back.
    [[std::string]] normalized_cipher_text() const
    {
        //:: Find the columns, the smallest number whose square is at least the size.
        const int size {static_cast<int>(text_.size())};
        int columns {0};
        while ([[columns * columns < size]]) {
            ++columns;
        }
        //:: Find the rows, the smallest number that times the columns is at least the size.
        int rows {0};
        while ([[rows * columns < size]]) {
            ++rows;
        }
        //:: Start the result as an empty string.
        std::string result {[[""]]};
        //:: For each column, add a space before all but the first, then its character in each row, or a space past the end.
        for (int column {0}; column < columns; ++column) {
            if (column > 0) {
                result += ' ';
            }
            for (int row {0}; row < rows; ++row) {
                const int index {row * columns + column};
                result += [[index < size]] ? text_[index] : ' ';
            }
        }
        //:: Give back the result.
        return [[result]];
    }
};

}  // namespace crypto_square
```
