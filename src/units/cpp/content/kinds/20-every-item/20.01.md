# 20.01
Source: exercism pangram
Write a function `pangram::is_pangram(const std::string& text)` that returns `true` when the text holds each of the 26 letters `a` to `z` at least once, else `false`.
An upper-case letter counts as its lower-case letter.
Digits, spaces, `_` and punctuation count as no letter.
An empty text returns `false`.
Limits: 0 ≤ length of the text ≤ 100; each character is ASCII.
## Solution
```cpp
#pragma once

#include <cctype>
#include <string>

namespace pangram {

//: Write a function that gives back false at the first item that fails a test, else true.
bool is_pangram([[const std::string& text]])
{
    //:: Make a copy of the text with each letter in lower case.
    std::string lower {};
    for (const char character : text) {
        lower += [[std::tolower(character)]];
    }
    //:: Give back false for the first letter from `a` to `z` that the copy lacks.
    for (char letter {'a'}; letter <= 'z'; ++letter) {
        if ([[!lower.contains(letter)]]) {
            return false;
        }
    }
    //:: Give back true.
    return [[true]];
}

}  // namespace pangram
```
