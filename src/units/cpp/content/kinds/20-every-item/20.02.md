# 20.02
Source: exercism isogram
Write a function `isogram::is_isogram(const std::string& phrase)` that returns whether no letter occurs twice in the phrase.
Upper and lower case count as the same letter. Spaces and dashes may occur any number of times.
The empty phrase gives `true`.
Limits: 0 ≤ length of the phrase ≤ 1000.
## Solution
```cpp
#pragma once

#include <cctype>
#include <string>

namespace isogram {

//: Write a function that gives back false at the first item that fails a test, else true.
bool is_isogram([[const std::string& phrase]])
{
    //:: Start the letters seen as an empty string.
    std::string seen {[[""]]};
    //:: For each letter, in lower case, give back false when it was seen before, else add it to the letters seen.
    for (const char character : phrase) {
        if (std::isalpha(character)) {
            const char letter {
                static_cast<char>(std::tolower(character))};
            if ([[seen.contains(letter)]]) {
                return false;
            }
            seen += letter;
        }
    }
    //:: Give back true, since no letter came twice.
    return [[true]];
}

}  // namespace isogram
```
