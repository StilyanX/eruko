# 28.01
Source: exercism rna-transcription
Write a function `rna_transcription::to_rna(char nucleotide)` that returns `C` for `G`, `G` for `C`, `A` for `T` and `U` for `A`.
Write a second function `rna_transcription::to_rna(const std::string& strand)` that returns, as a `std::string`, the strand with each character replaced this way.
Limits: the strand holds only `A`, `C`, `G` and `T`.
## Solution
```cpp
#pragma once

#include <string>

namespace rna_transcription {

//: Write a function that tests each case in order and gives back the result of the first that holds.
char to_rna([[char nucleotide]])
{
    //:: Give back `C` for `G`, `G` for `C`, `A` for `T`, else `U`.
    if ([[nucleotide == 'G']]) {
        return 'C';
    } else if (nucleotide == 'C') {
        return 'G';
    } else if (nucleotide == 'T') {
        return 'A';
    } else {
        return 'U';
    }
}

//: Write a function that builds a new string from each character of the text.
std::string to_rna([[const std::string& strand]])
{
    //:: Start the result as an empty string.
    std::string result {[[""]]};
    //:: For each character of the strand, in order, add its partner to the result.
    for (const char character : strand) {
        result += [[to_rna(character)]];
    }
    //:: Give back the result.
    return [[result]];
}

}  // namespace rna_transcription
```
