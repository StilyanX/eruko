# 28.02
Source: written
Write a function `leet::to_leet(char character)` that returns `4` for `a`, `3` for `e`, `0` for `o`, else the character itself.
Write a second function `leet::to_leet(const std::string& text)` that returns, as a `std::string`, the text with each character changed this way.
Limits: 0 ≤ length of the text ≤ 100; the text holds lowercase letters and spaces.
## Solution
```cpp
#pragma once

#include <string>

namespace leet {

//: Write a function that tests each case in order and gives back the result of the first that holds.
char to_leet([[char character]])
{
    //:: Give back `4` for `a`, `3` for `e`, `0` for `o`, else the character itself.
    if ([[character == 'a']]) {
        return '4';
    } else if (character == 'e') {
        return '3';
    } else if (character == 'o') {
        return '0';
    } else {
        return character;
    }
}

//: Write a function that builds a new string from each character of the text.
std::string to_leet([[const std::string& text]])
{
    //:: Start the result as an empty string.
    std::string result {[[""]]};
    //:: For each character of the text, in order, add it changed to the result.
    for (const char character : text) {
        result += [[to_leet(character)]];
    }
    //:: Give back the result.
    return [[result]];
}

}  // namespace leet
```
## Slow
```cpp
#pragma once

#include <string>

namespace leet {

char to_leet(char character)
{
    const std::string from {"aeo"};
    const std::string to {"430"};
    char answer {character};
    for (std::size_t i {0}; i < from.size(); ++i) {
        if (from[i] == character) {
            answer = to[i];
        }
    }
    return answer;
}

std::string to_leet(const std::string& text)
{
    std::string result {text};
    for (std::size_t i {0}; i < result.size(); ++i) {
        result[i] = to_leet(text[i]);
    }
    return result;
}

}  // namespace leet
```
