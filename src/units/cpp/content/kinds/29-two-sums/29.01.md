# 29.01
Source: exercism difference-of-squares
Write a function `difference_of_squares::square_of_sum(int n)` that returns the square of the sum of the integers from 1 to n.
Write a function `difference_of_squares::sum_of_squares(int n)` that returns the sum of the squares of the integers from 1 to n.
Write a function `difference_of_squares::difference(int n)` that returns the first of these minus the second.
Limits: 1 ≤ n ≤ 100.
## Solution
```cpp
#pragma once

namespace difference_of_squares {

//: Write a function that adds up a sequence and gives back the total.
int square_of_sum([[int n]])
{
    //:: Start the total at zero.
    int total {[[0]]};
    //:: Add each integer from 1 to n to the total.
    for (int number {1}; number <= n; ++number) {
        total += [[number]];
    }
    //:: Give back the square of the total.
    return [[total * total]];
}

//: Write a function that adds up a sequence and gives back the total.
int sum_of_squares([[int n]])
{
    //:: Start the total at zero.
    int total {[[0]]};
    //:: Add the square of each integer from 1 to n to the total.
    for (int number {1}; number <= n; ++number) {
        total += [[number * number]];
    }
    //:: Give back the total.
    return [[total]];
}

//: Write a function that calls the functions above and gives back the answer.
int difference([[int n]])
{
    return square_of_sum(n) - sum_of_squares(n);
}

}  // namespace difference_of_squares
```
