# 67.01
Source: exercism beer-song
Write a function `beer_song::verse(int bottles)` that returns the verse for that number of bottles as a `std::string` of 2 lines, each ending in a newline.
For n of 3 or more, the lines are `n bottles of beer on the wall, n bottles of beer.` and `Take one down and pass it around, m bottles of beer on the wall.`, where m is n - 1.
For 2, the second line ends `1 bottle of beer on the wall.` instead.
For 1, the lines are `1 bottle of beer on the wall, 1 bottle of beer.` and `Take it down and pass it around, no more bottles of beer on the wall.`.
For 0, the lines are `No more bottles of beer on the wall, no more bottles of beer.` and `Go to the store and buy some more, 99 bottles of beer on the wall.`.
Write a function `beer_song::sing(int start, int end)` that returns the verses from start down to end, with an empty line between 2 verses; end is 0 when it is left out.
Limits: 0 ≤ end ≤ start ≤ 99.
## Solution
```cpp
#pragma once

#include <format>
#include <string>

namespace beer_song {

//: Write a function that tests each case in order and gives back the result of the first that holds.
std::string verse([[int bottles]])
{
    //:: Give back the verse for 0, for 1, for 2, else for any other number.
    if ([[bottles == 0]]) {
        return "No more bottles of beer on the wall, "
               "no more bottles of beer.\n"
               "Go to the store and buy some more, "
               "99 bottles of beer on the wall.\n";
    } else if (bottles == 1) {
        return "1 bottle of beer on the wall, "
               "1 bottle of beer.\n"
               "Take it down and pass it around, "
               "no more bottles of beer on the wall.\n";
    } else if (bottles == 2) {
        return "2 bottles of beer on the wall, "
               "2 bottles of beer.\n"
               "Take one down and pass it around, "
               "1 bottle of beer on the wall.\n";
    } else {
        return std::format("{0} bottles of beer on the wall, "
                           "{0} bottles of beer.\n"
                           "Take one down and pass it around, "
                           "{1} bottles of beer on the wall.\n",
                           bottles, bottles - 1);
    }
}

//: Write a function that builds a new string one piece at a time and gives it back.
std::string sing([[int start]], int end = 0)
{
    //:: Start the result as an empty string.
    std::string result {[[""]]};
    //:: For each number from start down to end, add an empty line before all but the first, then its verse.
    for (int bottles {start}; bottles >= end; --bottles) {
        if (bottles < start) {
            result += "\n";
        }
        result += [[verse(bottles)]];
    }
    //:: Give back the result.
    return [[result]];
}

}  // namespace beer_song
```
