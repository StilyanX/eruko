# 67.02
Source: written
Write a function `ducks::verse(int ducks)` that returns the verse for that number of ducks as a `std::string` of one line ending in a newline.
For n of 2 or more, the line is `n ducks swim, 1 swims away.`; for 1, `1 duck swims away.`; for 0, `The pond is quiet.`.
Write a function `ducks::song(int start)` that returns the verses from start down to 0, with an empty line between 2 verses.
Limits: 0 ≤ start ≤ 99.
## Solution
```cpp
#pragma once

#include <string>

namespace ducks {

//: Write a function that tests each case in order and gives back the result of the first that holds.
std::string verse([[int ducks]])
{
    //:: Give back the verse for 0, for 1, else for any other number.
    if ([[ducks == 0]]) {
        return "The pond is quiet.\n";
    } else if (ducks == 1) {
        return "1 duck swims away.\n";
    } else {
        return std::to_string(ducks)
            + " ducks swim, 1 swims away.\n";
    }
}

//: Write a function that builds a new string one piece at a time and gives it back.
std::string song([[int start]])
{
    //:: Start the result as an empty string.
    std::string result {[[""]]};
    //:: For each number from start down to 0, add an empty line before all but the first, then its verse.
    for (int ducks {start}; ducks >= 0; --ducks) {
        if (ducks < start) {
            result += "\n";
        }
        result += [[verse(ducks)]];
    }
    //:: Give back the result.
    return [[result]];
}

}  // namespace ducks
```
## Slow
```cpp
#pragma once

#include <string>
#include <vector>

namespace ducks {

std::string verse(int ducks)
{
    std::string text {"The pond is quiet.\n"};
    if (ducks == 1) {
        text = "1 duck swims away.\n";
    }
    if (ducks >= 2) {
        text = std::to_string(ducks) + " ducks swim, 1 swims away.\n";
    }
    return text;
}

std::string song(int start)
{
    std::vector<std::string> verses {};
    for (int ducks {0}; ducks <= start; ++ducks) {
        verses.insert(verses.begin(), verse(ducks));
    }
    std::string result {verses[0]};
    for (std::size_t index {1}; index < verses.size(); ++index) {
        result += "\n" + verses[index];
    }
    return result;
}

}  // namespace ducks
```
