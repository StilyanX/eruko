# 37.01
Source: exercism scrabble-score
Write a function `scrabble_score::score(const std::string& word)` that returns the sum of the values of the word's letters, whatever their case.
The values: A, E, I, O, U, L, N, R, S, T are 1; D, G are 2; B, C, M, P are 3; F, H, V, W, Y are 4; K is 5; J, X are 8; Q, Z are 10.
The empty word scores 0.
Limits: 0 ≤ length of word ≤ 100; word holds letters only.
## Solution
```cpp
#pragma once

#include <array>
#include <cctype>
#include <string>

namespace scrabble_score {

//: Make a table of fixed values.
const [[std::array<int, 26>]] values {
    1, 3, 3, 2, 1, 4, 2, 4, 1, 8, 5, 1, 3,
    1, 1, 3, 10, 1, 1, 1, 1, 4, 4, 8, 4, 10};

//: Write a function that adds up a sequence and gives back the total.
int score([[const std::string& word]])
{
    //:: Start the total at zero.
    int total {[[0]]};
    //:: Add the value of each letter, made small, from the table.
    for (const char letter : word) {
        total += [[values.at(std::tolower(letter) - 'a')]];
    }
    //:: Give back the total.
    return [[total]];
}

}  // namespace scrabble_score
```
