# 19.02
Source: exercism roman-numerals
Write a function `roman_numerals::convert(int number)` that returns number in Roman numerals as a `std::string`.
The numerals are `M` 1000, `CM` 900, `D` 500, `CD` 400, `C` 100, `XC` 90, `L` 50, `XL` 40, `X` 10, `IX` 9, `V` 5, `IV` 4 and `I` 1.
Write as many of the largest numeral as fit in what is left of the number, then go on to the next largest.
Limits: 1 ≤ number ≤ 3999.
## Solution
```cpp
#pragma once

#include <string>
#include <utility>
#include <vector>

namespace roman_numerals {

//: Write a function that builds a new string one piece at a time and gives it back.
std::string convert([[int number]])
{
    //:: Make the list of values and their numerals, largest first.
    const std::vector<std::pair<int, std::string>> numerals {
        {1000, "M"}, {[[900, "CM"]]}, {500, "D"}, {400, "CD"},
        {100, "C"}, {90, "XC"}, {50, "L"}, {40, "XL"},
        {10, "X"}, {9, "IX"}, {5, "V"}, {4, "IV"}, {1, "I"}};
    //:: Start the result as an empty string.
    std::string result {[[""]]};
    //:: For each value, largest first, add its numeral while the value fits in the number.
    for (const auto& [value, numeral] : numerals) {
        while ([[number >= value]]) {
            result += numeral;
            number -= value;
        }
    }
    //:: Give back the result.
    return [[result]];
}

}  // namespace roman_numerals
```
