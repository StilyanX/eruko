# 19.01
Source: exercism raindrops
Write a function `raindrops::convert(int number)` that returns a string built from the divisors of the number.
Add `Pling` when 3 divides the number, then `Plang` when 5 divides it, then `Plong` when 7 divides it.
When none of 3, 5 and 7 divides the number, return the number itself in digits.
Limits: 1 ≤ number ≤ 10 000.
## Solution
```cpp
#pragma once

#include <string>

namespace raindrops {

//: Write a function that builds a new string one piece at a time and gives it back.
std::string convert([[int number]])
{
    //:: Start the result as an empty string.
    std::string result {[[""]]};
    //:: Add `Pling` when 3 divides the number.
    if ([[number % 3 == 0]]) {
        result += "Pling";
    }
    //:: Add `Plang` when 5 divides the number.
    if ([[number % 5 == 0]]) {
        result += "Plang";
    }
    //:: Add `Plong` when 7 divides the number.
    if ([[number % 7 == 0]]) {
        result += "Plong";
    }
    //:: Give back the number in digits for an empty result, else the result.
    if ([[result.empty()]]) {
        return std::to_string(number);
    }
    return result;
}

}  // namespace raindrops
```
