# 44.01
Source: exercism all-your-base
Write a function `all_your_base::convert(unsigned int input_base, const std::vector<unsigned int>& input_digits, unsigned int output_base)` that returns the digits of the same number in the output base.
The input digits come first digit first, each a number from 0 to the input base - 1; return the output digits first digit first too.
Leading zeros in the input count for nothing. A number of 0, from an empty list or from zeros alone, gives the empty list.
Throw `std::invalid_argument` when either base is below 2, or when a digit is not below the input base.
Limits: 0 ≤ input base, output base ≤ 1000; 0 ≤ number of input digits ≤ 20; the number is below 2^32.
## Solution
```cpp
#pragma once

#include <stdexcept>
#include <vector>

namespace all_your_base {

//: Write a function that adds up a sequence and gives back the total.
unsigned int to_number([[const std::vector<unsigned int>& digits]],
    unsigned int base)
{
    //:: Start the total at zero.
    unsigned int total {[[0]]};
    //:: For each digit, throw when it is not below the base, else times the total by the base and add the digit.
    for (const unsigned int digit : digits) {
        if ([[digit >= base]]) {
            throw std::invalid_argument {"digit too large"};
        }
        total = total * base + digit;
    }
    //:: Give back the total.
    return [[total]];
}

//: Write a function that repeats a step until a condition holds and gives back the result.
std::vector<unsigned int> to_digits([[unsigned int number]],
    unsigned int base)
{
    //:: Start the result as an empty list.
    [[std::vector<unsigned int>]] result {};
    //:: While the number is above 0, put its last digit in the base at the front of the result, then drop it.
    while ([[number > 0]]) {
        result.insert(result.begin(), number % base);
        number /= base;
    }
    //:: Give back the result.
    return [[result]];
}

//: Write a function that calls the functions above and gives back the answer.
std::vector<unsigned int> convert([[unsigned int input_base]],
    const std::vector<unsigned int>& input_digits,
    unsigned int output_base)
{
    //:: Throw `std::invalid_argument` when a base is below 2.
    if ([[input_base < 2 || output_base < 2]]) {
        throw std::invalid_argument {"a base is below 2"};
    }
    //:: Give back the digits of the number in the output base.
    return to_digits([[to_number(input_digits, input_base)]],
                     output_base);
}

}  // namespace all_your_base
```
