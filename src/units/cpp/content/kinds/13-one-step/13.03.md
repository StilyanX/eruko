# 13.03
Source: exercism gigasecond
Write a function `gigasecond::advance(const boost::posix_time::ptime& start)` that returns the moment 1,000,000,000 seconds after `start`, as a `boost::posix_time::ptime`.
Limits: none
## Solution
```cpp
#pragma once

#include <boost/date_time/posix_time/posix_time.hpp>

namespace gigasecond {

//: Write a function that gives back a value worked out in one step.
inline boost::posix_time::ptime advance(
    const boost::posix_time::ptime& start)
{
    return [[start + boost::posix_time::seconds {1'000'000'000}]];
}

}  // namespace gigasecond
```
