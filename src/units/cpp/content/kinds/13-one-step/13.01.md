# 13.01
Source: exercism hello-world
Write a function `hello_world::hello()` that returns the text `Hello, World!` as a `std::string`.
Limits: none
## Solution
```cpp
#pragma once

#include <string>

namespace hello_world {

//: Write a function that gives back a value worked out in one step.
[[std::string]] hello()
{
    //:: Give back the words `Hello, World!`.
    return [["Hello, World!"]];
}

}  // namespace hello_world
```
