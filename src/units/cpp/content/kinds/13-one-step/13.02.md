# 13.02
Source: exercism two-fer
Write a function `two_fer::two_fer(const std::string& name)` that returns the `std::string` `One for `, then the name, then `, one for me.`.
Called with no argument, it uses `you` as the name.
Limits: none
## Solution
```cpp
#pragma once

#include <string>

namespace two_fer {

//: Write a function that gives back a value worked out in one step.
std::string two_fer(const std::string& name = [["you"]])
{
    //:: Give back the words with the name between them.
    return "One for " + [[name]] + ", one for me.";
}

}  // namespace two_fer
```
