# 64.01
Source: exercism knapsack
Write a struct `knapsack::Item` with two `int` members, `weight` then `value`.
Write a function `knapsack::maximum_value(int maximum_weight, const std::vector<knapsack::Item>& items)` that returns the largest sum of values of items you can choose, each item at most once, whose weights add up to at most `maximum_weight`.
With no items it returns 0.
Limits: 0 ≤ items ≤ 100; 1 ≤ maximum_weight ≤ 1000; 1 ≤ each weight ≤ 1000; 1 ≤ each value ≤ 1000.
## Solution
```cpp
#pragma once

#include <algorithm>
#include <vector>

namespace knapsack {

//: Write a struct that holds several values together.
struct Item {
    int weight {[[0]]};
    int value {0};
};

//: Write a function that keeps the best value for each weight, one item at a time.
int maximum_value(int maximum_weight,
                  [[const std::vector<Item>& items]])
{
    //:: Start the best value for each weight from 0 to the most at 0.
    std::vector<int> best(maximum_weight + 1, [[0]]);
    //:: For each item, keep the larger of the best value without it and with it, heaviest weight first.
    for (const Item& item : items) {
        for (int w {maximum_weight}; w >= item.weight; --w) {
            const int with {best[w - item.weight] + item.value};
            best[w] = [[std::max(best[w], with)]];
        }
    }
    //:: Give back the best value for the most weight.
    return [[best.back()]];
}

}  // namespace knapsack
```
