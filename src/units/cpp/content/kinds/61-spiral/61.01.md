# 61.01
Source: exercism spiral-matrix
Write a function `spiral_matrix::spiral_matrix(std::uint32_t size)` that returns a square grid of `size` rows of `size` numbers each, as a `std::vector` of rows, each a `std::vector<std::uint32_t>`.
Fill it with the numbers from 1 to size × size, starting at the top left and moving right, turning right at each edge or at a filled cell, so the numbers wind inward clockwise.
Size 0 gives the empty grid.
Limits: 0 ≤ size ≤ 100.
## Solution
```cpp
#pragma once

#include <cstdint>
#include <utility>
#include <vector>

namespace spiral_matrix {

//: Give a type a short name.
using matrix = [[std::vector<std::vector<std::uint32_t>>]];

//: Write a function that gives back a value worked out in one step.
bool is_free([[const matrix& grid, int row, int column]])
{
    //:: Give back whether the cell is in the grid and still 0.
    return row >= 0 && row < std::ssize(grid) && column >= 0
        && column < std::ssize(grid) && [[grid[row][column] == 0]];
}

//: Write a function that fills a grid and gives it back.
matrix spiral_matrix([[std::uint32_t size]])
{
    //:: Start the grid with size rows of size zeros.
    matrix grid(size, std::vector<std::uint32_t>([[size]], 0));
    //:: Start at the top left, moving right.
    int row {0};
    int column {0};
    int down {0};
    int across {[[1]]};
    //:: For each number from 1 to size times size, put it in the cell, turn right when the next cell is not free, then move on.
    for (std::uint32_t number {1}; number <= size * size;
         ++number) {
        grid[row][column] = number;
        if ([[!is_free(grid, row + down, column + across)]]) {
            std::swap(down, across);
            across = -across;
        }
        row += down;
        column += across;
    }
    //:: Give back the grid.
    return [[grid]];
}

}  // namespace spiral_matrix
```
