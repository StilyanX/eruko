# 1.04
Write a program that reads 2 integers and prints the remainder of the first divided by the second.

Input: one line, 2 integers separated by a space.
Output: one line, one integer.
Limits: 0 ≤ first integer ≤ 100 000, 1 ≤ second integer ≤ 1000.

## Examples
```in
17 5
```
```out
2
```
```in
20 4
```
```out
0
```
## Solution
```cpp
#include <iostream>
#include <print>

int main()
{
    //: Read the input.
    int first {0};
    int second {0};
    std::cin >> [[first >> second]];
    //: Print the value.
    std::println("{}", [[first % second]]);
}
```
## Slow
```cpp
#include <iostream>
#include <print>

int main()
{
    int first {0};
    int second {0};
    std::cin >> first >> second;
    int rest {first};
    while (rest >= second) {
        rest -= second;
    }
    std::println("{}", rest);
}
```
