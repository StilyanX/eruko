# 1.09
Write a program that reads the length of the side of a cube and prints its volume.

Input: one line, one integer, the length of the side.
Output: one line, one integer.
Limits: 1 ≤ side ≤ 1000.

## Examples
```in
3
```
```out
27
```
## Solution
```cpp
#include <iostream>
#include <print>

int main()
{
    //: Read the input.
    int side {0};
    std::cin >> [[side]];
    //: Print the value.
    std::println("{}", [[side * side * side]]);
}
```
## Slow
```cpp
#include <iostream>
#include <print>

int main()
{
    int side {0};
    std::cin >> side;
    int volume {0};
    for (int layer {0}; layer < side; ++layer) {
        for (int row {0}; row < side; ++row) {
            volume += side;
        }
    }
    std::println("{}", volume);
}
```
