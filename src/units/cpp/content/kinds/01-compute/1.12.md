# 1.12
Write a program that reads an integer n and prints the sum of the integers from 1 to n.
The sum includes both 1 and n.

Input: one line, one integer n.
Output: one line, one integer.
Limits: 1 ≤ n ≤ 10 000.

## Examples
```in
4
```
```out
10
```
## Solution
```cpp
#include <iostream>
#include <print>

int main()
{
    //: Read the input.
    int n {0};
    std::cin >> [[n]];
    //: Print the value.
    std::println("{}", [[n * (n + 1) / 2]]);
}
```
## Slow
```cpp
#include <iostream>
#include <print>

int main()
{
    int n {0};
    std::cin >> n;
    int sum {0};
    for (int number {1}; number <= n; ++number) {
        sum += number;
    }
    std::println("{}", sum);
}
```
