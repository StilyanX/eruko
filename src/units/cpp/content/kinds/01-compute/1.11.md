# 1.11
Write a program that reads an integer and prints the sum of its 3 digits.

Input: one line, one integer.
Output: one line, one integer.
Limits: 100 ≤ the integer ≤ 999.

## Examples
```in
472
```
```out
13
```
## Solution
```cpp
#include <iostream>
#include <print>

int main()
{
    //: Read the input.
    int number {0};
    std::cin >> [[number]];
    //: Print the value.
    std::println(
        "{}", [[number / 100 + number / 10 % 10 + number % 10]]);
}
```
## Slow
```cpp
#include <iostream>
#include <print>
#include <string>

int main()
{
    int number {0};
    std::cin >> number;
    const std::string digits {std::to_string(number)};
    int sum {0};
    for (const char digit : digits) {
        sum += digit - '0';
    }
    std::println("{}", sum);
}
```
