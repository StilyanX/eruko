# 1.06
Write a program that reads the width and the height of a rectangle and prints its perimeter.

Input: one line, 2 integers, the width and the height, separated by a space.
Output: one line, one integer.
Limits: 1 ≤ width ≤ 10 000, 1 ≤ height ≤ 10 000.

## Examples
```in
3 5
```
```out
16
```
## Solution
```cpp
#include <iostream>
#include <print>

int main()
{
    //: Read the input.
    int width {0};
    int height {0};
    std::cin >> [[width >> height]];
    //: Print the value.
    std::println("{}", [[2 * (width + height)]]);
}
```
## Slow
```cpp
#include <iostream>
#include <print>

int main()
{
    int width {0};
    int height {0};
    std::cin >> width >> height;
    int length {0};
    for (int side {0}; side < 4; ++side) {
        int steps {side % 2 == 0 ? width : height};
        for (int step {0}; step < steps; ++step) {
            ++length;
        }
    }
    std::println("{}", length);
}
```
