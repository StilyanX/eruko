# 1.07
Write a program that reads 3 integers and prints their average, rounded down to a whole number.

Input: one line, 3 integers separated by spaces.
Output: one line, one integer.
Limits: 0 ≤ each integer ≤ 1000.

## Examples
```in
4 5 7
```
```out
5
```
## Solution
```cpp
#include <iostream>
#include <print>

int main()
{
    //: Read the input.
    int first {0};
    int second {0};
    int third {0};
    std::cin >> [[first >> second >> third]];
    //: Print the value.
    std::println("{}", [[(first + second + third) / 3]]);
}
```
## Slow
```cpp
#include <iostream>
#include <print>

int main()
{
    int first {0};
    int second {0};
    int third {0};
    std::cin >> first >> second >> third;
    int average {0};
    while (3 * (average + 1) <= first + second + third) {
        ++average;
    }
    std::println("{}", average);
}
```
