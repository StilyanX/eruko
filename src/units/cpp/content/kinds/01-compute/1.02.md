# 1.02
Write a program that reads a time as hours and minutes and prints it in minutes.

Input: one line, 2 integers, the hours and the minutes, separated by a space.
Output: one line, one integer.
Limits: 0 ≤ hours ≤ 1000, 0 ≤ minutes ≤ 59.

## Examples
```in
2 15
```
```out
135
```
## Solution
```cpp
#include <iostream>
#include <print>

int main()
{
    //: Read the input.
    int hours {0};
    int minutes {0};
    std::cin >> [[hours >> minutes]];
    //: Print the value.
    std::println("{}", [[hours * 60 + minutes]]);
}
```
## Slow
```cpp
#include <iostream>
#include <print>

int main()
{
    int hours {0};
    int minutes {0};
    std::cin >> hours >> minutes;
    int total {0};
    for (int hour {0}; hour < hours; ++hour) {
        for (int minute {0}; minute < 60; ++minute) {
            ++total;
        }
    }
    for (int minute {0}; minute < minutes; ++minute) {
        ++total;
    }
    std::println("{}", total);
}
```
