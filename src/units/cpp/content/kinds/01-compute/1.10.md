# 1.10
Write a program that reads 2 integers and prints the square of their difference.

Input: one line, 2 integers separated by a space.
Output: one line, one integer.
Limits: -1000 ≤ each integer ≤ 1000.

## Examples
```in
3 7
```
```out
16
```
## Solution
```cpp
#include <iostream>
#include <print>

int main()
{
    //: Read the input.
    int first {0};
    int second {0};
    std::cin >> [[first >> second]];
    //: Print the value.
    std::println("{}", [[(first - second) * (first - second)]]);
}
```
## Slow
```cpp
#include <cstdlib>
#include <iostream>
#include <print>

int main()
{
    int first {0};
    int second {0};
    std::cin >> first >> second;
    const int distance {std::abs(first - second)};
    int square {0};
    for (int step {0}; step < distance; ++step) {
        square += distance;
    }
    std::println("{}", square);
}
```
