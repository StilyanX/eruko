# 1.08
Write a program that reads an integer and prints its last digit.

Input: one line, one integer.
Output: one line, one integer.
Limits: 0 ≤ the integer ≤ 1 000 000 000.

## Examples
```in
2026
```
```out
6
```
## Solution
```cpp
#include <iostream>
#include <print>

int main()
{
    //: Read the input.
    int number {0};
    std::cin >> [[number]];
    //: Print the value.
    std::println("{}", [[number % 10]]);
}
```
## Slow
```cpp
#include <iostream>
#include <print>
#include <string>

int main()
{
    int number {0};
    std::cin >> number;
    const std::string digits {std::to_string(number)};
    std::println("{}", digits.back());
}
```
