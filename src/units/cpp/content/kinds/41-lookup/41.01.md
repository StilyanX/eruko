# 41.01
Source: exercism kindergarten-garden
Write a function `kindergarten_garden::plants(std::string_view diagram, std::string_view student)` that returns the 4 plants of student as a `std::array<Plants, 4>`.
The header also defines `enum class kindergarten_garden::Plants { clover, grass, radishes, violets }`.
The diagram holds 2 rows of the same length, split by a newline; each letter is a plant: `C` clover, `G` grass, `R` radishes, `V` violets.
The students, in order, are Alice, Bob, Charlie, David, Eve, Fred, Ginny, Harriet, Ileana, Joseph, Kincaid and Larry; student k, counting from 0, has the letters at positions 2k and 2k + 1 of each row.
Return the plants of the first row's 2 letters, then of the second row's.
Limits: each row holds from 2 to 24 letters; student is one of the 12 names and has letters in the diagram.
## Solution
```cpp
#pragma once

#include <array>
#include <string>
#include <string_view>

namespace kindergarten_garden {

//: Name each possible value in an `enum class`.
enum class Plants { [[clover]], grass, radishes, violets };

//: Write a function that tests each case in order and gives back the result of the first that holds.
Plants plant([[char letter]])
{
    //:: Give back clover for `C`, grass for `G`, radishes for `R`, else violets.
    if ([[letter == 'C']]) {
        return Plants::clover;
    } else if (letter == 'G') {
        return Plants::grass;
    } else if (letter == 'R') {
        return Plants::radishes;
    } else {
        return Plants::violets;
    }
}

//: Write a function that finds the first item that passes a test and gives back its position.
int position([[std::string_view student]])
{
    //:: Make the list of students, in order.
    const std::array<std::string_view, 12> students {
        [["Alice"]], "Bob", "Charlie", "David",
        "Eve", "Fred", "Ginny", "Harriet",
        "Ileana", "Joseph", "Kincaid", "Larry"};
    //:: Give back the index of the first student in the list equal to the student, else -1.
    for (int index {0}; index < std::ssize(students); ++index) {
        if ([[students[index] == student]]) {
            return index;
        }
    }
    return -1;
}

//: Write a function that gives back a value worked out in one step.
std::array<Plants, 4> plants([[std::string_view diagram]],
                             std::string_view student)
{
    //:: Work out where the student's letters start in each row.
    const int first {2 * position(student)};
    const int length {static_cast<int>(diagram.find('\n'))};
    const int second {[[first + length + 1]]};
    //:: Give back the plants of the student's 2 letters in each row.
    return {plant(diagram[first]), plant(diagram[first + 1]),
            plant(diagram[second]), [[plant(diagram[second + 1])]]};
}

}  // namespace kindergarten_garden
```
