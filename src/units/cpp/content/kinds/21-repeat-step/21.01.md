# 21.01
Source: exercism collatz-conjecture
Write a function `collatz_conjecture::steps(int value)` that returns how many steps take the number to 1.
In one step, an even number is halved, and an odd number becomes 3 times itself plus 1.
For 1 it returns 0.
For a number below 1 it throws `std::domain_error`.
Limits: -1 000 000 ≤ value ≤ 1 000 000.
## Solution
```cpp
#pragma once

#include <stdexcept>

namespace collatz_conjecture {

//: Write a function that repeats a step until a condition holds and gives back the result.
int steps([[int value]])
{
    //:: Throw `std::domain_error` for a number below 1.
    if ([[value < 1]]) {
        throw std::domain_error {"only positive numbers"};
    }
    //:: Start the count at zero.
    int count {[[0]]};
    //:: While the test holds, change the number and add one to the count.
    while ([[value != 1]]) {
        if (value % 2 == 0) {
            value /= 2;
        } else {
            value = 3 * value + 1;
        }
        ++count;
    }
    //:: Give back the count.
    return [[count]];
}

}  // namespace collatz_conjecture
```
