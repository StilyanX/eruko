# 21.02
Source: exercism prime-factors
Write a function `prime_factors::of(long long number)` that returns a `std::vector<long long>` of the prime factors of number, smallest first, each as many times as it divides number.
For 1 it returns an empty list.
Limits: 1 ≤ number ≤ 100 000 000 000; no prime factor of number is above 1 000 000.
## Solution
```cpp
#pragma once

#include <vector>

namespace prime_factors {

//: Write a function that repeats a step until a condition holds and gives back the result.
std::vector<long long> of([[long long number]])
{
    //:: Start the result as an empty list.
    std::vector<long long> factors [[{}]];
    //:: Start the divisor at 2.
    long long divisor {[[2]]};
    //:: While the number is above 1, take out the divisor when it divides the number, else add one to it.
    while ([[number > 1]]) {
        if (number % divisor == 0) {
            factors.push_back(divisor);
            number /= divisor;
        } else {
            ++divisor;
        }
    }
    //:: Give back the result.
    return [[factors]];
}

}  // namespace prime_factors
```
