# 45.01
Source: exercism robot-simulator
Write a class `robot_simulator::Robot` whose objects stand on a grid of whole-number points (x, y), each facing one of the values of an enum class `robot_simulator::Bearing`: `NORTH`, `EAST`, `SOUTH` and `WEST`.
x grows to the east and y grows to the north.
`Robot()` stands at (0, 0) facing `NORTH`; `Robot(std::pair<int, int> position, Bearing bearing)` stands at the position with the bearing.
`get_position()` returns the position as a `std::pair<int, int>`, and `get_bearing()` returns the bearing.
`turn_right()` and `turn_left()` turn it a quarter turn to the right or the left, in place.
`advance()` moves it 1 point in the direction it faces.
`execute_sequence(const std::string& instructions)` runs each letter of the text in order: `R` turns right, `L` turns left and `A` advances.
Limits: -10 ≤ x, y ≤ 10 at the start; 0 ≤ length of the instructions ≤ 12, each `R`, `L` or `A`.
## Solution
```cpp
#pragma once

#include <string>
#include <utility>

namespace robot_simulator {

//: Name each possible value in an `enum class`.
enum class Bearing { [[NORTH]], EAST, SOUTH, WEST };

//: Write a class that keeps its data in private members.
class Robot {
    std::pair<int, int> position_ [[{0, 0}]];
    Bearing bearing_ {Bearing::NORTH};
public:
    //: Write a constructor that sets the data.
    Robot() = default;
    Robot(std::pair<int, int> position, Bearing bearing)
        : position_ {[[position]]}, bearing_ {bearing}
    {
    }
    //: Write member functions that give back the data.
    std::pair<int, int> get_position() const
    {
        return [[position_]];
    }
    Bearing get_bearing() const
    {
        return bearing_;
    }
    //: Write member functions that turn it a quarter turn to the right or to the left.
    void turn_right()
    {
        const int next {[[(static_cast<int>(bearing_) + 1) % 4]]};
        bearing_ = static_cast<Bearing>(next);
    }
    void turn_left()
    {
        const int next {(static_cast<int>(bearing_) + 3) % 4};
        bearing_ = static_cast<Bearing>(next);
    }
    //: Write a member function that moves it one point in the direction it faces.
    void advance()
    {
        if ([[bearing_ == Bearing::NORTH]]) {
            ++position_.second;
        } else if (bearing_ == Bearing::EAST) {
            ++position_.first;
        } else if (bearing_ == Bearing::SOUTH) {
            --position_.second;
        } else {
            --position_.first;
        }
    }
    //: Write a member function that runs each instruction of the text in turn.
    void execute_sequence(const std::string& instructions)
    {
        for (const char instruction : instructions) {
            if ([[instruction == 'R']]) {
                turn_right();
            } else if (instruction == 'L') {
                turn_left();
            } else {
                advance();
            }
        }
    }
};

}  // namespace robot_simulator
```
