# 3.05
Write a program that reads an integer and prints it, with 10 taken off when it is 100 or more.

Input: one line, one integer.
Output: one line, one integer.
Limits: 0 ≤ the integer ≤ 100 000.

## Examples
```in
250
```
```out
240
```
```in
60
```
```out
60
```
## Solution
```cpp
#include <iostream>
#include <print>

int main()
{
    //: Read the input.
    int number {0};
    std::cin >> [[number]];
    //: Print the first result if the test holds, else the second.
    if ([[number >= 100]]) {
        std::println("{}", number - 10);
    } else {
        std::println("{}", number);
    }
}
```
## Slow
```cpp
#include <iostream>
#include <print>

int main()
{
    int number {0};
    std::cin >> number;
    int off {0};
    for (int step {100}; step <= number && off == 0; ++step) {
        off = 10;
    }
    std::println("{}", number - off);
}
```
