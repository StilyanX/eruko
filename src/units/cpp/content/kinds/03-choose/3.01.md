# 3.01
Write a program that reads 2 integers and prints the larger of them.

Input: one line, 2 integers separated by a space.
Output: one line, one integer.
Limits: -1000 ≤ each integer ≤ 1000.

## Examples
```in
3 8
```
```out
8
```
## Solution
```cpp
#include <iostream>
#include <print>

int main()
{
    //: Read the input.
    int first {0};
    int second {0};
    std::cin >> [[first >> second]];
    //: Print the first result if the test holds, else the second.
    if ([[first > second]]) {
        std::println("{}", first);
    } else {
        std::println("{}", second);
    }
}
```
