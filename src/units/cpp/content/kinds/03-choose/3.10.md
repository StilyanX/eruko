# 3.10
Write a program that reads the minutes past the hour and prints the minutes left until the next full hour.

Input: one line, one integer, the minutes past the hour.
Output: one line, one integer, 0 when the minutes are 0.
Limits: 0 ≤ minutes ≤ 59.

## Examples
```in
45
```
```out
15
```
```in
0
```
```out
0
```
## Solution
```cpp
#include <iostream>
#include <print>

int main()
{
    //: Read the input.
    int minutes {0};
    std::cin >> [[minutes]];
    //: Print the first result if the test holds, else the second.
    if ([[minutes == 0]]) {
        std::println("0");
    } else {
        std::println("{}", 60 - minutes);
    }
}
```
## Slow
```cpp
#include <iostream>
#include <print>

int main()
{
    int minutes {0};
    std::cin >> minutes;
    int left {0};
    int clock {minutes};
    while (clock % 60 != 0) {
        ++clock;
        ++left;
    }
    std::println("{}", left);
}
```
