# 3.11
Write a program that reads 2 integers and prints Yes when they have the same last digit, else No.

Input: one line, 2 integers separated by a space.
Output: one line.
Limits: 0 ≤ each integer ≤ 100 000.

## Examples
```in
47 1287
```
```out
Yes
```
```in
30 3
```
```out
No
```
## Solution
```cpp
#include <iostream>
#include <print>

int main()
{
    //: Read the input.
    int first {0};
    int second {0};
    std::cin >> [[first >> second]];
    //: Print the first result if the test holds, else the second.
    if ([[first % 10 == second % 10]]) {
        std::println("Yes");
    } else {
        std::println("No");
    }
}
```
## Slow
```cpp
#include <iostream>
#include <print>
#include <string>

int main()
{
    int first {0};

    std::cin >> first >> second;
    const std::string first_digits {std::to_string(first)};
    const std::string second_digits {std::to_string(second)};
    if (first_digits.back() == second_digits.back()) {
        std::println("Yes");
    } else {
        std::println("No");
    }
}
```
