# 3.02
Write a program that reads an integer and prints it without its minus sign.

Input: one line, one integer.
Output: one line, one integer.
Limits: -100 000 ≤ the integer ≤ 100 000.

## Examples
```in
-42
```
```out
42
```
```in
17
```
```out
17
```
## Solution
```cpp
#include <iostream>
#include <print>

int main()
{
    //: Read the input.
    int number {0};
    std::cin >> [[number]];
    //: Print the first result if the test holds, else the second.
    if ([[number < 0]]) {
        std::println("{}", -number);
    } else {
        std::println("{}", number);
    }
}
```
