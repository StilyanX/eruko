# 3.07
Write a program that reads an integer n and prints half of n when n is even.
When n is odd, print 3 times n plus 1.

Input: one line, one integer n.
Output: one line, one integer.
Limits: 1 ≤ n ≤ 100 000.

## Examples
```in
6
```
```out
3
```
```in
7
```
```out
22
```
## Solution
```cpp
#include <iostream>
#include <print>

int main()
{
    //: Read the input.
    int n {0};
    std::cin >> [[n]];
    //: Print the first result if the test holds, else the second.
    if ([[n % 2 == 0]]) {
        std::println("{}", n / 2);
    } else {
        std::println("{}", 3 * n + 1);
    }
}
```
