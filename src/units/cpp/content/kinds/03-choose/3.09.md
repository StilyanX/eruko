# 3.09
Write a program that reads an integer and prints the greatest even integer that is not greater than it.

Input: one line, one integer.
Output: one line, one integer.
Limits: -1000 ≤ the integer ≤ 1000.

## Examples
```in
7
```
```out
6
```
```in
-3
```
```out
-4
```
## Solution
```cpp
#include <iostream>
#include <print>

int main()
{
    //: Read the input.
    int number {0};
    std::cin >> [[number]];
    //: Print the first result if the test holds, else the second.
    if ([[number % 2 == 0]]) {
        std::println("{}", number);
    } else {
        std::println("{}", number - 1);
    }
}
```
