# 3.03
Write a program that reads 2 integers and prints Yes when the first divides the second, else No.

Input: one line, 2 integers separated by a space.
Output: one line.
Limits: 1 ≤ first integer ≤ 1000, 0 ≤ second integer ≤ 1 000 000.

## Examples
```in
4 12
```
```out
Yes
```
```in
5 12
```
```out
No
```
## Solution
```cpp
#include <iostream>
#include <print>

int main()
{
    //: Read the input.
    int first {0};
    int second {0};
    std::cin >> [[first >> second]];
    //: Print the first result if the test holds, else the second.
    if ([[second % first == 0]]) {
        std::println("Yes");
    } else {
        std::println("No");
    }
}
```
