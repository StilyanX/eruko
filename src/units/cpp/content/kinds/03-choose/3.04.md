# 3.04
Write a program that reads a score and prints pass when it is 50 or more, else fail.

Input: one line, one integer, the score.
Output: one line.
Limits: 0 ≤ score ≤ 100.

## Examples
```in
73
```
```out
pass
```
```in
12
```
```out
fail
```
## Solution
```cpp
#include <iostream>
#include <print>

int main()
{
    //: Read the input.
    int score {0};
    std::cin >> [[score]];
    //: Print the first result if the test holds, else the second.
    if ([[score >= 50]]) {
        std::println("pass");
    } else {
        std::println("fail");
    }
}
```
## Slow
```cpp
#include <iostream>
#include <print>
#include <string>

int main()
{
    int score {0};
    std::cin >> score;
    std::string result {"fail"};
    for (int mark {50}; mark <= 100; ++mark) {
        if (mark == score) {
            result = "pass";
        }
    }
    std::println("{}", result);
}
```
