# 3.08
Write a program that reads 2 integers and prints Yes when their product is greater than 0, else No.

Input: one line, 2 integers separated by a space.
Output: one line.
Limits: -1000 ≤ each integer ≤ 1000.

## Examples
```in
-3 -4
```
```out
Yes
```
```in
5 -2
```
```out
No
```
## Solution
```cpp
#include <iostream>
#include <print>

int main()
{
    //: Read the input.
    int first {0};
    int second {0};
    std::cin >> [[first >> second]];
    //: Print the first result if the test holds, else the second.
    if ([[first * second > 0]]) {
        std::println("Yes");
    } else {
        std::println("No");
    }
}
```
## Slow
```cpp
#include <iostream>
#include <print>

int main()
{
    int first {0};
    int second {0};
    std::cin >> first >> second;
    const bool positive {(first > 0 && second > 0) || (first < 0 && second < 0)};
    std::println("{}", positive ? "Yes" : "No");
}
```
