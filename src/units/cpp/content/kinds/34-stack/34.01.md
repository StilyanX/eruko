# 34.01
Source: exercism matching-brackets
Write a function `matching_brackets::check(const std::string& expression)` that returns whether the brackets `()`, `[]` and `{}` in the text pair up and nest correctly.
Every closing bracket must close the latest opening bracket still open, of the same shape, and no bracket may stay open at the end.
Ignore every other character. The empty text gives `true`.
Limits: 0 ≤ length of the text ≤ 1000.
## Solution
```cpp
#pragma once

#include <string>

namespace matching_brackets {

//: Write a function that keeps a stack of characters, adding to and taking from its end, and gives back the answer.
bool check([[const std::string& expression]])
{
    //:: Start the closing brackets needed as an empty string.
    std::string needed {[[""]]};
    //:: For each character, add the closing bracket an opening one needs, and give back false for a closing one that is not the last needed, else take it off.
    for (const char character : expression) {
        if (character == '(') {
            needed += ')';
        } else if (character == '[') {
            needed += ']';
        } else if (character == '{') {
            needed += '}';
        } else if (character == ')' || character == ']'
                   || character == '}') {
            if ([[needed.empty() || needed.back() != character]]) {
                return false;
            }
            needed.pop_back();
        }
    }
    //:: Give back whether no closing bracket is still needed.
    return [[needed.empty()]];
}

}  // namespace matching_brackets
```
