# 70.01
Source: exercism zebra-puzzle
Write a function `zebra_puzzle::solve()` that returns a `zebra_puzzle::Solution`, a struct with 2 `std::string` members: `drinksWater`, the nation of the one who drinks water, and `ownsZebra`, the nation of the one who owns the zebra.
There are 5 houses in a row, numbered 1 to 5 from the left. Each has one of 5 colors (red, green, ivory, yellow, blue), one of 5 nations (`Englishman`, `Spaniard`, `Ukrainian`, `Norwegian`, `Japanese`), one of 5 drinks (coffee, tea, milk, orange juice, water), one of 5 hobbies (dancing, painting, reading, football, chess) and one of 5 pets (dog, snail, fox, horse, zebra), and no two houses share any of these.
These 14 facts hold:
- The Englishman lives in the red house.
- The Spaniard owns the dog.
- The green house drinks coffee.
- The Ukrainian drinks tea.
- The green house is just right of the ivory house.
- The snail's owner likes dancing.
- The yellow house likes painting.
- The middle house drinks milk.
- The Norwegian lives in house 1.
- The house that likes reading is next to the house with the fox.
- The house that likes painting is next to the house with the horse.
- The house that likes football drinks orange juice.
- The Japanese likes chess.
- The Norwegian lives next to the blue house.
Exactly one way of filling the houses fits every fact.
Limits: none.
## Solution
```cpp
#pragma once

#include <algorithm>
#include <array>
#include <cstdlib>
#include <string>

namespace zebra_puzzle {

//: Write a struct that holds several values together.
struct Solution {
    [[std::string]] drinksWater {};
    std::string ownsZebra {};
};

//: Name the place of each value in its list.
enum { red, green, ivory, yellow, blue };
enum { [[english]], spanish, ukrainian, norwegian, japanese };
enum { coffee, tea, milk, juice, water };
enum { dance, paint, read, ball, chess };
enum { dog, snail, fox, horse, zebra };

//: Make a table of fixed values.
const std::array<std::string, 5> names {
    [["Englishman"]], "Spaniard", "Ukrainian", "Norwegian",
    "Japanese"};

//: Write a function that gives back a value worked out in one step.
std::string name_at(const std::array<int, 5>& nation, [[int house]])
{
    //:: Give back the name of the nation in the house.
    const auto place {[[std::ranges::find(nation, house)]]};
    return names[place - nation.begin()];
}

//: Write a function that gives back a value worked out in one step.
bool near([[int first, int second]])
{
    //:: Give back whether the 2 houses are side by side.
    return [[std::abs(first - second) == 1]];
}

//: Write a function that gives back a value worked out in one step.
bool next_order([[std::array<int, 5>& order]])
{
    //:: Change the list to its next order, and give back false after the last.
    return [[std::ranges::next_permutation(order)]].found;
}

//: Write a function that tries each order until one passes every test.
Solution solve()
{
    std::array<int, 5> color {[[0, 1, 2, 3, 4]]};
    std::array<int, 5> nation {0, 1, 2, 3, 4};
    std::array<int, 5> drink {0, 1, 2, 3, 4};
    std::array<int, 5> hobby {0, 1, 2, 3, 4};
    std::array<int, 5> pet {0, 1, 2, 3, 4};
    //:: Try each order of the colors with green just right of ivory.
    do {
        if ([[color[green] != color[ivory] + 1]]) {
            continue;
        }
        //:: Try each order of the nations that fits the colors.
        do {
            if ([[nation[english] != color[red]]]
                || nation[norwegian] != 0
                || !near(nation[norwegian], color[blue])) {
                continue;
            }
            //:: Try each order of the drinks that fits.
            do {
                if ([[drink[coffee] != color[green]]]
                    || drink[tea] != nation[ukrainian]
                    || drink[milk] != 2) {
                    continue;
                }
                //:: Try each order of the hobbies that fits.
                do {
                    if ([[hobby[paint] != color[yellow]]]
                        || hobby[ball] != drink[juice]
                        || hobby[chess] != nation[japanese]) {
                        continue;
                    }
                    //:: Give back the answer for the first order of pets that fits.
                    do {
                        if ([[pet[dog] == nation[spanish]]]
                            && pet[snail] == hobby[dance]
                            && near(pet[fox], hobby[read])
                            && near(pet[horse], hobby[paint])) {
                            return Solution {
                                name_at(nation, drink[water]),
                                name_at(nation, pet[zebra])};
                        }
                    } while (next_order(pet));
                } while (next_order(hobby));
            } while (next_order(drink));
        } while (next_order(nation));
    } while (next_order(color));
    return {};
}

}  // namespace zebra_puzzle
```
