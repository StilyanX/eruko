# 31.03
Source: exercism binary
Write a function `binary::convert(const std::string& text)` that returns, as an `int`, the value of text read as a number in base 2.
It returns 0 when text holds any character other than `0` and `1`.
Limits: text holds at most 30 characters.
## Solution
```cpp
#pragma once

#include <string>

namespace binary {

//: Write a function that adds up a sequence and gives back the total.
int convert([[const std::string& text]])
{
    //:: Start the result at zero.
    int result {[[0]]};
    //:: For each character, give back 0 when it is not `0` or `1`, else add it as a new last digit of the result.
    for (const char character : text) {
        if (character != '0' && [[character != '1']]) {
            return 0;
        }
        result = result * 2 + (character - '0');
    }
    //:: Give back the result.
    return [[result]];
}

}  // namespace binary
```
