# 31.05
Source: exercism eliuds-eggs
Write a function `chicken_coop::positions_to_quantity(int number)` that returns how many of the digits of the number, written in binary, are 1.
It must not use a library function that does this.
Limits: 0 ≤ number ≤ 2 000 000 000.
## Solution
```cpp
#pragma once

namespace chicken_coop {

//: Write a function that adds up a sequence and gives back the total.
int positions_to_quantity([[int number]])
{
    //:: Start the total at zero.
    int total {[[0]]};
    //:: Add each last binary digit to the total, then drop it from the number.
    while (number > 0) {
        total += [[number % 2]];
        number /= 2;
    }
    //:: Give back the total.
    return [[total]];
}

}  // namespace chicken_coop
```
