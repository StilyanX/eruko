# 31.01
Source: exercism sum-of-multiples
Write a function `sum_of_multiples::to(const std::vector<int>& factors, int limit)` that returns the sum of every whole number from 1 to limit - 1 that at least one of the factors divides.
Each number counts once, however many factors divide it.
With no factors, or a limit of 1 or less, it returns 0.
Limits: 0 ≤ limit ≤ 10 000; 0 to 3 factors, each from 1 to 50.
## Solution
```cpp
#pragma once

#include <vector>

namespace sum_of_multiples {

//: Write a function that adds up a sequence and gives back the total.
int to([[const std::vector<int>& factors]], int limit)
{
    //:: Start the total at zero.
    int total {[[0]]};
    //:: Add each number from 1 to the limit - 1 that one of the factors divides.
    for (int number {1}; number < limit; ++number) {
        for (const int factor : factors) {
            if ([[number % factor == 0]]) {
                total += number;
                break;
            }
        }
    }
    //:: Give back the total.
    return [[total]];
}

}  // namespace sum_of_multiples
```
