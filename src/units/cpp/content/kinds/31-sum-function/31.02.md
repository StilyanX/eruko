# 31.02
Source: exercism trinary
Write a function `trinary::to_decimal(const std::string& text)` that returns the value of the text read as a number in base 3.
Each character is a digit 0, 1 or 2, and the last digit counts ones, the one before it threes, the one before that nines, and so on.
When any character is not 0, 1 or 2, return 0.
Limits: 1 ≤ length of the text ≤ 15.
## Solution
```cpp
#pragma once

#include <string>

namespace trinary {

//: Write a function that adds up a sequence and gives back the total.
int to_decimal([[const std::string& text]])
{
    //:: Start the total at zero.
    int total {[[0]]};
    //:: For each character, give back 0 when it is not 0, 1 or 2, else times the total by 3 and add the digit.
    for (const char character : text) {
        if ([[character < '0' || character > '2']]) {
            return 0;
        }
        total = total * 3 + (character - '0');
    }
    //:: Give back the total.
    return [[total]];
}

}  // namespace trinary
```
