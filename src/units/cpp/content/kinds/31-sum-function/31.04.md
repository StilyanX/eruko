# 31.04
Source: exercism hexadecimal
Write a function `hexadecimal::convert(const std::string& text)` that returns the value of the text read as a number in base 16, with the digits 0 to 9 and `a` to `f`.
It returns 0 when the text holds any other character.
Do it without a library function that reads numbers.
Limits: 1 ≤ length of text ≤ 7; text holds small letters and digits.
## Solution
```cpp
#pragma once

#include <string>

namespace hexadecimal {

//: Write a function that adds up a sequence and gives back the total.
int convert([[const std::string& text]])
{
    //:: Start the total at zero.
    int total {[[0]]};
    //:: Add each digit to 16 times the total, and give back 0 at any other character.
    for (const char character : text) {
        if (character >= '0' && character <= '9') {
            total = total * 16 + character - '0';
        } else if ([[character >= 'a' && character <= 'f']]) {
            total = total * 16 + character - 'a' + 10;
        } else {
            return 0;
        }
    }
    //:: Give back the total.
    return [[total]];
}

}  // namespace hexadecimal
```
