# 11.11
Write a program that reads n words and prints each different word with how often it appears.
Print once for 1 time, twice for 2 times, and many for more.

Input: line 1, n; line 2, n words separated by spaces.
Output: one line per different word, in alphabetical order: the word, a space, then once, twice or many.
Limits: 1 ≤ n ≤ 100, each word 1 to 10 lowercase letters.

## Examples
```in
6
fig oak fig elm oak fig
```
```out
elm once
fig many
oak twice
```
## Solution
```cpp
#include <iostream>
#include <map>
#include <print>
#include <string>

int main()
{
    //: Read how many words follow.
    int n {0};
    std::cin >> [[n]];
    //: Start an empty map from each word to its count.
    std::map<std::string, int> counts [[{}]];
    //: For each index from 0 to n - 1, read a word and add one to its count.
    for (int index {0}; index < [[n]]; ++index) {
        std::string word {};
        std::cin >> word;
        //:: Add one to the word's count.
        [[++counts]][word];
    }
    //: Go through each word and its count in the map, in alphabetical order.
    for (const auto& [word, count] : [[counts]]) {
        //:: Print the word, then once, twice or many for its count.
        if ([[count == 1]]) {
            std::println("{} once", word);
        } else if (count == 2) {
            std::println("{} twice", word);
        } else {
            std::println("{} many", word);
        }
    }
}
```
## Slow
```cpp
#include <iostream>
#include <print>
#include <string>
#include <vector>

int main()
{
    int n {0};
    std::cin >> n;
    std::vector<std::string> words(n);
    for (auto& w : words) std::cin >> w;
    std::vector<std::string> seen;
    for (const auto& w : words) {
        bool found {false};
        for (const auto& s : seen) if (s == w) found = true;
        if (!found) seen.push_back(w);
    }
    for (std::size_t i {0}; i < seen.size(); ++i)
        for (std::size_t j {i + 1}; j < seen.size(); ++j)
            if (seen[j] < seen[i]) std::swap(seen[i], seen[j]);
    for (const auto& word : seen) {
        int count {0};
        for (const auto& w : words) if (w == word) ++count;
        std::println("{} {}", word, count == 1 ? "once" : count == 2 ? "twice" : "many");
    }
}
```
