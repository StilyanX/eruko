# 11.14
Write a program that reads n words and prints each different word.
After a word that appears more than once, also print how many times it appears.

Input: line 1, n; then n lines, one word on each.
Output: one line per different word, in alphabetical order: the word alone, or the word, a space, then one integer.
Limits: 1 ≤ n ≤ 100, each word 1 to 10 lowercase letters.

## Examples
```in
5
kiwi
lime
kiwi
fig
kiwi
```
```out
fig
kiwi 3
lime
```
## Solution
```cpp
#include <iostream>
#include <map>
#include <print>
#include <string>

int main()
{
    //: Read how many words follow.
    int n {0};
    std::cin >> [[n]];
    //: Start an empty map from each word to its count.
    std::map<std::string, int> counts [[{}]];
    //: For each index from 0 to n - 1, read a word and add one to its count.
    for (int index {0}; index < [[n]]; ++index) {
        std::string word {};
        std::cin >> word;
        //:: Add one to the word's count.
        [[++counts]][word];
    }
    //: Go through each word and its count in the map, in alphabetical order.
    for (const auto& [word, count] : [[counts]]) {
        //:: Print the word, adding its count when the count is more than 1.
        if ([[count > 1]]) {
            std::println("{} {}", word, count);
        } else {
            std::println("{}", word);
        }
    }
}
```
## Slow
```cpp
#include <iostream>
#include <print>
#include <string>
#include <vector>

int main()
{
    int n {0};
    std::cin >> n;
    std::vector<std::string> words(n);
    for (auto& w : words) std::cin >> w;
    std::vector<std::string> seen;
    for (const auto& w : words) {
        bool found {false};
        for (const auto& s : seen) if (s == w) found = true;
        if (!found) seen.push_back(w);
    }
    for (std::size_t i {0}; i < seen.size(); ++i)
        for (std::size_t j {i + 1}; j < seen.size(); ++j)
            if (seen[j] < seen[i]) std::swap(seen[i], seen[j]);
    for (const auto& word : seen) {
        int count {0};
        for (const auto& w : words) if (w == word) ++count;
        if (count == 1) std::println("{}", word);
        else std::println("{} {}", word, count);
    }
}
```
