# 40.01
Source: exercism yacht
Write a function `yacht::score(std::array<int, 5> dice, const std::string& category)` that returns the score of the 5 dice in the category, as an `int`.
- `ones`, `twos`, `threes`, `fours`, `fives`, `sixes`: that face times how many dice show it.
- `full house`: the sum of the dice when 3 show one face and 2 show another.
- `four of a kind`: 4 times the face that at least 4 dice show.
- `little straight`: 30 when the dice show 1, 2, 3, 4 and 5.
- `big straight`: 30 when the dice show 2, 3, 4, 5 and 6.
- `choice`: the sum of the dice.
- `yacht`: 50 when all 5 dice show the same face.
Dice that do not fit the category score 0; 5 equal dice are not a full house.
Limits: each die is from 1 to 6, in any order; the category is one of the 12 above.
## Solution
```cpp
#pragma once

#include <algorithm>
#include <array>
#include <string>

namespace yacht {

//: Write a function that counts each item, then gives back the answer for the case it is given.
int score([[std::array<int, 5> dice]], const std::string& category)
{
    //:: Count the dice that show each face, and add each die to the total.
    std::array<int, 7> counts {};
    int total {0};
    for (const int die : dice) {
        ++counts[die];
        total += [[die]];
    }
    //:: Give back the face times its count for `ones` to `sixes`.
    const std::array<std::string, 7> names {
        "", "ones", "twos", "threes",
        "fours", "fives", "sixes"};
    for (int face {1}; face <= 6; ++face) {
        if ([[category == names[face]]]) {
            return face * counts[face];
        }
    }
    //:: Keep the face that the most dice show.
    int most {1};
    for (int face {2}; face <= 6; ++face) {
        if ([[counts[face] > counts[most]]]) {
            most = face;
        }
    }
    //:: Give back the score of each other category when the dice fit it.
    const int top {counts[most]};
    if (category == "yacht" && [[top == 5]]) {
        return 50;
    } else if (category == "four of a kind" && top >= 4) {
        return 4 * most;
    } else if (category == "full house" && top == 3
               && std::ranges::contains(counts, 2)) {
        return total;
    } else if (category == "little straight" && top == 1
               && counts[6] == 0) {
        return 30;
    } else if (category == "big straight" && top == 1
               && counts[1] == 0) {
        return 30;
    } else if (category == "choice") {
        return total;
    }
    //:: Give back 0 when the dice do not fit the category.
    return [[0]];
}

}  // namespace yacht
```
