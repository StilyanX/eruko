# 27.01
Source: exercism nucleotide-count
Write a function `nucleotide_count::count(std::string_view dna)` that returns a `std::map<char, int>` from each of `A`, `C`, `G` and `T` to how many times it occurs in the text.
Each of the 4 keys is in the map, with 0 for a letter that does not occur.
A text holding any other character throws `std::invalid_argument`.
Limits: 0 ≤ length of the text ≤ 100.
## Solution
```cpp
#pragma once

#include <map>
#include <stdexcept>
#include <string_view>

namespace nucleotide_count {

//: Write a function that counts each item in a map from the item to its count.
std::map<char, int> count([[std::string_view dna]])
{
    //:: Start the count of each of `A`, `C`, `G` and `T` at zero.
    std::map<char, int> counts {
        [[{'A', 0}, {'C', 0}, {'G', 0}, {'T', 0}]]};
    //:: Add one to the count of each character, and throw `std::invalid_argument` for one with no count.
    for (const char base : dna) {
        if ([[!counts.contains(base)]]) {
            throw std::invalid_argument {"not A, C, G or T"};
        }
        ++counts[base];
    }
    //:: Give back the counts.
    return [[counts]];
}

}  // namespace nucleotide_count
```
