# 27.02
Source: exercism word-count
Write a function `word_count::words(const std::string& text)` that returns a map from each word of the text to the number of times it occurs.
A word is a run of letters, digits and apostrophes; every other character, space or punctuation, ends a word.
An apostrophe at the start or the end of a run is not part of the word: in `'can't'` the word is `can't`.
Words are counted in lower case, so `Go` and `GO` are both `go`.
The text is ASCII.
Limits: 0 ≤ length of the text ≤ 1000.
## Solution
```cpp
#pragma once

#include <cctype>
#include <map>
#include <string>

namespace word_count {

//: Write a function that counts each item in a map from the item to its count.
std::map<std::string, int> words([[const std::string& text]])
{
    //:: Start an empty map from each word to its count.
    [[std::map<std::string, int>]] counts {};
    //:: Start the word as an empty string.
    std::string word {[[""]]};
    //:: For each character, add a letter, a digit or an inner apostrophe to the word, else add one to the count of the word, without its last apostrophes, and start a new word.
    for (const char character : text + " ") {
        if (std::isalnum(character)
            || (character == '\'' && !word.empty())) {
            word += static_cast<char>(std::tolower(character));
        } else {
            while (word.ends_with('\'')) {
                word.pop_back();
            }
            if ([[!word.empty()]]) {
                ++counts[word];
            }
            word = "";
        }
    }
    //:: Give back the map.
    return [[counts]];
}

}  // namespace word_count
```
