# 27.03
Source: exercism parallel-letter-frequency
Write a function `parallel_letter_frequency::frequency(const std::vector<std::string_view>& texts)` that returns a `std::unordered_map<char, std::size_t>` from each letter to how many times it occurs in all the texts together.
Upper and lower case count as the same letter, and the key is the lower-case letter.
Characters that are not letters `a` to `z` or `A` to `Z` are left out, and a letter that does not occur has no key.
Limits: 0 ≤ number of texts ≤ 50; 0 ≤ length of each text ≤ 6000; each character is ASCII.
## Solution
```cpp
#pragma once

#include <cctype>
#include <cstddef>
#include <string_view>
#include <unordered_map>
#include <vector>

namespace parallel_letter_frequency {

//: Write a function that counts each item in a map from the item to its count.
std::unordered_map<char, std::size_t> frequency(
    [[const std::vector<std::string_view>& texts]])
{
    //:: Start an empty map from each letter to its count.
    std::unordered_map<char, std::size_t> counts [[{}]];
    //:: Add one to the count of each letter of each text, in lower case.
    for (const std::string_view text : texts) {
        for (const char character : text) {
            if ([[std::isalpha(character)]]) {
                ++counts[std::tolower(character)];
            }
        }
    }
    //:: Give back the counts.
    return [[counts]];
}

}  // namespace parallel_letter_frequency
```
