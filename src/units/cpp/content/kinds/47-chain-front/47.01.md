# 47.01
Source: exercism simple-linked-list
Write a class `simple_linked_list::List` that holds `int` values, where each element holds one value and owns the next element, with these member functions.
`size() const` returns the number of values as a `std::size_t`.
`push(int data)` puts the value first.
`pop()` takes the first value off and returns it.
`peek() const` returns the first value and leaves it on.
`reverse()` turns the order of the values around.
`pop()` and `peek()` throw `std::out_of_range` on an empty list.
A new list is empty.
Limits: 0 ≤ values held ≤ 1000; -1000 ≤ each value ≤ 1000.
## Solution
```cpp
#pragma once

#include <cstddef>
#include <memory>
#include <stdexcept>
#include <utility>

namespace simple_linked_list {

//: Write a class that keeps its data in private members.
class List {
    struct Element {
        int data {0};
        [[std::unique_ptr<Element>]] next {};
    };
    std::unique_ptr<Element> head {};
    std::size_t count {0};
public:
    //: Write a member function that gives back the data.
    std::size_t size() const
    {
        return [[count]];
    }
    //: Write a member function that puts a new element first.
    void push([[int data]])
    {
        //:: Make the new element hold the value and the old first one.
        head = [[std::make_unique<Element>(data, std::move(head))]];
        //:: Add one to the size.
        ++[[count]];
    }
    //: Write a member function that takes off the first element and gives back its value.
    [[int]] pop()
    {
        //:: Keep the value of the first element.
        const int value {[[peek()]]};
        //:: Make the next element the first, and take one from the size.
        head = [[std::move(head->next)]];
        --count;
        //:: Give back the value.
        return [[value]];
    }
    //: Write a member function that gives back the value of the first element.
    [[int]] peek() const
    {
        //:: Throw `std::out_of_range` when the list is empty.
        if ([[!head]]) {
            throw std::out_of_range {"list is empty"};
        }
        //:: Give back the value of the first element.
        return [[head->data]];
    }
    //: Write a member function that turns the order of the elements around.
    [[void]] reverse()
    {
        //:: Start the turned list empty.
        std::unique_ptr<Element> done [[{}]];
        //:: Move each first element to the front of the turned list.
        while ([[head]]) {
            auto rest {std::move(head->next)};
            head->next = std::move(done);
            done = std::move(head);
            head = std::move(rest);
        }
        //:: Make the turned list the list.
        head = [[std::move(done)]];
    }
};

}  // namespace simple_linked_list
```
