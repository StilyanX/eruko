# 46.01
Source: exercism largest-series-product
Write a function `largest_series_product::largest_product(const std::string& digits, int span)` that returns the largest product of `span` digits next to each other in the text.
Throw `std::domain_error` when the span is below 0 or longer than the text, or when the text holds a character that is not a digit.
Limits: 0 ≤ length of the text ≤ 1000; -10 ≤ span ≤ 1000; a product of the span's digits is below 2^31.
## Solution
```cpp
#pragma once

#include <algorithm>
#include <cctype>
#include <stdexcept>
#include <string>

namespace largest_series_product {

//: Write a function that multiplies a sequence and gives back the product.
int product([[const std::string& digits, int start, int span]])
{
    //:: Start the product at 1.
    int result {[[1]]};
    //:: For each character of the span, throw when it is not a digit, else times the product by the digit.
    for (int index {start}; index < start + span; ++index) {
        if ([[!std::isdigit(digits[index])]]) {
            throw std::domain_error {"not a digit"};
        }
        result *= digits[index] - '0';
    }
    //:: Give back the product.
    return [[result]];
}

//: Write a function that keeps the largest value and gives it back.
int largest_product([[const std::string& digits, int span]])
{
    //:: Throw `std::domain_error` when the span is below 0 or longer than the text.
    if ([[span < 0 || span > std::ssize(digits)]]) {
        throw std::domain_error {"the span does not fit"};
    }
    //:: Start the largest at zero.
    int largest {[[0]]};
    //:: For each start, keep the product of the span from it when it is larger.
    for (int start {0}; start + span <= std::ssize(digits);
         ++start) {
        largest = std::max(largest,
                           [[product(digits, start, span)]]);
    }
    //:: Give back the largest.
    return [[largest]];
}

}  // namespace largest_series_product
```
