# 5.11
Write a program that reads a line of text and prints it with a space added after each comma.

Input: one line of text, which may hold spaces.
Output: one line of text, empty when the text is empty.
Limits: the text holds 0 to 100 characters.

## Examples
```in
1,2, 3
```
```out
1, 2,  3
```
## Solution
```cpp
#include <iostream>
#include <print>
#include <string>

int main()
{
    //: Read the line.
    std::string line {};
    std::getline(std::cin, [[line]]);
    //: Start the result as an empty string.
    std::string result {[[""]]};
    //: For each character of the line, in order, add to the result.
    for (const char character : [[line]]) {
        //:: Add the character, then a space when it is a comma.
        result += character;
        if ([[character == ',']]) {
            result += ' ';
        }
    }
    //: Print the result.
    std::println("{}", [[result]]);
}
```

        line.insert(at + 1, " ");
    }
    std::println("{}", line);
}

#include <iostream>
#include <print>
#include <string>

int main()
{
    int seed {0};
    std::cin >> seed;
    const std::string alphabet {"a, b"};
    const int size {static_cast<int>(alphabet.size())};
    unsigned value {static_cast<unsigned>(seed) * 2654435761u};
    std::string line {};
    for (int index {0}; index < 100; ++index) {
        value = value * 1103515245u + 12345u;
        int pick {static_cast<int>((value >> 8) % static_cast<unsigned>(size))};
        if (seed == 2) {
            pick = 1;
        }
        if (seed == 3) {
            pick = size - 1;
        }
        line += alphabet[pick];
    }
    std::println("{}", line);
}
