# 5.02
Write a program that reads a line of text and prints it with every space taken out.

Input: one line of text, which may hold spaces.
Output: one line of text.
Limits: the text holds 0 to 100 characters.

## Examples
```in
a b  c
```
```out
abc
```
## Solution
```cpp
#include <iostream>
#include <print>
#include <string>

int main()
{
    //: Read the line.
    std::string line {};
    std::getline(std::cin, [[line]]);
    //: Start the result as an empty string.
    std::string result {[[""]]};
    //: For each character of the line, in order, add to the result.
    for (const char character : [[line]]) {
        //:: Add the character when it is not a space.
        if ([[character != ' ']]) {
            result += character;
        }
    }
    //: Print the result.
    std::println("{}", [[result]]);
}
```
## Slow
```cpp
#include <algorithm>
#include <iostream>
#include <print>
#include <string>

int main()
{
    std::string line;
    std::getline(std::cin, line);
    for (std::size_t at {line.find(' ')}; at != std::string::npos; at = line.find(' ')) {
        line.erase(at, 1);
    }
    std::println("{}", line);
}
```

```cpp
#include <iostream>
#include <print>
#include <string>

int main()
{
    int seed {0};
    std::cin >> seed;
    const std::string alphabet {"xy "};
    const int size {static_cast<int>(alphabet.size())};
    unsigned value {static_cast<unsigned>(seed) * 2654435761u};
    std::string line {};
    for (int index {0}; index < 100; ++index) {
        value = value * 1103515245u + 12345u;
        int pick {static_cast<int>((value >> 8) % static_cast<unsigned>(size))};
        if (seed == 2) {
            pick = 0;
        }
        if (seed == 3) {
            pick = size - 1;
        }
        line += alphabet[pick];
    }
    std::println("{}", line);
}
```
