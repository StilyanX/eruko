# 5.08
Write a program that reads a line of text and prints it with round brackets turned into square ones.
Each ( becomes [, and each ) becomes ].

Input: one line of text, which may hold spaces.
Output: one line of text.
Limits: the text holds 0 to 100 characters.

## Examples
```in
f(x) = (1)
```
```out
f[x] = [1]
```
## Solution
```cpp
#include <iostream>
#include <print>
#include <string>

int main()
{
    //: Read the line.
    std::string line {};
    std::getline(std::cin, [[line]]);
    //: Start the result as an empty string.
    std::string result {[[""]]};
    //: For each character of the line, in order, add to the result.
    for (const char character : [[line]]) {
        //:: Add `[` for `(`, `]` for `)`, else the character itself.
        if ([[character == '(']]) {
            result += '[';
        } else if (character == ')') {
            result += ']';
        } else {
            result += character;
        }
    }
    //: Print the result.
    std::println("{}", [[result]]);
}
```

#include <algorithm>

int main()
{
    std::string line;

    std::ranges::replace(line, '(', '[');
    std::ranges::replace(line, ')', ']');
    std::println("{}", line);
}

## Large
```cpp
#include <iostream>
#include <print>
#include <string>

int main()
{
    int seed {0};
    std::cin >> seed;
    const std::string alphabet {"()[a "};
    const int size {static_cast<int>(alphabet.size())};
    unsigned value {static_cast<unsigned>(seed) * 2654435761u};
    std::string line {};
    for (int index {0}; index < 100; ++index) {
        value = value * 1103515245u + 12345u;
        int pick {static_cast<int>((value >> 8) % static_cast<unsigned>(size))};
        if (seed == 2) {
            pick = 0;
        }
        if (seed == 3) {
            pick = size - 1;
        }
        line += alphabet[pick];
    }
    std::println("{}", line);
}
```
Seeds: 1, 2, 3
