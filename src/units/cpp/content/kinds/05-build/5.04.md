# 5.04
Write a program that reads a line of 0s and 1s and prints it with each digit flipped.
Flipping turns 0 into 1 and 1 into 0.

Input: one line of the digits 0 and 1, with no spaces.
Output: one line of 0s and 1s.
Limits: the line holds 1 to 100 digits.

## Examples
```in
0110
```
```out
1001
```
## Solution
```cpp
#include <iostream>
#include <print>
#include <string>

int main()
{
    //: Read the line.
    std::string line {};
    std::getline(std::cin, [[line]]);
    //: Start the result as an empty string.
    std::string result {[[""]]};
    //: For each character of the line, in order, add to the result.
    for (const char character : [[line]]) {
        //:: Add 1 for a 0, else add 0.
        if ([[character == '0']]) {
            result += '1';
        } else {
            result += '0';
        }
    }
    //: Print the result.
    std::println("{}", [[result]]);
}
```

#include <algorithm>

int main()
{
    std::string line;
    std::getline(std::cin, line);
    std::ranges::transform(line, line.begin(), [](char c) { return static_cast<char>('0' + '1' - c); });
    std::println("{}", line);
}

## Large
```cpp
#include <iostream>
#include <print>
#include <string>

int main()
{
    int seed {0};
    std::cin >> seed;
    const std::string alphabet {"01"};
    const int size {static_cast<int>(alphabet.size())};
    unsigned value {static_cast<unsigned>(seed) * 2654435761u};
    std::string line {};
    for (int index {0}; index < 100; ++index) {
        value = value * 1103515245u + 12345u;
        int pick {static_cast<int>((value >> 8) % static_cast<unsigned>(size))};
        if (seed == 2) {
            pick = 0;
        }
        if (seed == 3) {
            pick = size - 1;
        }
        line += alphabet[pick];
    }
    std::println("{}", line);
}
```
