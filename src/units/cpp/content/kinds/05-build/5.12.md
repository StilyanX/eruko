# 5.12
Write a program that reads a line of letters and prints it with each letter swapped for its pair.
A becomes T, T becomes A, C becomes G, and G becomes C.

Input: one line of the letters A, C, G and T, with no spaces.
Output: one line of text.
Limits: the line holds 1 to 100 letters.

## Examples
```in
GATTACA
```
```out
CTAATGT
```
## Solution
```cpp
#include <iostream>
#include <print>
#include <string>

int main()
{
    //: Read the line.
    std::string line {};
    std::getline(std::cin, [[line]]);
    //: Start the result as an empty string.
    std::string result {[[""]]};
    //: For each character of the line, in order, add to the result.
    for (const char character : [[line]]) {
        //:: Add `T` for `A`, `A` for `T`, `G` for `C`, else `C`.
        if ([[character == 'A']]) {
            result += 'T';
        } else if (character == 'T') {
            result += 'A';
        } else if (character == 'C') {
            result += 'G';
        } else {
            result += 'C';
        }
    }
    //: Print the result.
    std::println("{}", [[result]]);
}
```

## Large
```cpp
#include <iostream>
#include <print>
#include <string>

int main()
{
    int seed {0};
    std::cin >> seed;
    const std::string alphabet {"ACGT"};
    const int size {static_cast<int>(alphabet.size())};
    unsigned value {static_cast<unsigned>(seed) * 2654435761u};
    std::string line {};
    for (int index {0}; index < 100; ++index) {
        value = value * 1103515245u + 12345u;
        int pick {static_cast<int>((value >> 8) % static_cast<unsigned>(size))};
        if (seed == 2) {
            pick = 0;
        }
        if (seed == 3) {
            pick = size - 1;
        }
        line += alphabet[pick];
    }
    std::println("{}", line);
}
```
