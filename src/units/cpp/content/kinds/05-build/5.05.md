# 5.05
Write a program that reads a line of text and prints it with each space turned into %20.

Input: one line of text, which may hold spaces.
Output: one line of text.
Limits: the text holds 0 to 100 characters.

## Examples
```in
a b
```
```out
a%20b
```
## Solution
```cpp
#include <iostream>
#include <print>
#include <string>

int main()
{
    //: Read the line.
    std::string line {};
    std::getline(std::cin, [[line]]);
    //: Start the result as an empty string.
    std::string result {[[""]]};
    //: For each character of the line, in order, add to the result.
    for (const char character : [[line]]) {
        //:: Add `%20` for a space, else the character itself.
        if ([[character == ' ']]) {
            result += "%20";
        } else {
            result += character;
        }
    }
    //: Print the result.
    std::println("{}", [[result]]);
}
```
## Slow
```cpp
#include <algorithm>
#include <iostream>
#include <print>
#include <string>

int main()
{
    std::string line;
    std::getline(std::cin, line);
    for (std::size_t at {line.find(' ')}; at != std::string::npos; at = line.find(' ', at + 3)) {
        line.replace(at, 1, "%20");
    }
    std::println("{}", line);
}
```

## Large
```cpp
#include <iostream>
#include <print>
#include <string>

int main()
{
    int seed {0};
    std::cin >> seed;
    const std::string alphabet {"a %"};
    const int size {static_cast<int>(alphabet.size())};
    unsigned value {static_cast<unsigned>(seed) * 2654435761u};
    std::string line {};
    for (int index {0}; index < 100; ++index) {
        value = value * 1103515245u + 12345u;
        int pick {static_cast<int>((value >> 8) % static_cast<unsigned>(size))};
        if (seed == 2) {
            pick = 0;
        }
        if (seed == 3) {
            pick = size - 1;
        }
        line += alphabet[pick];
    }
    std::println("{}", line);
}
```
