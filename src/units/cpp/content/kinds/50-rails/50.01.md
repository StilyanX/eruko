# 50.01
Source: exercism rail-fence-cipher
Write a function `rail_fence_cipher::encode(const std::string& text, int rails)` that returns the text's characters read row by row from a zigzag.
The zigzag puts index 0 in row 0, each next index one row lower down to row `rails - 1`, then one row higher back up to row 0, and so on.
The result is row 0's characters in order, then row 1's, and so on to the last row.
Write a function `rail_fence_cipher::decode(const std::string& text, int rails)` that returns the text that `encode` turns into the given text.
Limits: 2 ≤ rails ≤ 10; 1 ≤ length of text ≤ 1000.
## Solution
```cpp
#pragma once

#include <string>

namespace rail_fence_cipher {

//: Write a function that tests each case in order and gives back the result of the first that holds.
int rail_of([[int index, int rails]])
{
    //:: Work out the place of the index in one trip down and up.
    const int place {[[index % (2 * rails - 2)]]};
    //:: Give back the place on the way down, else count it back up.
    if ([[place < rails]]) {
        return place;
    }
    return 2 * rails - 2 - place;
}

//: Write a function that builds a new string one piece at a time and gives it back.
std::string encode([[const std::string& text, int rails]])
{
    //:: Start the result as an empty string.
    std::string result {[[""]]};
    //:: For each rail, add each character on it, in order.
    for (int rail {0}; rail < rails; ++rail) {
        for (int index {0}; index < std::ssize(text); ++index) {
            if ([[rail_of(index, rails) == rail]]) {
                result += text[index];
            }
        }
    }
    //:: Give back the result.
    return [[result]];
}

//: Write a function that puts each character of the text in its place on the rails, rail by rail.
std::string decode([[const std::string& text, int rails]])
{
    //:: Start the result as a copy of the text.
    std::string result {[[text]]};
    //:: Start the position in the text at zero.
    int next {[[0]]};
    //:: For each rail, put the next character of the text at each index on it.
    for (int rail {0}; rail < rails; ++rail) {
        for (int index {0}; index < std::ssize(text); ++index) {
            if (rail_of(index, rails) == rail) {
                result[index] = [[text.at(next)]];
                ++next;
            }
        }
    }
    //:: Give back the result.
    return [[result]];
}

}  // namespace rail_fence_cipher
```
