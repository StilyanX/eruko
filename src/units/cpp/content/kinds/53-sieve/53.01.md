# 53.01
Source: exercism sieve
Write a function `sieve::primes(int n)` that returns a `std::vector<int>` of every prime from 2 to n, smallest first.
A prime is a number above 1 that only 1 and itself divide.
Find them by crossing out the multiples of each number not yet crossed out, without testing each number for divisors.
For n below 2 it returns no numbers.
Limits: 1 ≤ n ≤ 1 000 000.
## Solution
```cpp
#pragma once

#include <vector>

namespace sieve {

//: Write a function that marks the multiples of each number, and gives back the numbers left unmarked.
std::vector<int> primes([[int n]])
{
    //:: Start with no number from 0 to n marked.
    std::vector<bool> marked(n + 1, [[false]]);
    //:: Start the result as an empty list.
    std::vector<int> result [[{}]];
    //:: Keep each unmarked number from 2 to n, and mark its multiples.
    for (int number {2}; number <= n; ++number) {
        if ([[!marked.at(number)]]) {
            result.push_back(number);
            for (int m {2 * number}; m <= n; m += number) {
                marked.at(m) = true;
            }
        }
    }
    //:: Give back the result.
    return [[result]];
}

}  // namespace sieve
```
