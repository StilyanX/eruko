# 33.01
Source: exercism etl
Write a function `etl::transform(const std::map<int, std::vector<char>>& old)` that returns a `std::map<char, int>`.
The result maps each letter in a list of `old`, made lower case, to the number whose list holds it.
Limits: 0 ≤ entries of old ≤ 26; 1 ≤ each number ≤ 10; the letters are capitals from A to Z, each in one list only.
## Solution
```cpp
#pragma once

#include <cctype>
#include <map>
#include <vector>

namespace etl {

//: Write a function that builds a new map from each entry of the old one.
std::map<char, int> transform(
    [[const std::map<int, std::vector<char>>& old]])
{
    //:: Start an empty map from each letter to its score.
    std::map<char, int> result [[{}]];
    //:: Add each letter of each score, made small, with that score.
    for (const auto& [score, letters] : old) {
        for (const char letter : letters) {
            result[std::tolower(letter)] = [[score]];
        }
    }
    //:: Give back the result.
    return [[result]];
}

}  // namespace etl
```
