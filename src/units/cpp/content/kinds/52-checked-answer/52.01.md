# 52.01
Source: exercism queen-attack
Write a class `queen_attack::chess_board` whose constructor takes the positions of a white and a black queen, each a `std::pair<int, int>` of a row and a column.
The constructor throws `std::domain_error` when a row or a column is not from 0 to 7, or when the 2 positions are the same.
`white()` and `black()` return the 2 positions.
`can_attack()` returns true when the queens share a row, a column or a diagonal, else false.
Limits: none
## Solution
```cpp
#pragma once

#include <cstdlib>
#include <initializer_list>
#include <stdexcept>
#include <utility>

namespace queen_attack {

//: Write a class that keeps its data in private members.
class chess_board {
    std::pair<int, int> white_ [[{}]];
    std::pair<int, int> black_ {};
public:
    //: Write a constructor that sets the data, and stops with an error when it is bad.
    chess_board([[std::pair<int, int> white]],
                std::pair<int, int> black)
        : white_ {white}, black_ {black}
    {
        //:: Stop with an error when a row or a column is not from 0 to 7.
        for (const auto& [row, column] : {white, black}) {
            if (row < 0 || row > 7 || column < 0
                || [[column > 7]]) {
                throw std::domain_error {"not on the board"};
            }
        }
        //:: Stop with an error when the 2 positions are the same.
        if ([[white == black]]) {
            throw std::domain_error {"the same position"};
        }
    }
    //: Write member functions that give back the data.
    std::pair<int, int> white() const
    {
        return [[white_]];
    }
    std::pair<int, int> black() const
    {
        return black_;
    }
    //: Write a member function that gives back a value worked out in one step.
    [[bool]] can_attack() const
    {
        //:: Work out how far apart the rows and the columns are.
        const int rows {white_.first - black_.first};
        const int columns {[[white_.second - black_.second]]};
        //:: Give back whether they share a row, a column or a diagonal.
        return rows == 0 || columns == 0
            || [[std::abs(rows) == std::abs(columns)]];
    }
};

}  // namespace queen_attack
```
