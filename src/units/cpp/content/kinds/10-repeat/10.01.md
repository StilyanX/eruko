# 10.01
Write a program that reads an integer and prints how many steps it takes to reach 1.
A step halves an even number, and turns an odd number x into 3x + 1.

Input: one line, one integer.
Output: one line, one integer; 0 when the integer is 1.
Limits: 1 ≤ the integer ≤ 10 000.

## Examples
```in
6
```
```out
8
```
## Solution
```cpp
#include <iostream>
#include <print>

int main()
{
    //: Read the input.
    int number {0};
    std::cin >> [[number]];
    //: Start the count at zero.
    int count {[[0]]};
    //: While the test holds, change the number and add one to the count.
    while ([[number != 1]]) {
        //:: Halve an even number, or make an odd number 3 times itself plus 1.
        if ([[number % 2 == 0]]) {
            number /= 2;
        } else {
            number = 3 * number + 1;
        }
        //:: Add one to the count.
        ++[[count]];
    }
    //: Print the count.
    std::println("{}", [[count]]);
}
```
## Slow
```cpp
#include <iostream>
#include <print>

int steps(long long x)
{
    if (x == 1) return 0;
    return 1 + steps(x % 2 == 0 ? x / 2 : 3 * x + 1);
}

int main()
{
    long long x {0};
    std::cin >> x;
    std::println("{}", steps(x));
}
```
