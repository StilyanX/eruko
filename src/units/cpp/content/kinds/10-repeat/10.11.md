# 10.11
Write a program that reads an integer and prints how many steps it takes to reach 0 or less, the step that reaches it counted.
Step 1 takes 1 from the number, step 2 takes 2, step 3 takes 3, and so on.

Input: one line, one integer.
Output: one line, one integer.
Limits: 1 ≤ the integer ≤ 1 000 000 000.

## Examples
```in
10
```
```out
4
```
```in
11
```
```out
5
```
## Solution
```cpp
#include <iostream>
#include <print>

int main()
{
    //: Read the input.
    int number {0};
    std::cin >> [[number]];
    //: Start the count at zero.
    int count {[[0]]};
    //: While the test holds, change the number and add one to the count.
    while ([[number > 0]]) {
        //:: Add one to the count.
        ++[[count]];
        //:: Take the count from the number.
        number = [[number - count]];
    }
    //: Print the count.
    std::println("{}", [[count]]);
}
```
