# 10.03
Write a program that reads an integer and prints how many steps it takes to reach 0.
A step halves an even number and takes 1 from an odd number.

Input: one line, one integer.
Output: one line, one integer; 0 when the integer is 0.
Limits: 0 ≤ the integer ≤ 1 000 000 000.

## Examples
```in
14
```
```out
6
```
## Solution
```cpp
#include <iostream>
#include <print>

int main()
{
    //: Read the input.
    int number {0};
    std::cin >> [[number]];
    //: Start the count at zero.
    int count {[[0]]};
    //: While the test holds, change the number and add one to the count.
    while ([[number > 0]]) {
        //:: Halve an even number, or take 1 from an odd one.
        if ([[number % 2 == 0]]) {
            number /= 2;
        } else {
            number = number - 1;
        }
        //:: Add one to the count.
        ++[[count]];
    }
    //: Print the count.
    std::println("{}", [[count]]);
}
```
## Slow
```cpp
#include <iostream>
#include <print>

int main()
{
    long long x {0};
    std::cin >> x;
    int bits {0};
    int ones {0};
    for (long long rest {x}; rest > 0; rest >>= 1) {
        ++bits;
        if (rest & 1) ++ones;
    }
    std::println("{}", x == 0 ? 0 : bits - 1 + ones);
}
```
