# 10.12
Write a program that reads 2 integers and prints how many steps it takes to make them equal.
A step takes the smaller integer away from the larger one, once.

Input: one line, 2 integers separated by a space.
Output: one line, one integer; 0 when the 2 integers are already equal.
Limits: 1 ≤ each integer ≤ 1000.

## Examples
```in
12 18
```
```out
2
```
```in
7 1
```
```out
6
```
## Solution
```cpp
#include <iostream>
#include <print>

int main()
{
    //: Read the input.
    int first {0};
    int second {0};
    std::cin >> [[first >> second]];
    //: Start the count at zero.
    int count {[[0]]};
    //: While the test holds, change the number and add one to the count.
    while ([[first != second]]) {
        //:: Take the smaller number away from the larger one.
        if ([[first > second]]) {
            first = first - second;
        } else {
            second = second - first;
        }
        //:: Add one to the count.
        ++[[count]];
    }
    //: Print the count.
    std::println("{}", [[count]]);
}
```
## Slow
```cpp
#include <iostream>
#include <print>

int main()
{
    int a {0};
    int b {0};
    std::cin >> a >> b;
    int steps {0};
    while (b != 0) {
        steps += a / b;
        const int r {a % b};
        a = b;
        b = r;
    }
    std::println("{}", steps - 1);
}
```
