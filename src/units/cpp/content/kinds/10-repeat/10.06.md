# 10.06
Write a program that reads an integer and prints how many steps it takes to reach 1.
A step divides the number by 3 when 3 divides it, and takes 1 from it otherwise.

Input: one line, one integer.
Output: one line, one integer; 0 when the integer is 1.
Limits: 1 ≤ the integer ≤ 1 000 000.

## Examples
```in
10
```
```out
3
```
## Solution
```cpp
#include <iostream>
#include <print>

int main()
{
    //: Read the input.
    int number {0};
    std::cin >> [[number]];
    //: Start the count at zero.
    int count {[[0]]};
    //: While the test holds, change the number and add one to the count.
    while ([[number != 1]]) {
        //:: Divide the number by 3 when 3 divides it, or take 1 from it.
        if ([[number % 3 == 0]]) {
            number /= 3;
        } else {
            number = number - 1;
        }
        //:: Add one to the count.
        ++[[count]];
    }
    //: Print the count.
    std::println("{}", [[count]]);
}
```
## Slow
```cpp
#include <iostream>
#include <print>

int steps(int x)
{
    if (x == 1) return 0;
    if (x % 3 == 0) return 1 + steps(x / 3);
    return 1 + steps(x - 1);
}

int main()
{
    int x {0};
    std::cin >> x;
    std::println("{}", steps(x));
}
```
