# 10.14
Write a program that reads an integer and prints how many steps it takes until 7 divides it.
A step adds 1 to the number. 7 divides 0 and every multiple of 7, negative ones included.

Input: one line, one integer.
Output: one line, one integer; 0 when 7 already divides the integer.
Limits: -1 000 000 ≤ the integer ≤ 1 000 000.

## Examples
```in
10
```
```out
4
```
```in
-3
```
```out
3
```
## Solution
```cpp
#include <iostream>
#include <print>

int main()
{
    //: Read the input.
    int number {0};
    std::cin >> [[number]];
    //: Start the count at zero.
    int count {[[0]]};
    //: While the test holds, change the number and add one to the count.
    while ([[number % 7 != 0]]) {
        //:: Add one to the number.
        ++[[number]];
        //:: Add one to the count.
        ++[[count]];
    }
    //: Print the count.
    std::println("{}", [[count]]);
}
```
## Slow
```cpp
#include <iostream>
#include <print>

int main()
{
    int x {0};
    std::cin >> x;
    for (int k {0}; k < 7; ++k) {
        if ((x + k) % 7 == 0) {
            std::println("{}", k);
            return 0;
        }
    }
}
```
