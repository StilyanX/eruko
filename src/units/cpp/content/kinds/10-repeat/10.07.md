# 10.07
Write a program that reads an integer and prints how many steps it takes to reach 1.
A step halves the number, rounded up.

Input: one line, one integer.
Output: one line, one integer; 0 when the integer is 1.
Limits: 1 ≤ the integer ≤ 1 000 000 000.

## Examples
```in
5
```
```out
3
```
## Solution
```cpp
#include <iostream>
#include <print>

int main()
{
    //: Read the input.
    int number {0};
    std::cin >> [[number]];
    //: Start the count at zero.
    int count {[[0]]};
    //: While the test holds, change the number and add one to the count.
    while ([[number > 1]]) {
        //:: Halve the number, rounded up.
        number = [[(number + 1) / 2]];
        //:: Add one to the count.
        ++[[count]];
    }
    //: Print the count.
    std::println("{}", [[count]]);
}
```
