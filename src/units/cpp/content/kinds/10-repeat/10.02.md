# 10.02
Write a program that reads an integer and prints how many zeros it ends in.

Input: one line, one integer.
Output: one line, one integer.
Limits: 1 ≤ the integer ≤ 1 000 000 000.

## Examples
```in
120400
```
```out
2
```
```in
7
```
```out
0
```
## Solution
```cpp
#include <iostream>
#include <print>

int main()
{
    //: Read the input.
    int number {0};
    std::cin >> [[number]];
    //: Start the count at zero.
    int count {[[0]]};
    //: While the test holds, change the number and add one to the count.
    while ([[number % 10 == 0]]) {
        //:: Drop the last digit.
        number [[/= 10]];
        //:: Add one to the count.
        ++[[count]];
    }
    //: Print the count.
    std::println("{}", [[count]]);
}
```
## Slow
```cpp
#include <iostream>
#include <print>
#include <string>

int main()
{
    std::string text {};
    std::cin >> text;
    int zeros {0};
    for (int i {static_cast<int>(text.size()) - 1}; i >= 0 && text[i] == '0'; --i) ++zeros;
    std::println("{}", zeros);
}
```
