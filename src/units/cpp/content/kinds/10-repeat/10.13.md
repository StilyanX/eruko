# 10.13
Write a program that reads an integer and prints how many steps it takes to fall below 100.
A step takes a tenth of the number, rounded down, away from it.

Input: one line, one integer.
Output: one line, one integer.
Limits: 1 ≤ the integer ≤ 1 000 000 000.

## Examples
```in
120
```
```out
2
```
```in
99
```
```out
0
```
## Solution
```cpp
#include <iostream>
#include <print>

int main()
{
    //: Read the input.
    int number {0};
    std::cin >> [[number]];
    //: Start the count at zero.
    int count {[[0]]};
    //: While the test holds, change the number and add one to the count.
    while ([[number >= 100]]) {
        //:: Take a tenth of the number, rounded down, away from it.
        number = [[number - number / 10]];
        //:: Add one to the count.
        ++[[count]];
    }
    //: Print the count.
    std::println("{}", [[count]]);
}
```
## Slow
```cpp
#include <iostream>
#include <print>

int steps(int x)
{
    if (x < 100) return 0;
    return 1 + steps(x - x / 10);
}

int main()
{
    int x {0};
    std::cin >> x;
    std::println("{}", steps(x));
}
```
