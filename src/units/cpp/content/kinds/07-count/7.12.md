# 7.12
Write a program that reads n integers and prints how many of them are multiples of n.

Input: line 1, n; line 2, n integers separated by spaces.
Output: one line, one integer.
Limits: 1 ≤ n ≤ 100, 1 ≤ each integer ≤ 1000.

## Examples
```in
4
8 6 12 4
```
```out
3
```
## Solution
```cpp
#include <iostream>
#include <print>

int main()
{
    //: Read how many numbers follow.
    int n {0};
    std::cin >> [[n]];
    //: Start the count at zero.
    int count {[[0]]};
    //: For each index from 0 to n - 1, read a number and test it.
    for (int index {0}; index < [[n]]; ++index) {
        int number {0};
        std::cin >> number;
        //:: Add one when n divides the number.
        if ([[number % n == 0]]) {
            ++count;
        }
    }
    //: Print the count.
    std::println("{}", [[count]]);
}
```
## Slow
```cpp
#include <iostream>
#include <print>
#include <vector>

int main()
{
    int n {0};
    std::cin >> n;
    std::vector<int> numbers(n);
    for (int& x : numbers) {
        std::cin >> x;
    }
    int count {0};
    for (int place {0}; place < n; ++place) {
        for (int times {1}; times * n <= 1000; ++times) {
            if (numbers[place] == times * n) {
                ++count;
            }
        }
    }
    std::println("{}", count);
}
```
