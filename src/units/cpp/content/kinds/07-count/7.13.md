# 7.13
Write a program that reads n integers and prints how many of them equal their index.
The first integer has index 0, the next has index 1, and so on.

Input: line 1, n; line 2, n integers separated by spaces.
Output: one line, one integer.
Limits: 1 ≤ n ≤ 100, -1000 ≤ each integer ≤ 1000.

## Examples
```in
5
0 5 2 2 4
```
```out
3
```
## Solution
```cpp
#include <iostream>
#include <print>

int main()
{
    //: Read how many numbers follow.
    int n {0};
    std::cin >> [[n]];
    //: Start the count at zero.
    int count {[[0]]};
    //: For each index from 0 to n - 1, read a number and test it.
    for (int index {0}; index < [[n]]; ++index) {
        int number {0};
        std::cin >> number;
        //:: Add one when the number equals its index.
        if ([[number == index]]) {
            ++count;
        }
    }
    //: Print the count.
    std::println("{}", [[count]]);
}
```
## Slow
```cpp
#include <iostream>
#include <print>
#include <vector>

int main()
{
    int n {0};
    std::cin >> n;
    std::vector<int> numbers(n);
    for (int& x : numbers) {
        std::cin >> x;
    }
    int count {0};
    for (int place {0}; place < n; ++place) {
        int steps {0};
        for (int before {0}; before < place; ++before) {
            ++steps;
        }
        if (numbers[place] == steps) {
            ++count;
        }
    }
    std::println("{}", count);
}
```
