# 7.07
Write a program that reads n integers and prints how many of them end in the digit 7.

Input: line 1, n; line 2, n integers separated by spaces.
Output: one line, one integer.
Limits: 1 ≤ n ≤ 100, 0 ≤ each integer ≤ 1000.

## Examples
```in
4
7 17 70 127
```
```out
3
```
## Solution
```cpp
#include <iostream>
#include <print>

int main()
{
    //: Read how many numbers follow.
    int n {0};
    std::cin >> [[n]];
    //: Start the count at zero.
    int count {[[0]]};
    //: For each index from 0 to n - 1, read a number and test it.
    for (int index {0}; index < [[n]]; ++index) {
        int number {0};
        std::cin >> number;
        //:: Add one when the last digit of the number is 7.
        if ([[number % 10 == 7]]) {
            ++count;
        }
    }
    //: Print the count.
    std::println("{}", [[count]]);
}
```
## Slow
```cpp
#include <algorithm>
#include <iostream>
#include <print>
#include <string>
#include <vector>

int main()
{
    int n {0};
    std::cin >> n;
    std::vector<int> numbers(n);
    for (int& x : numbers) {
        std::cin >> x;
    }
    auto passes = [](int v) { return v % 10 == 7; };
    int count {0};
    for (int v {0}; v <= 1000; ++v) {
        if (passes(v)) {
            count += static_cast<int>(std::ranges::count(numbers, v));
        }
    }
    std::println("{}", count);
}
```
