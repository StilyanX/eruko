# 7.11
Write a program that reads n integers and prints how many of them have 2 equal digits.

Input: line 1, n; line 2, n integers separated by spaces.
Output: one line, one integer.
Limits: 1 ≤ n ≤ 100, 10 ≤ each integer ≤ 99.

## Examples
```in
5
11 12 99 90 44
```
```out
3
```
## Solution
```cpp
#include <iostream>
#include <print>

int main()
{
    //: Read how many numbers follow.
    int n {0};
    std::cin >> [[n]];
    //: Start the count at zero.
    int count {[[0]]};
    //: For each index from 0 to n - 1, read a number and test it.
    for (int index {0}; index < [[n]]; ++index) {
        int number {0};
        std::cin >> number;
        //:: Add one when the 2 digits of the number are equal.
        if ([[number / 10 == number % 10]]) {
            ++count;
        }
    }
    //: Print the count.
    std::println("{}", [[count]]);
}
```
## Slow
```cpp
#include <iostream>
#include <print>
#include <vector>

int main()
{
    int n {0};
    std::cin >> n;
    std::vector<int> numbers(n);
    for (int& x : numbers) {
        std::cin >> x;
    }
    int count {0};
    for (int place {0}; place < n; ++place) {
        for (int digit {1}; digit <= 9; ++digit) {
            if (numbers[place] == digit * 11) {
                ++count;
            }
        }
    }
    std::println("{}", count);
}
```
