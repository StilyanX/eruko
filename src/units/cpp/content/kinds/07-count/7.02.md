# 7.02
Write a program that reads n integers and prints how many of them are greater than 0.

Input: line 1, n; line 2, n integers separated by spaces.
Output: one line, one integer.
Limits: 1 ≤ n ≤ 100, -1000 ≤ each integer ≤ 1000.

## Examples
```in
5
4 -2 0 6 -9
```
```out
2
```
## Solution
```cpp
#include <iostream>
#include <print>

int main()
{
    //: Read how many numbers follow.
    int n {0};
    std::cin >> [[n]];
    //: Start the count at zero.
    int count {[[0]]};
    //: For each index from 0 to n - 1, read a number and test it.
    for (int index {0}; index < [[n]]; ++index) {
        int number {0};
        std::cin >> number;
        //:: Add one when the number is greater than 0.
        if ([[number > 0]]) {
            ++count;
        }
    }
    //: Print the count.
    std::println("{}", [[count]]);
}
```
## Slow
```cpp
#include <algorithm>
#include <iostream>
#include <print>
#include <string>
#include <vector>

int main()
{
    int n {0};
    std::cin >> n;
    std::vector<int> numbers(n);
    for (int& x : numbers) {
        std::cin >> x;
    }
    auto passes = [](int v) { return v > 0; };
    int count {0};
    for (int v {-1000}; v <= 1000; ++v) {
        if (passes(v)) {
            count += static_cast<int>(std::ranges::count(numbers, v));
        }
    }
    std::println("{}", count);
}
```
