# 9.06
Write a program that reads n integers and prints the largest of them and how many times it appears.

Input: line 1, n; line 2, n integers separated by spaces.
Output: one line, 2 integers separated by a space, the largest first.
Limits: 1 ≤ n ≤ 100, -1000 ≤ each integer ≤ 1000.

## Examples
```in
6
4 9 2 9 9 1
```
```out
9 3
```
## Solution
```cpp
#include <iostream>
#include <print>

int main()
{
    //: Read how many numbers follow.
    int n {0};
    std::cin >> [[n]];
    //: Read the first number and keep it.
    int largest {0};
    std::cin >> [[largest]];
    //:: Start the count at 1.
    int count {[[1]]};
    //: For each index from 1 to n - 1, read a number and compare it with the kept one.
    for (int index {[[1]]}; index < n; ++index) {
        int number {0};
        std::cin >> number;
        //:: Keep a larger number and start its count at 1, or add one to the count for an equal one.
        if ([[number > largest]]) {
            largest = number;
            count = 1;
        } else if (number == largest) {
            ++count;
        }
    }
    //: Print the value.
    std::println("{} {}", [[largest, count]]);
}
```
## Slow
```cpp
#include <iostream>
#include <print>
#include <vector>

int main()
{
    int n {0};
    std::cin >> n;
    std::vector<int> numbers(n);
    for (int& x : numbers) std::cin >> x;
    for (int value {1000}; value >= -1000; --value) {
        int count {0};
        for (int x : numbers) {
            if (x == value) ++count;
        }
        if (count > 0) {
            std::println("{} {}", value, count);
            return 0;
        }
    }
}
```
