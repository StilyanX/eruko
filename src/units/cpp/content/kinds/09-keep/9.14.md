# 9.14
Write a program that reads n integers and prints the one closest to 0.
When more than one integer is that close to 0, print the first of them.

Input: line 1, n; line 2, n integers separated by spaces.
Output: one line, one integer.
Limits: 1 ≤ n ≤ 100, -1000 ≤ each integer ≤ 1000.

## Examples
```in
5
7 -4 9 4 -5
```
```out
-4
```
```in
3
-1000 1000 999
```
```out
999
```
## Solution
```cpp
#include <iostream>
#include <print>

int main()
{
    //: Read how many numbers follow.
    int n {0};
    std::cin >> [[n]];
    //: Read the first number and keep it.
    int closest {0};
    std::cin >> [[closest]];
    //: For each index from 1 to n - 1, read a number and compare it with the kept one.
    for (int index {[[1]]}; index < n; ++index) {
        int number {0};
        std::cin >> number;
        //:: Keep the number when it is closer to 0.
        if ([[number * number < closest * closest]]) {
            closest = number;
        }
    }
    //: Print the value.
    std::println("{}", [[closest]]);
}
```

    std::vector<int> numbers(n);
    for (int& x : numbers) std::cin >> x;
    for (int distance {0}; distance <= 1000; ++distance) {
        for (int x : numbers) {
            if (x == distance || x == -distance) {
                std::println("{}", x);
                return 0;
            }
        }
    }
}
