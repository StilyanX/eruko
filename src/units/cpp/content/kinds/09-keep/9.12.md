# 9.12
Write a program that reads n integers and prints the largest drop from an integer to a later one.
A drop is the earlier integer minus the later one.

Input: line 1, n; line 2, n integers separated by spaces.
Output: one line, one integer; 0 when no integer is smaller than an integer before it.
Limits: 1 ≤ n ≤ 100, -1000 ≤ each integer ≤ 1000.

## Examples
```in
5
4 9 2 7 1
```
```out
8
```
```in
3
1 2 3
```
```out
0
```
## Solution
```cpp
#include <iostream>
#include <print>

int main()
{
    //: Read how many numbers follow.
    int n {0};
    std::cin >> [[n]];
    //: Read the first number and keep it.
    int largest {0};
    std::cin >> [[largest]];
    //:: Start the largest drop at 0.
    int drop {[[0]]};
    //: For each index from 1 to n - 1, read a number and compare it with the kept one.
    for (int index {[[1]]}; index < n; ++index) {
        int number {0};
        std::cin >> number;
        //:: Keep the drop to the number when it is larger than the kept drop.
        if ([[largest - number > drop]]) {
            drop = largest - number;
        }
        //:: Keep the number when it is larger.
        if ([[number > largest]]) {
            largest = number;
        }
    }
    //: Print the value.
    std::println("{}", [[drop]]);
}
```
## Slow
```cpp
#include <iostream>
#include <print>
#include <vector>

int main()
{
    int n {0};
    std::cin >> n;
    std::vector<int> numbers(n);
    for (int& x : numbers) std::cin >> x;
    int best {0};
    for (int i {0}; i < n; ++i) {
        for (int j {i + 1}; j < n; ++j) {
            if (numbers[i] - numbers[j] > best) best = numbers[i] - numbers[j];
        }
    }
    std::println("{}", best);
}
```
