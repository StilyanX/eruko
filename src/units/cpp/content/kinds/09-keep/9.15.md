# 9.15
Write a program that reads n integers and prints the largest sum of the first k of them.
k is any integer from 1 to n, both included.

Input: line 1, n; line 2, n integers separated by spaces.
Output: one line, one integer.
Limits: 1 ≤ n ≤ 100, -1000 ≤ each integer ≤ 1000.

## Examples
```in
5
3 -5 4 2 -1
```
```out
4
```
```in
3
-2 -1 -3
```
```out
-2
```
## Solution
```cpp
#include <iostream>
#include <print>

int main()
{
    //: Read how many numbers follow.
    int n {0};
    std::cin >> [[n]];
    //: Read the first number and keep it.
    int best {0};
    std::cin >> [[best]];
    //:: Keep the first number as the total too.
    int total {[[best]]};
    //: For each index from 1 to n - 1, read a number and compare it with the kept one.
    for (int index {[[1]]}; index < n; ++index) {
        int number {0};
        std::cin >> number;
        //:: Add the number to the total.
        total += [[number]];
        //:: Keep the total when it is larger.
        if ([[total > best]]) {
            best = total;
        }
    }
    //: Print the value.
    std::println("{}", [[best]]);
}
```
## Slow
```cpp
#include <iostream>
#include <print>
#include <vector>

int main()
{
    int n {0};
    std::cin >> n;
    std::vector<int> numbers(n);
    for (int& x : numbers) std::cin >> x;
    int best {numbers[0]};
    for (int k {1}; k <= n; ++k) {
        int sum {0};
        for (int i {0}; i < k; ++i) sum += numbers[i];
        if (sum > best) best = sum;
    }
    std::println("{}", best);
}
```
