# 9.03
Write a program that reads n integers and prints the position of the smallest of them.
Positions count from 1; when the smallest appears more than once, print its last position.

Input: line 1, n; line 2, n integers separated by spaces.
Output: one line, one integer.
Limits: 1 ≤ n ≤ 100, -1000 ≤ each integer ≤ 1000.

## Examples
```in
5
4 1 6 1 9
```
```out
4
```
## Solution
```cpp
#include <iostream>
#include <print>

int main()
{
    //: Read how many numbers follow.
    int n {0};
    std::cin >> [[n]];
    //: Read the first number and keep it.
    int smallest {0};
    std::cin >> [[smallest]];
    //:: Start the position at 1.
    int position {[[1]]};
    //: For each index from 1 to n - 1, read a number and compare it with the kept one.
    for (int index {[[1]]}; index < n; ++index) {
        int number {0};
        std::cin >> number;
        //:: Keep the number and its position when it is smaller than or equal to the kept one.
        if ([[number <= smallest]]) {
            smallest = number;
            position = index + 1;
        }
    }
    //: Print the value.
    std::println("{}", [[position]]);
}
```

#include <print>
#include <vector>

int main()
{
    int n {0};
    std::cin >> n;
    std::vector<int> numbers(n);
    for (int& x : numbers) std::cin >> x;
    for (int i {n - 1}; i >= 0; --i) {
        bool beaten {false};
        for (int j {0}; j < n; ++j) {
            if (numbers[j] < numbers[i]) beaten = true;
        }
        if (!beaten) {
            std::println("{}", i + 1);
            return 0;
        }
    }
}
