# 9.04
Write a program that reads n integers and prints the largest and the smallest of them.

Input: line 1, n; line 2, n integers separated by spaces.
Output: one line, 2 integers separated by a space, the largest first.
Limits: 1 ≤ n ≤ 100, -1000 ≤ each integer ≤ 1000.

## Examples
```in
4
5 -3 9 0
```
```out
9 -3
```
```in
1
7
```
```out
7 7
```
## Solution
```cpp
#include <iostream>
#include <print>

int main()
{
    //: Read how many numbers follow.
    int n {0};
    std::cin >> [[n]];
    //: Read the first number and keep it.
    int largest {0};
    std::cin >> [[largest]];
    //:: Keep the first number as the smallest too.
    int smallest {[[largest]]};
    //: For each index from 1 to n - 1, read a number and compare it with the kept one.
    for (int index {[[1]]}; index < n; ++index) {
        int number {0};
        std::cin >> number;
        //:: Keep the number when it is larger.
        if ([[number > largest]]) {
            largest = number;
        }
        //:: Keep the number when it is smaller.
        if ([[number < smallest]]) {
            smallest = number;
        }
    }
    //: Print the value.
    std::println("{} {}", [[largest, smallest]]);
}
```
## Slow
```cpp
#include <iostream>
#include <print>
#include <vector>

int main()
{
    int n {0};
    std::cin >> n;
    std::vector<int> numbers(n);
    for (int& x : numbers) std::cin >> x;
    int high {-1001};
    for (int value {-1000}; value <= 1000; ++value) {
        for (int x : numbers) {
            if (x == value) high = value;
        }
    }
    int low {1001};
    for (int value {1000}; value >= -1000; --value) {
        for (int x : numbers) {
            if (x == value) low = value;
        }
    }
    std::println("{} {}", high, low);
}
```
