# 9.02
Write a program that reads n integers and prints the position of the largest of them.
Positions count from 1; when the largest appears more than once, print its first position.

Input: line 1, n; line 2, n integers separated by spaces.
Output: one line, one integer.
Limits: 1 ≤ n ≤ 100, -1000 ≤ each integer ≤ 1000.

## Examples
```in
5
3 8 1 8 2
```
```out
2
```
## Solution
```cpp
#include <iostream>
#include <print>

int main()
{
    //: Read how many numbers follow.
    int n {0};
    std::cin >> [[n]];
    //: Read the first number and keep it.
    int largest {0};
    std::cin >> [[largest]];
    //:: Start the position at 1.
    int position {[[1]]};
    //: For each index from 1 to n - 1, read a number and compare it with the kept one.
    for (int index {[[1]]}; index < n; ++index) {
        int number {0};
        std::cin >> number;
        //:: Keep the number and its position when it is larger.
        if ([[number > largest]]) {
            largest = number;
            position = index + 1;
        }
    }
    //: Print the value.
    std::println("{}", [[position]]);
}
```

    std::vector<int> numbers(n);
    for (int& x : numbers) std::cin >> x;
    for (int i {0}; i < n; ++i) {
        bool beaten {false};
        for (int j {0}; j < n; ++j) {
            if (numbers[j] > numbers[i]) beaten = true;
        }
        if (!beaten) {
            std::println("{}", i + 1);
            return 0;
        }
    }
}
