# 9.13
Write a program that reads n integers and prints the one with the largest last digit.
When more than one integer has that last digit, print the first of them.

Input: line 1, n; then n lines, one integer on each.
Output: one line, one integer.
Limits: 1 ≤ n ≤ 100, 0 ≤ each integer ≤ 1 000 000.

## Examples
```in
4
23
107
58
17
```
```out
58
```
```in
3
19
9
29
```
```out
19
```
## Solution
```cpp
#include <iostream>
#include <print>

int main()
{
    //: Read how many numbers follow.
    int n {0};
    std::cin >> [[n]];
    //: Read the first number and keep it.
    int kept {0};
    std::cin >> [[kept]];
    //: For each index from 1 to n - 1, read a number and compare it with the kept one.
    for (int index {[[1]]}; index < n; ++index) {
        int number {0};
        std::cin >> number;
        //:: Keep the number when its last digit is larger than the kept one's.
        if ([[number % 10 > kept % 10]]) {
            kept = number;
        }
    }
    //: Print the value.
    std::println("{}", [[kept]]);
}
```

#include <vector>

int main()
{
    int n {0};
    std::cin >> n;
    std::vector<int> numbers(n);
    for (int& x : numbers) std::cin >> x;
    for (int digit {9}; digit >= 0; --digit) {
        for (int x : numbers) {
            if (x % 10 == digit) {
                std::println("{}", x);
                return 0;
            }
        }
    }
}
