# 9.11
Write a program that reads n integers and prints how many of them are strictly larger than every integer before them.
The first integer counts, since no integer comes before it.

Input: line 1, n; line 2, n integers separated by spaces.
Output: one line, one integer.
Limits: 1 ≤ n ≤ 100, -1000 ≤ each integer ≤ 1000.

## Examples
```in
6
3 1 4 1 5 9
```
```out
4
```
```in
4
5 5 2 5
```
```out
1
```
## Solution
```cpp
#include <iostream>
#include <print>

int main()
{
    //: Read how many numbers follow.
    int n {0};
    std::cin >> [[n]];
    //: Read the first number and keep it.
    int largest {0};
    std::cin >> [[largest]];
    //:: Start the count at 1.
    int count {[[1]]};
    //: For each index from 1 to n - 1, read a number and compare it with the kept one.
    for (int index {[[1]]}; index < n; ++index) {
        int number {0};
        std::cin >> number;
        //:: Keep a larger number and add one to the count.
        if ([[number > largest]]) {
            largest = number;
            ++count;
        }
    }
    //: Print the value.
    std::println("{}", [[count]]);
}
```
## Slow
```cpp
#include <iostream>
#include <print>
#include <vector>

int main()
{
    int n {0};
    std::cin >> n;
    std::vector<int> numbers(n);
    for (int& x : numbers) std::cin >> x;
    int count {0};
    for (int i {0}; i < n; ++i) {
        bool beaten {false};
        for (int j {0}; j < i; ++j) {
            if (numbers[j] >= numbers[i]) beaten = true;
        }
        if (!beaten) ++count;
    }
    std::println("{}", count);
}
```
