# 9.09
Write a program that reads n integers and prints the largest of them minus the first.

Input: line 1, n; line 2, n integers separated by spaces.
Output: one line, one integer.
Limits: 1 ≤ n ≤ 100, -1000 ≤ each integer ≤ 1000.

## Examples
```in
5
3 -2 10 4 10
```
```out
7
```
```in
3
6 1 6
```
```out
0
```
## Solution
```cpp
#include <iostream>
#include <print>

int main()
{
    //: Read how many numbers follow.
    int n {0};
    std::cin >> [[n]];
    //: Read the first number and keep it.
    int first {0};
    std::cin >> [[first]];
    //:: Keep the first number as the largest too.
    int largest {[[first]]};
    //: For each index from 1 to n - 1, read a number and compare it with the kept one.
    for (int index {[[1]]}; index < n; ++index) {
        int number {0};
        std::cin >> number;
        //:: Keep the number when it is larger.
        if ([[number > largest]]) {
            largest = number;
        }
    }
    //: Print the value.
    std::println("{}", [[largest - first]]);
}
```
## Slow
```cpp
#include <iostream>
#include <print>
#include <vector>

int main()
{
    int n {0};
    std::cin >> n;
    std::vector<int> numbers(n);
    for (int& x : numbers) std::cin >> x;
    int rise {0};
    while (true) {
        bool found {false};
        for (int x : numbers) {
            if (x - numbers[0] > rise) found = true;
        }
        if (!found) break;
        ++rise;
    }
    std::println("{}", rise);
}
```
