# 25.01
Source: exercism grade-school
Write a class `grade_school::school` that keeps names by grade, with these member functions.
`add(const std::string& name, int grade)` puts the name in the grade, unless some grade already has that name.
`roster() const` returns a `std::map<int, std::vector<std::string>>` from each grade that has names to its names in alphabetical order.
`grade(int grade) const` returns a `std::vector<std::string>` of the names in that grade in alphabetical order, or no names when it has none.
A new school has no names.
Limits: 1 ≤ grade ≤ 12; 0 ≤ names added ≤ 100; each name is 1 to 20 letters.
## Solution
```cpp
#pragma once

#include <algorithm>
#include <map>
#include <string>
#include <vector>

namespace grade_school {

//: Write a class that keeps its data in private members.
class school {
    [[std::map<int, std::vector<std::string>>]] grades {};
public:
    //: Write a member function that adds an item to the data.
    void add([[const std::string& name, int grade]])
    {
        //:: Give back at once when some grade has the name.
        for (const auto& [number, names] : grades) {
            if ([[std::ranges::contains(names, name)]]) {
                return;
            }
        }
        //:: Put the name in its grade, and sort the grade's names.
        auto& names {grades[grade]};
        names.push_back(name);
        std::ranges::sort([[names]]);
    }
    //: Write a member function that gives back the data.
    std::map<int, std::vector<std::string>> roster() const
    {
        return [[grades]];
    }
    //: Write a member function that gives back part of the data.
    std::vector<std::string> grade([[int number]]) const
    {
        //:: Give back no names when the map has no such grade.
        if ([[!grades.contains(number)]]) {
            return {};
        }
        //:: Give back the names of the grade.
        return [[grades.at(number)]];
    }
};

}  // namespace grade_school
```
