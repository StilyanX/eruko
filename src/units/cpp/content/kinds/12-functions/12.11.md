# 12.11
Write a program that reads n integers and prints, for each, the sum of its digits.

Input: line 1, n; line 2, n integers separated by spaces.
Output: n lines, one per integer in the order read.
Limits: 1 ≤ n ≤ 100, 0 ≤ each integer ≤ 1 000 000 000.

## Examples
```in
3
305 9 0
```
```out
8
9
0
```
## Solution
```cpp
#include <iostream>
#include <print>

//: Write a function above main that takes one number and gives back the answer for it.
int digit_sum([[int number]])
{
    //:: Start the total at zero.
    int total {[[0]]};
    //:: Add each last digit to the total, then drop it from the number.
    while ([[number > 0]]) {
        total += number % 10;
        number /= 10;
    }
    //:: Give back the total.
    return [[total]];
}

int main()
{
    //: Read how many numbers follow.
    int n {0};
    std::cin >> [[n]];
    //: For each index from 0 to n - 1, read a number and print the function's answer.
    for (int index {0}; index < n; ++index) {
        int number {0};
        std::cin >> number;
        std::println("{}", [[digit_sum(number)]]);
    }
}
```
