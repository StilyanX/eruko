# 12.08
Write a program that reads n integers and prints a value for each.

Input: line 1, n; line 2, n integers separated by spaces.
Output: n lines, one per integer in the order read.
Each line is 10 for 1 to 20, 25 for 21 to 100, 60 for 101 to 500, else 120.
Each range includes both its ends.
Limits: 1 ≤ n ≤ 100, 1 ≤ each integer ≤ 2000.

## Examples
```in
4
15 21 500 900
```
```out
10
25
60
120
```
## Solution
```cpp
#include <iostream>
#include <print>

//: Write a function above main that takes one number and gives back the answer for it.
int value([[int number]])
{
    //:: Give back the value for the band of the number.
    if ([[number <= 20]]) {
        return 10;
    } else if (number <= 100) {
        return 25;
    } else if (number <= 500) {
        return 60;
    } else {
        return 120;
    }
}

int main()
{
    //: Read how many numbers follow.
    int n {0};
    std::cin >> [[n]];
    //: For each index from 0 to n - 1, read a number and print the function's answer.
    for (int index {0}; index < n; ++index) {
        int number {0};
        std::cin >> number;
        std::println("{}", [[value(number)]]);
    }
}
```
