# 12.12
Write a program that reads n integers and prints each with its digits in reverse order.
The reversed integer has no zeros in front, so 120 gives 21 and 0 gives 0.

Input: line 1, n; line 2, n integers separated by spaces.
Output: n lines, one per integer in the order read.
Limits: 1 ≤ n ≤ 100, 0 ≤ each integer ≤ 1 000 000 000.

## Examples
```in
3
123 120 7
```
```out
321
21
7
```
## Solution
```cpp
#include <iostream>
#include <print>

//: Write a function above main that takes one number and gives back the answer for it.
int reversed([[int number]])
{
    //:: Start the result at zero.
    int result {[[0]]};
    //:: Move each last digit of the number to the end of the result.
    while ([[number > 0]]) {
        result = result * 10 + number % 10;
        number /= 10;
    }
    //:: Give back the result.
    return [[result]];
}

int main()
{
    //: Read how many numbers follow.
    int n {0};
    std::cin >> [[n]];
    //: For each index from 0 to n - 1, read a number and print the function's answer.
    for (int index {0}; index < n; ++index) {
        int number {0};
        std::cin >> number;
        std::println("{}", [[reversed(number)]]);
    }
}
```

        const std::string text {std::to_string(x)};
        std::string back {};
        for (int k {static_cast<int>(text.size()) - 1}; k >= 0; --k) back += text[k];
        std::println("{}", std::stoi(back));
    }
}
