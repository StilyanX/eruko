# 12.15
Write a program that reads n integers and prints, for each, a row of that many * characters.

Input: line 1, n; line 2, n integers separated by spaces.
Output: n lines, one per integer in the order read.
Limits: 1 ≤ n ≤ 100, 1 ≤ each integer ≤ 50.

## Examples
```in
3
2 5 1
```
```out
**
*****
*
```
## Solution
```cpp
#include <iostream>
#include <print>
#include <string>

//: Write a function above main that takes one number and gives back the answer for it.
std::string row([[int number]])
{
    //:: Start the result as an empty string.
    std::string result [[{}]];
    //:: Add a `*` for each index from 0 to the number - 1.
    for (int index {0}; index < [[number]]; ++index) {
        result += '*';
    }
    //:: Give back the result.
    return [[result]];
}

int main()
{
    //: Read how many numbers follow.
    int n {0};
    std::cin >> [[n]];
    //: For each index from 0 to n - 1, read a number and print the function's answer.
    for (int index {0}; index < n; ++index) {
        int number {0};
        std::cin >> number;
        std::println("{}", [[row(number)]]);
    }
}
```
## Slow
```cpp
#include <iostream>
#include <print>
#include <string>

int main()
{
    int n {0};
    std::cin >> n;
    for (int i {0}; i < n; ++i) {
        int x {0};
        std::cin >> x;
        std::string line(50, '*');
        while (static_cast<int>(line.size()) > x) line.pop_back();
        std::println("{}", line);
    }
}
```
