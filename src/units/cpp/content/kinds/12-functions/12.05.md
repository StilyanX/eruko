# 12.05
Write a program that reads n hours of the day and prints the part of the day each falls in.

Input: line 1, n; line 2, n integers separated by spaces.
Output: n lines, one per hour in the order read.
Night is 0 to 5, morning 6 to 11, afternoon 12 to 17, and evening 18 to 23.
Each range includes both its ends.
Limits: 1 ≤ n ≤ 100, 0 ≤ each integer ≤ 23.

## Examples
```in
4
7 23 0 12
```
```out
morning
evening
night
afternoon
```
## Solution
```cpp
#include <iostream>
#include <print>
#include <string>

//: Write a function above main that takes one number and gives back the answer for it.
std::string part_of_day([[int hour]])
{
    //:: Give back the part of the day for the hour.
    if ([[hour < 6]]) {
        return "night";
    } else if (hour < 12) {
        return "morning";
    } else if (hour < 18) {
        return "afternoon";
    } else {
        return "evening";
    }
}

int main()
{
    //: Read how many numbers follow.
    int n {0};
    std::cin >> [[n]];
    //: For each index from 0 to n - 1, read a number and print the function's answer.
    for (int index {0}; index < n; ++index) {
        int number {0};
        std::cin >> number;
        std::println("{}", [[part_of_day(number)]]);
    }
}
```
