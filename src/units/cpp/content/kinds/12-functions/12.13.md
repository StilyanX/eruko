# 12.13
Write a program that reads n integers and prints, for each, how many divisors it has.
A divisor is an integer from 1 to the integer itself, both included, that divides it.

Input: line 1, n; line 2, n integers separated by spaces.
Output: n lines, one per integer in the order read.
Limits: 1 ≤ n ≤ 100, 1 ≤ each integer ≤ 10 000.

## Examples
```in
3
12 7 1
```
```out
6
2
1
```
## Solution
```cpp
#include <iostream>
#include <print>

//: Write a function above main that takes one number and gives back the answer for it.
int divisors([[int number]])
{
    //:: Start the count at zero.
    int count {[[0]]};
    //:: Add one for each integer from 1 to the number that divides it.
    for (int divisor {1}; divisor <= number; ++divisor) {
        if ([[number % divisor == 0]]) {
            ++count;
        }
    }
    //:: Give back the count.
    return [[count]];
}

int main()
{
    //: Read how many numbers follow.
    int n {0};
    std::cin >> [[n]];
    //: For each index from 0 to n - 1, read a number and print the function's answer.
    for (int index {0}; index < n; ++index) {
        int number {0};
        std::cin >> number;
        std::println("{}", [[divisors(number)]]);
    }
}
```
