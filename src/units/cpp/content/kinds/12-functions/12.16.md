# 12.16
Write a program that reads n integers and prints each rounded to the nearest multiple of 10.
An integer whose last digit is 5 rounds up.

Input: line 1, n; line 2, n integers separated by spaces.
Output: n lines, one per integer in the order read.
Limits: 1 ≤ n ≤ 100, 0 ≤ each integer ≤ 1 000 000.

## Examples
```in
4
23 25 7 40
```
```out
20
30
10
40
```
## Solution
```cpp
#include <iostream>
#include <print>

//: Write a function above main that takes one number and gives back the answer for it.
int rounded([[int number]])
{
    //:: Give back the number rounded down or up to a multiple of 10.
    if ([[number % 10 < 5]]) {
        return number - number % 10;
    } else {
        return number - number % 10 + 10;
    }
}

int main()
{
    //: Read how many numbers follow.
    int n {0};
    std::cin >> [[n]];
    //: For each index from 0 to n - 1, read a number and print the function's answer.
    for (int index {0}; index < n; ++index) {
        int number {0};
        std::cin >> number;
        std::println("{}", [[rounded(number)]]);
    }
}
```
## Slow
```cpp
#include <iostream>
#include <print>

int main()
{
    int n {0};
    std::cin >> n;
    for (int i {0}; i < n; ++i) {
        int x {0};
        std::cin >> x;
        int best {0};
        for (int m {0}; m <= 1000010; m += 10) {
            const int gap {x > m ? x - m : m - x};
            const int old {x > best ? x - best : best - x};
            if (gap < old || (gap == old && m > best)) best = m;
        }
        std::println("{}", best);
    }
}
```
