# 12.14
Write a program that reads n integers and prints, for each, the smallest integer greater than 1 that divides it.

Input: line 1, n; line 2, n integers separated by spaces.
Output: n lines, one per integer in the order read.
Limits: 1 ≤ n ≤ 100, 2 ≤ each integer ≤ 10 000.

## Examples
```in
4
15 7 8 49
```
```out
3
7
2
7
```
## Solution
```cpp
#include <iostream>
#include <print>

//: Write a function above main that takes one number and gives back the answer for it.
int smallest_divisor([[int number]])
{
    //:: Start the divisor at 2.
    int divisor {[[2]]};
    //:: Add one to the divisor until it divides the number.
    while ([[number % divisor != 0]]) {
        ++divisor;
    }
    //:: Give back the divisor.
    return [[divisor]];
}

int main()
{
    //: Read how many numbers follow.
    int n {0};
    std::cin >> [[n]];
    //: For each index from 0 to n - 1, read a number and print the function's answer.
    for (int index {0}; index < n; ++index) {
        int number {0};
        std::cin >> number;
        std::println("{}", [[smallest_divisor(number)]]);
    }
}
```
