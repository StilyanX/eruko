# 12.06
Write a program that reads n integers and prints, for each, the nearest integer from 0 to 100, both included.

Input: line 1, n; line 2, n integers separated by spaces.
Output: n lines, one per integer in the order read.
Each line is 0 for an integer below 0, 100 for one above 100, else the integer.
Limits: 1 ≤ n ≤ 100, -1000 ≤ each integer ≤ 1000.

## Examples
```in
4
-5 50 101 100
```
```out
0
50
100
100
```
## Solution
```cpp
#include <iostream>
#include <print>

//: Write a function above main that takes one number and gives back the answer for it.
int within_range([[int number]])
{
    //:: Give back 0 for a number below 0, 100 for one above 100, else the number.
    if ([[number < 0]]) {
        return 0;
    } else if (number > 100) {
        return 100;
    } else {
        return number;
    }
}

int main()
{
    //: Read how many numbers follow.
    int n {0};
    std::cin >> [[n]];
    //: For each index from 0 to n - 1, read a number and print the function's answer.
    for (int index {0}; index < n; ++index) {
        int number {0};
        std::cin >> number;
        std::println("{}", [[within_range(number)]]);
    }
}
```
