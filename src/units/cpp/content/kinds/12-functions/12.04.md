# 12.04
Write a program that reads n month numbers and prints the number of days in each.
The year is not a leap year.

Input: line 1, n; line 2, n integers separated by spaces.
Output: n lines, one per month in the order read.
Each line is 28 for month 2, 30 for months 4, 6, 9 and 11, else 31.
Limits: 1 ≤ n ≤ 100, 1 ≤ each integer ≤ 12.

## Examples
```in
3
2 4 1
```
```out
28
30
31
```
## Solution
```cpp
#include <iostream>
#include <print>

//: Write a function above main that takes one number and gives back the answer for it.
int days([[int month]])
{
    //:: Give back 28 for month 2, 30 for months 4, 6, 9 and 11, else 31.
    if ([[month == 2]]) {
        return 28;
    } else if (month == 4) {
        return 30;
    } else if (month == 6) {
        return 30;
    } else if (month == 9) {
        return 30;
    } else if (month == 11) {
        return 30;
    } else {
        return 31;
    }
}

int main()
{
    //: Read how many numbers follow.
    int n {0};
    std::cin >> [[n]];
    //: For each index from 0 to n - 1, read a number and print the function's answer.
    for (int index {0}; index < n; ++index) {
        int number {0};
        std::cin >> number;
        std::println("{}", [[days(number)]]);
    }
}
```
