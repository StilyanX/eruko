# 42.01
Source: exercism twelve-days
Write a function `twelve_days::recite(int start, int end)` that returns, as a `std::string`, the verses for the days from start to end, with an empty line between 2 verses.
The verse for day d is one line: `On the `, the name of day d, ` day of Christmas my true love gave to me: `, then the gifts of the days from d down to 1 split by `, `, with `and ` before the last gift when d is more than 1, then a full stop and a newline.
The names of the days are first, second, third, fourth, fifth, sixth, seventh, eighth, ninth, tenth, eleventh and twelfth.
The gifts of days 1 to 12 are: a Partridge in a Pear Tree, two Turtle Doves, three French Hens, four Calling Birds, five Gold Rings, six Geese-a-Laying, seven Swans-a-Swimming, eight Maids-a-Milking, nine Ladies Dancing, ten Lords-a-Leaping, eleven Pipers Piping, twelve Drummers Drumming.
Limits: 1 ≤ start ≤ end ≤ 12.
## Solution
```cpp
#pragma once

#include <array>
#include <string>

namespace twelve_days {

//: Write a function that builds a new string one piece at a time and gives it back.
std::string verse([[int day]])
{
    //:: Make the lists of the names of the days and of the gifts, the first day first.
    const std::array<std::string, 12> names {
        [["first"]], "second", "third", "fourth", "fifth",
        "sixth", "seventh", "eighth", "ninth", "tenth",
        "eleventh", "twelfth"};
    const std::array<std::string, 12> gifts {
        "a Partridge in a Pear Tree", "two Turtle Doves",
        "three French Hens", "four Calling Birds",
        "five Gold Rings", "six Geese-a-Laying",
        "seven Swans-a-Swimming", "eight Maids-a-Milking",
        "nine Ladies Dancing", "ten Lords-a-Leaping",
        "eleven Pipers Piping", "twelve Drummers Drumming"};
    //:: Start the result with the opening words for the day.
    std::string result {[["On the "]] + names[day - 1] + " day of "
                        "Christmas my true love gave to me: "};
    //:: Add each gift from the day's down to the second, each with a comma after it.
    for (int index {day - 1}; [[index > 0]]; --index) {
        result += gifts[index] + ", ";
    }
    //:: Add `and ` when there is more than one gift, then the first gift and a full stop.
    if ([[day > 1]]) {
        result += "and ";
    }
    result += gifts[0] + ".\n";
    //:: Give back the result.
    return [[result]];
}

//: Write a function that builds a new string one piece at a time and gives it back.
std::string recite([[int start]], int end)
{
    //:: Start the result as an empty string.
    std::string result {[[""]]};
    //:: For each day from start to end, add an empty line before all but the first, then its verse.
    for (int day {start}; day <= end; ++day) {
        if (day > start) {
            result += "\n";
        }
        result += [[verse(day)]];
    }
    //:: Give back the result.
    return [[result]];
}

}  // namespace twelve_days
```
