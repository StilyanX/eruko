# 59.01
Source: exercism sublist
Write a function `sublist::sublist(const std::vector<int>& list_one, const std::vector<int>& list_two)` that returns how the two lists relate, as a value of `enum class List_comparison { equal, sublist, superlist, unequal }`, which you write in namespace `sublist` too.
Return `equal` when the lists hold the same values in the same order.
Else return `sublist` when the second list holds the first as a run of values next to each other, and `superlist` when the first holds the second so.
Else return `unequal`. The empty list is a run inside every list.
Limits: 0 ≤ length of each list ≤ 1000.
## Solution
```cpp
#pragma once

#include <algorithm>
#include <vector>

namespace sublist {

//: Name each possible value in an `enum class`.
enum class List_comparison {
    equal, [[sublist]], superlist, unequal
};

//: Write a function that gives back true at the first item that passes a test, else false.
bool contains([[const std::vector<int>& list]],
    const std::vector<int>& part)
{
    //:: Give back true at the first start in the list where the part follows.
    for (std::size_t start {0};
         start + part.size() <= list.size(); ++start) {
        const auto first {list.begin() + start};
        if ([[std::equal(part.begin(), part.end(), first)]]) {
            return true;
        }
    }
    //:: Give back false, since no start matched.
    return [[false]];
}

//: Write a function that tests each case in order and gives back the result of the first that holds.
List_comparison sublist([[const std::vector<int>& list_one]],
    const std::vector<int>& list_two)
{
    //:: Give back equal for equal lists, sublist when the second holds the first, superlist when the first holds the second, else unequal.
    if ([[list_one == list_two]]) {
        return List_comparison::equal;
    } else if (contains(list_two, list_one)) {
        return List_comparison::sublist;
    } else if (contains(list_one, list_two)) {
        return List_comparison::superlist;
    } else {
        return List_comparison::unequal;
    }
}

}  // namespace sublist
```
