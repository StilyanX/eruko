# Releases

Eruko uses Semantic Versioning (semver.org). Before 1.0.0, any release may change anything.

The `main` branch holds every unit, finished or not, each labelled in [`STATUS.md`](STATUS.md).

A new version never forces itself on you: the version you have keeps working with no connection.

Each release states its download size in [`CHANGELOG.md`](CHANGELOG.md).
