# Security

Report a security hole privately, through the repository's Security tab, "Report a vulnerability". Do not open a public issue for it.

Say what you found, how to reproduce it and which release or commit you used. The maintainers answer within 14 days, fix it in the stable release and in preview, and name you in the changelog if you wish.

Eruko keeps no data about you on any server but the one on your own computer that `npm start` runs, so a hole can reach only what is in your own browser or on your own computer.
